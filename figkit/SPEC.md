# PPT 配图规格（v1，2026-11-13 定稿）

> 来源：fig12/13 方法对照图（峰哥认可版式）—— 把当时的手工数值固化为规格。
> 落地：`figkit/figlib.py` 里的常量与本文一一对应，**改数值先改本文，再改库**。
> 参考样例：`splatanything/09_make_fig12_13.py`（双栏流水线 + 差异表的完整用法）。

## 0. 适用范围

汇报 / 答辩 PPT 里的**整页插图**：方法对照页、机制示意页、读数汇总页、趋势页。
封面与装饰图不受此约束。核心目的是"一页讲一件事"，让观众不看讲稿也能读出差异。

## 1. 画布与导出

| 项 | 值 |
|---|---|
| 尺寸 | **1920 × 1080**（16:9 满版，铺满 PPT 页面不留白边） |
| 色彩 | RGB，无 alpha；底色纯白 `#FFFFFF` |
| 格式 | PNG，`optimize=True` |
| 插入 PPT | 选"铺满整页"，**不要**拉伸变形（拉伸会改字号观感） |
| 字体 | 微软雅黑 `msyh.ttc` / 粗 `msyhbd.ttc` / 细 `msyhl.ttc` |

非满版（半页图、单图卡）用 960×1080 或 1920×540，纵向栅格从 §3 等比例减半。

## 2. 栅格

固定边距 **M = 64**（四边同心）。可用区 1792 × 952。

```
y=32   标题（42px bold）        ┃ 竖条 64..72 × 40..92
y=90   副标题（22px）
y=132  ──── 通栏分隔线 2px ────
y=142  ┌ 左卡 852×80 ┐ 88 ┌ 右卡 852×80 ┐
y=234  │ 步骤 1  66 高 │    │             │   ← CARD_Y+92
       │ 步骤 i  行距 72 │    │             │
y=660  └ 步骤 6       ┘    └             ┘
y=706  表头（维度 / 左 / 右）
y=736  ──── 细线 2px ────
y=744  行 1..5（每行 57）
y=1029 表格底
y=1044 页脚口径（17px light）
```

| 元素 | 数值 |
|---|---|
| 左右双卡 | 卡宽 852，中间沟 88；x = 64 / 1004 |
| 卡内步骤块 | x = 卡左 + 28，宽 796（= 852 − 56） |
| 步骤块 | 高 66，纵向间距 6（行距 72）；第 i 步 y = 234 + i×72 |
| 流转轨道 | 竖线 2px，x = 块左 + 12，仅连相邻块 |
| 差异表 | x = 64，宽 1792；维度列 200 + 两列各 796 |
| 表格行 | 高 57，双线斑马（奇数行填 `BG_SOFT`，左右各出血 12 / 6） |

**硬约束**：

1. **两栏行数必须相等**，同 y 逐行对齐 —— 差异靠"灰化块 + 徽章 + 高亮环"表达，
   不靠错位。行数不等时把缺的一步写成"无此步"，不要留空。
2. 任何元素不得越过 y = 1029；页脚文字底边 ≤ 1067。
3. 表格固定 5 行。超过 5 行改成分组或拆页，不缩行高。

## 3. 字号阶梯

| 用途 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 页标题 | 42 | bold | INK |
| 副标题 / 一句话定位 | 22 | regular | INK2 |
| 卡片方法名 | 32 | bold | INK |
| 卡片脚注 | 19 | light | INK2 |
| 步骤主标题 | 23 | bold | INK（灰化块用 INK2） |
| 步骤副说明 | 17 | light | INK2 |
| 徽章 | 16 | bold | 白字 |
| 表头 | 20 / 列标题 21 | bold | 维度列 INK2，列标题用方法色 |
| 表格正文 | 19（超宽自动降到 16 为止） | regular | 维度列 bold INK，内容 INK |
| 页脚口径 | 17 | light | INK2 |

不许出现阶梯外的字号。**行内只有两级**：主标题 + 一行副说明，第三行起改用表格。

## 5. 组件

- **页眉**：左侧 8×52 靛蓝竖条 + 42px 标题 + 22px 副标题，下方通栏 2px 细线。
  标题写成"结论句"（`A 与 B：差在「要不要回炉」`），不写"XX 对比图"。
- **卡片头**：圆角 14、底 `CARD_FILL`、边 `CARD_EDGE`；左内侧 10 宽色条标方法身份色；
  方法名 + 一行"是什么"的定位语（≤ 20 字）。
- **步骤块**：圆角 10、白底、2px 方法色边框；主标题 23 bold + 副说明 17 light；
  右侧可选胶囊徽章（`1 次前向` / `独有` / `新增`，**≤ 6 个汉字**）。
  灰化（`dim=True`）表示"这一步被去掉 / 不属于该列"，用 `DIM_EDGE` 边 + `DIM_FILL` 底。
- **高亮环**：给关键差异块包一圈 3px 方法色圆角外环（外扩 7px），一张图最多 1 处。
- **差异表**：5 行固定维度（冗余/外观/后处理/尺度/典型失败一类的正交切面），
  每格 ≤ 2 行；列标题用方法身份色。
- **页脚口径**：**必填**。一句话写清数据来源 + 不可比之处。

## 6. 内容纪律（比版式更重要）

1. **无口径不出图**：页脚必须能回答"数字哪来的、能不能横比"。
2. **不跨口径比分数**：自洽 vs held-out、不同场景/分辨率/体素/步数，只比机制不比数字。
3. **机制示意图要标明性质**：`机制示意，非实验结果`；图内不写推断性因果
   （"因为 X 所以差"必须是实测结论，否则写"根因未定"）。
4. **按区域裁剪必须逐视角定框**，并目视核对裁切图 —— 固定框换个视角会框到背景，
   把指标虚高（历史事故：人脸锐度虚高 +180）。
5. **负结果与未定论**用 RED / GRAY + 明确措辞，不写"更好/更差"。
6. 微软雅黑**无 `✓` `✗` 字形** → 一律用 `√` `×`；箭头用 `→`，间隔用 `·`。
7. 图内每个数字都要能回查到 `NOTES.md` / `FINDINGS.md` / `EXPERIMENTS.md` 的具体章节，
   并在脚本 docstring 里写出处。

## 7. 实现坑（PIL）

1. **圆角块内两行字会被底边框切**：块高须 ≥ 副字 y + 副字号×1.4 + 8。
   66 高配 23/17（y+4 / y+34）安全；64 高会切掉副说明的下缘。
2. **表格列错位**：列起点 `xs` 必须从 `x + dim_w` 起算，别把维度列宽算进第一列。
3. **PIL 无自动换行**：超宽靠 `table()` 降字号（19→16）或手动 `\n`（≤ 2 行，行距 26）。
4. 徽章宽度是估算（中文 15 / 西文 9 + padding 26），标签过长会压到主标题。
5. 每次导出后**必看成品图**，不靠 print 判断：重点查副说明是否被切、徽章是否溢出、
   表格末行是否压到页脚。

## 8. 交付前自检

- [ ] 1920×1080；无元素越过 y=1029；页脚底边 ≤ 1067
- [ ] 两栏行数相等、同 y 对齐；关键差异有灰化/徽章/高亮环
- [ ] 副标题、副说明、徽章均未被边框切、未溢出
- [ ] 页脚口径存在，且能回查来源
- [ ] 图内数字逐个对照台账核对过（不靠记忆）
- [ ] 已目视检查成品 PNG

## 10. 用法

```bash
# 图脚本放在算法目录下，按 <编号>_make_<主题>_figures.py 命名
python figkit_demo.py            # 见 README.md
```

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parents[1] / 'figkit'))

import figlib as F

F.set_root(r'D:/splatanything_figures')   # 成品落 <root>/figures/
im, d = F.canvas()                        # 1920×1080
F.header(d, '结论句标题', '一句话副标题')
F.card_head(d, F.M, F.CARD_Y, F.C_DA3, 'DA3-GS', '一次前向直出')
F.footer(d, '口径：...（数据来源 + 不可比之处）')
F.save(im, 'fig14_xxx.png')
```
