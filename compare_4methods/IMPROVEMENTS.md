## 0. 工作方式：官方基线优先

峰哥 2026-11-08 定的规矩：**先把 DA3 官方效果复现干净，再以它为唯一参照，一次只加一个改动。**

不是形式主义，有两次实证代价：

- **E-01**：高斯漏乘 `scale_factor`，我们拿"错尺度的 DA3"当基线比了三天，得出"加容量无效"的错误结论。
- **R-5**：把"PLY 交付口径（裁剪+仅 DC）"当成"官方效果"，于是"前馈 init 的优势"被高估 3.1 dB。

两次都是**参照物本身不干净**，而不是改动没效果。

所以：**主判据一律不用全图 PSNR**，用结构指标（掠射区一致性 / 法向一致性 / mask 外泄漏）。

### 2.5.3 结论：两个开关分工明确（本轮最重要的发现）

**全 SH 买「清晰度」，不裁剪买「准确度」，两者几乎不重叠。**

- 全 SH 把人脸锐度从 268 拉到 450（+182，+68%），但 PSNR 只 +0.81 —— 因为 SH rest 补的是
  **颜色随视角的变化**，它让表面有明暗层次和高频，但不改变几何落点。
- 不裁剪把点数提高 26%（484→610 万），人脸 PSNR +2.96，锐度几乎不动（+4）—— 它治的是
  **点密度不足导致的空洞与错位**，不负责高频。
- 归位前那种「既糊又重影」，其实是**两个不同的缺失各占一半**：糊来自只有 DC（颜色无高频），
  重影来自点数被砍掉 26%。此前把所有症状都记在"点数/密度"账上，是错的。

对后续的直接影响：

1. **要治"糊"，第一优先级是 I-02（全 SH），不是加点或加分辨率**。而且它零训练成本。
2. 之前 R-2（训练后 SH rest 仅 +0.23 dB）之所以收益小，是因为训练会让 DC 去重新拟合颜色，
   把 SH rest 的价值吃掉；**直出**时它值 +1.15 dB。两个结论不矛盾，但用的时候要分清口径。
3. 归位后的人脸基线是 **19.72 dB / 锐度 489**（378×504 口径）。I-03/I-04 的收益要相对它报。

## 3. I-03 / I-04：把 DA3 的高斯头换成 2DGS 头

### 3.0 一句话

**提升点不在"2DGS 更强"，而在"DA3 已经在输出一个退化的 2D 表示，却用 3DGS 的光栅器去渲染它"。**
换 2DGS 是①把表示和渲染器对齐、②把一个原本自由回归、没有几何意义的量（法向）变成可监督量。
预期收益集中在**掠射视角的重影/幽灵/拉丝**，**不是全图 PSNR**。

### 3.1 事实：DA3 的头现在输出什么（实测，非推断）

**(a) scale 是三轴独立 sigmoid，没有排序**（`model/gs_adapter.py`）：

```python
scales = 1e-5 + (30 - 1e-5) * scales.sigmoid()          # 三轴各自独立
gs_scales = scales * depth * 0.1*(1/fx_px + 1/fy_px)    # 折成米制，与分辨率无关
```

**(b) 最小 σ 落在局部 x 轴（index 0），占比 99.9%**（`audit_12_surfel_orient.py`，4 视角各 15 万点）：

| 视角 | argmin = 轴0 / 轴1 / 轴2 | σ 最长轴中位（px @378） |
|---|---|---|
| 0 | 151,545 / 1 / 0 | 1.31 |
| 8 | 149,868 / 1 / 0 | 1.85 |
| 16 | 150,316 / 0 / 0 | 2.01 |
| 24 | 151,146 / 45 / 1,168 | 1.76 |

σ 三轴折合像素：init `[0, 0.48, 1.28]` @378（`audit_7`），同一批渲染 1439 时 `[0, 1.84, 4.86]`。
→ 第三维不是"薄"，是**被 `gaussian_scale_min=1e-5` 压到下限的退化轴**。

**(c) 这个退化轴的方向（= 盘的法向）与几何无关**：

| 视角 | vs 视线 | vs 真实表面法向 |
|---|---|---|
| 0 | 28.9° | 56.9° |
| 8 | 50.9° | 56.5° |
| 16 | 41.6° | 64.4° |
| 24 | 25.2° | 56.7° |

按表面倾斜度 `slant = ∠(表面法向, 视线)` 分层：

| slant | 占比 | vs 视线 | vs 表面 |
|---|---|---|---|
| 0–30°（正对） | 16.4% | 29.0° | 32.9° |
| 30–60° | 59.6% | 41.1° | 60.9° |
| 60–90°（掠射） | 23.9% | 34.3° | **66.4°** |

**两个向量夹角的中位，随机基线是 57.3°。** 所以：

- 这个法向**与真实表面基本无关**（56.9~66.4° ≈ 随机）；
- 它也**不是严格 billboard**（朝相机应 <10°），而是"半侧立、逐视角自由回归"；
- 三轴里确实有一轴接近视线（最近轴 vs 视线 19~25°），**但被压到 0 的不是那一轴**。

→ **DA3 学出了"零厚度"，但没学出"法向"。厚度这一自由度被用掉了，方向这一自由度被浪费了。**

### 3.2 原理：表示与渲染器错配在哪

3DGS 的渲染是 EWA 投影：

```
Σ_world = R S Sᵀ Rᵀ        (S = diag(σ0,σ1,σ2))
Σ_screen = J W Σ_world Wᵀ Jᵀ  (2×2)  + ε·I
```

它暗含两个假设：

- **H1** 高斯在屏幕上的足迹是 2D 高斯（仿射近似：视锥在单个高斯尺度内近似平行）；
- **H2** `Σ_world` 满秩 3×3。

**DA3 的输出直接违反 H2**：第三轴 = 0 → `Σ_world` 秩 2 → 投影协方差秩 ≤ 2。
数值上只能靠 `eps2d=0.3`（σ 下限 ~0.55 px）兜住——**这就是"低通"，也是"糊"的机制之一**。

掠射时（盘法向 ⟂ 视线）更糟：透视缩短让两个屏幕特征值一个 →0、一个 →∞，**条件数爆炸**。
屏幕上表现为"极长条 + 低通"：长条 = 拉丝/飞镖伪影，低通 = 糊。这正是 fig20 侧立视角淡重影的来源之一。

2DGS 改了两件事：

**(1) 表示**：只有切平面内两轴，第三维是法向，厚度恒为 0。
`gsplat/cuda/csrc/Projection2DGSFused.cu:152`：

```c
mat3(scales[0], 0.0, 0.0,
     0.0, scales[1], 0.0,
     0.0, 0.0, 1.0);      // 第三维是常量 1，不是学出来的
```

**(2) 求交**：射线 `x(t)=o+td` 与平面 `(p,n)` 求交 `t = (p·n − o·n)/(d·n)`，在交点处取 2D 高斯值
（`gsplat` 的 `rasterization_2dgs` docstring 明写 "prepares ray-splat intersection matrices"）。

后者的意义：屏幕上得到的是**被正确透视缩短的椭圆**，不是"无限支撑的高斯尾部"。
掠射角下不再需要靠低通去救。

### 3.3 提升点，分三档

#### A. 确定的（有数学必然性）

- **A1 消除退化轴的病态**。表示与渲染器对齐后，`[0, 0.48, 1.28] px` 从"3D 高斯的极限退化"变成"合法的 2D 椭圆"，
  σ 不再需要 `eps2d` 兜底，掠射时也不再条件数爆炸。
- **A2 深度变成平面交点**，而不是"沿视线的高斯中心加权平均"。`rasterization_2dgs` 额外返回
  `median_depth` 与 `distort`；多层叠加时 median 深度不会被"前后两层拉向中间"——**这直接对应幽灵/半透明的观感**。
- **A3 法向从"自由参数"变成"可监督量"**（最大的一条）。现在 484 万个法向各自独立回归、与表面差 ~57°（≈随机）；
  2DGS 下可被 `L_normal = Σ wᵢ(1 − nᵢᵀN̂)` 拉向深度图法向、被 `L_distort` 拉向"同一射线单深度"。
  **这两个损失在 3DGS 里没有定义**（3D 高斯的"法向"不存在）——这是换表示才能拿到的东西。

#### B. 可能的（机理成立，幅度要实测）

- **B1 掠射视角（slant>60°，占 24%）的重影/拉丝减少**。A1+A2 的直接后果，也是我们真正在意的观感。
- **B2 跨视角一致性改善 → 31 层叠加从"平均掉误差"变成"收敛到同一表面"**，锐度可能回升
  （不再需要靠大 σ 去平均）。
- **B3 点数效率**：surfel 表达薄表面更省点，同样 484 万点的覆盖可能更好。

#### C. 不会发生的（必须提前写清，否则会被误判成失败）

- **C1 不会凭空造出高频**。σ 的像素当量由"点数/像素"决定（0.79 个/px，单层 α 中位 0.036）；
  换渲染器不改这个数。1.3 px 的点还是 1.3 px。
- **C2 不会修位姿**。跨视角深度一致性中位 0.95%、p90 视角对 37.3% 的偏差来自 DA3 的位姿/深度；
  2DGS 只会让它**更诚实地显影**，不会让它消失。
- **C3 全图 PSNR 可能不动甚至微降**。自一致性口径奖励平滑，2DGS 更锐 → 在点不足的区域可能掉分。
  **所以主判据绝不能是全图 PSNR**（R-3 的教训）。

### 3.4 落地：最小改动与两个陷阱

**⚠️ 陷阱 1（会直接毁掉结果）：轴序。**
2DGS 只用 `scales[0], scales[1]`，第三维硬编码 1.0；而 DA3 的最小轴在 **index 0**（99.9%）。
直接喂 → `s0≈0` 被当成切平面内的一轴 → **宽度为 0 的刀片，屏幕上几乎消失**。
必须重排：`s' = [s1, s2, s0]`，并对旋转矩阵做同排列置换 `R' = [c1, c2, c0]`（再转回四元数）。

**陷阱 2：法向符号。** surfel 法向无符号，`d·n` 可能为负 → 背面剔除/深度符号错。
要么统一翻转朝相机，要么在损失里用 `|nᵀN̂|`。

**分两步走（遵循 R2 单变量）**：

| 步 | 改什么 | 是否重训 | 能测出什么 |
|---|---|---|---|
| **I-03** | 只换光栅器，头不动，导出时做轴重排 | 否（用现有 PLY，~20 行） | "表示/渲染器错配"的净代价 |
| **I-04** | 头输出 2 轴 + 3 轴法向；训练加 `L_normal` + `L_distort` | 是（2k 步） | 法向可监督带来的真实收益 |

I-03 几乎零成本且**不需要重训**，能立刻给方向性信号；I-04 才是提升主体。

### 3.5 预注册判据（跑之前定死）

**I-03（只换光栅器，不重训）**

- 主判据：掠射区（slant>60°）的**跨视角深度一致性中位**，应从 0.95% 降到 **< 0.85%**
- 次判据：`median_depth` 相对 GT 深度的中位绝对误差应下降
- 反判据：全图 PSNR 若降 >1 dB 且掠射区无改善 → 判"错配不是主要矛盾"，回去做 I-01/I-02（归位）

**I-04（改头 + 正则，重训 2k 步）**

- 主判据：**跨视角法向一致性**——同一世界点在相邻视角的盘法向夹角中位，应从 57° 降到 **< 30°**
- 次判据：掠射视角（view 8 / 16）PSNR 相对基线 **+0.5 dB** 以上
- 反判据：法向一致性改善但掠射 PSNR 不变 → 瓶颈是点数/σ 而非朝向，2DGS 判 B（不否定，但降优先级）

### 3.6 与其它案子的耦合

- I-03/I-04 与 I-01（不裁剪）、I-02（全 SH）**正交**，可独立叠加。
- **顺序建议**：I-01 → I-02 → I-03 → I-04。前两项零成本且幅度确定，先把参照物抬到官方水平，
  再谈演进；否则 I-03 的收益会跟"归位"混在一起，分不清是谁的功劳。
- 若 I-03/I-04 之后仍要提升清晰度，真正的杠杆回到"点数/像素"（0.79 个/px）与"σ 下限"，
  即加训练分辨率或加点——但 R-3 已实测：加分辨率买的是"大面积纹理"（背景），人脸几乎不变。
