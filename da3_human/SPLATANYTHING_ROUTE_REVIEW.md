# DA3 与 SplatAnything：人像前馈路线评审及实验设计

日期：2026-11-12。状态：**源码/文献评审与预注册方案，未执行本文实验**。
执行入口为 [EXPERIMENT_PLAN.md](EXPERIMENT_PLAN.md)；结果落入各项目 `EXPERIMENTS.md`。
本文不替代现有 DA3 E1～E4 结论，也不把其他会话的进行中记录当成已验证结果。

## 1. 建议：优先验证 SplatAnything，暂缓 DA3 大规模重训

当前最合理的投入顺序是：**SplatAnything 成品基线 → 中心来源诊断 → 胜出基座的人像域改进**。
不是立即废弃 DA3。DA3 的数据协议、UE 数据、几何诊断、渲染器和 T1～T4 外观实验均可复用。
切换的是模型基座，不是把前期工作推倒重来。

理由：DA3 已有反复出现的非参考视角几何/外观问题；继续从头设计 Geometry Head 的成本较高。
SplatAnything 已提供不同的几何基座、固定反投影中心和训练好的高斯属性模型，值得先测其起点。
但只有在本任务上的真实 held-out 结果及小规模训练可行性均通过后，才建议正式迁移。

目标仍是 3～13 张人物图像的前馈直出。18v 作扩展，32v 作压力测试；不引入逐场景优化、
测试时位姿优化或视频生成补全。人物运动另记为数据条件，不能默认静态模型可解释跨帧动作。

## 2. 方法哪里好，哪里不能替我们解决问题

| 维度 | 对本任务的价值 | 边界 |
|---|---|---|
| GSNorm | 让不同焦距、距离、分辨率下的高斯预测使用一致的间距尺度 | 一个场景级标量不会让三簇错位人物云自动对齐 |
| 冻结几何、固定中心 | 限制外观学习通过移动中心“作弊”，值得优先引入 DA3 对照 | 依赖基础深度本身正确；合并后的中心仍是体素内加权位置 |
| WorldMirror-2 几何 | 为 DA3 已发现的几何问题提供一个独立候选 | 不能从场景榜单推断其人体、脸、手、稀疏大角度一定更好 |
| RGB 残差外观与合并权重 | 有望改善颜色保持、减少逐视角重复高斯 | DC 外观、错误遮挡、融合后透明/模糊仍需实测 |
| 现成权重与推理包 | 可先测成品质量，避免先投入大训练 | 发布包没有训练闭环；能推理不等于能直接微调 |

GSNorm 是值得吸收的方法，但**对本仓更关键的是固定中心及几何/外观分工**。
本仓 E3 已证明盲目压 scale 会塌覆盖，因此不能把它理解成“换一个更聪明的 scale 钳制”。

对用户论文总结的四项校正：

1. “与 Mirror2-GS 唯一差别是归一化”不宜用于归因。端到端模型比较混有训练、中心约束、
   数据与解码配置差异；归一化贡献应看受控消融或自己同训练条件的 RDNorm/GSNorm 对照。
2. 两个 encoder 结构相近但权重/职责不同；直接共享会改变特征分布。先 profile，
   质量通过后再考虑共享骨干蒸馏，不能承诺 50% 算力浪费或固定毫秒收益。
3. 固定几何不适合直接替代 3DMM 拟合，不等于不适合静态人体 3DGS。
   当前目标是稀疏人像重建，不是驱动绑定；人体专项证据不足应记为待测。
4. 深度边缘处等深近似会失准，误差方向取决于邻域，不能笼统说“间距偏大”。
   直接开飞点过滤可能删除发丝、手指和轮廓，应单独测召回/空洞，不能默认开启。

## 3. 源码审计事实及其影响

本次读取官方网页，并读取本机干净 checkout：SplatAnything
`b51899653863ee498d2dcfa8141201d9225441f1`；DA3
`41736238f5bced4debf3f2a12375d2466874866d`。后续实验必须另存实际 commit、配置与权重哈希。

- SplatAnything `src/models/models/rasterization.py`：解码为 quat/scale/opacity/SH residual/weight；
  合并前 centers 来自 depth 反投影，无自由 center offset。外观是输入 RGB 的 DC 残差。
- GSNorm 在该实现中为 `factor = 0.0013227513 / median(D / sqrt(fx*fy))`，
  D 与相机平移共同缩放；YAML 的 voxel 为 0.002。不能把目标改成 1 而保留原权重和阈值。
- 合并 opacity 为 `sum(w*w)/sum(w)`，不是原 opacity 的普通加权平均。
  **因此只训练原 opacity 通道或只在它上面乘 confidence，可能根本影响不到最终图像。**
- 实际 YAML `max_scale_pct=99.8`，文档写 99.5；baseline 记录真实生效值，不静默“修正”。
- `GaussianWorldMirror.forward` 有 `@torch.no_grad()`；入口还调用 `requires_grad_(False)`
  和 `inference_mode()`。微调要恢复可导路径、接光栅化器、loss/优化器与数据加载。
- `depth/*.npy` 是归一前预测尺度，`cameras.json` 与 PLY 在归一后的云坐标；必须显式保存
  alignment/spacing 因子。不可拿两者直接反投影并宣称几何失败。
  UE 若提供 radial depth，要先按 K 的射线范数转换为 axial Z，再与模型 Z-depth 比较。
- `scene_io.py` 先按主点做对称矩形裁剪，再按目标宽高比缩放/裁切；**不是首步永远裁正方形**。
  默认方形输出可能损失竖幅人物头脚，评测前必须统计保留的前景面积。
- DA3 `gs_adapter.py` 已存在与深度、焦距相关的 scale multiplier，不能声称它完全没有
  footprint 自适应。`da3-giant.yaml` 启用 depth/xy offset，adapter 先修 depth 与射线再反投影。
  “最终中心错位”尚不能区分原始深度错误与 GS offset 引入的错误；S2 专门补这一层归因。

依据：官方 [SplatAnything 解码/合并源码](https://github.com/zju3dv/SplatAnything/blob/b51899653863ee498d2dcfa8141201d9225441f1/src/models/models/rasterization.py)、
[学生前向](https://github.com/zju3dv/SplatAnything/blob/b51899653863ee498d2dcfa8141201d9225441f1/src/models/models/gaussian_worldmirror.py)、
[预处理](https://github.com/zju3dv/SplatAnything/blob/b51899653863ee498d2dcfa8141201d9225441f1/src/utils/scene_io.py)、
[配置](https://github.com/zju3dv/SplatAnything/blob/b51899653863ee498d2dcfa8141201d9225441f1/configs/inference.yaml)、
[DA3 adapter](https://github.com/ByteDance-Seed/Depth-Anything-3/blob/41736238f5bced4debf3f2a12375d2466874866d/src/depth_anything_3/model/gs_adapter.py)。

## 4. 数据、相机和评测：先保证能回答问题

### 4.1 数据分层与防泄漏

- **小试真实集**：从现有 55 包中按人物、衣着纹理、头发/手、背景、轨迹缺口分层选 6 包，
  选包标准及 frame IDs 在看 SplatAnything 结果前冻结。既有坏例只作诊断，不代表泛化。
- **真实回归集**：全部 55 包按人物/同次采集分组去重；后续域训练前再按组划分。
  相同人物的不同包不能分属 train/test。实际独立人物不足时明确报告，不能把包数当人数。
- **UE 数据**：建议起步 24 个独立人物/场景组合，按身份及其关联场景分组 12/6/6，
  同一身份和同一场景资产均不跨训练/验证/测试；若无法同时隔离，额外建身份/场景 OOD 子集。
  这是工程筛选规模，不足以声称通用人体 SOTA；未收齐前不开始路线终判。
- 只有一个 UE 场景时只做相机/梯度/过拟合冒烟，不可将同场景不同相机拆成独立泛化样本。
- 真实序列剩余帧只有在人物姿态稳定且曝光可比时才作 held-out NVS；动态包先分姿态段，
  报保留帧数和覆盖损失，不用拟合失败掩饰动作不一致。三张都作输入时只有自一致性指标。

### 4.2 固定采样与同口径

主桶 N={3,8,13}，扩展 N=18，压力 N=32。输入取同一覆盖弧上的嵌套子集，增加 N 时
不扩大观测范围；另外保留近对跖、不均匀轨迹的压力子集。3v 是重点风险桶，不能只给 8v 平均值。
目标视角按插值/外推和共视程度分组；UE 使用 GT depth 可见性，真实无 GT 的估计不能冒充真值。

两条信息轨道分表：

| 轨道 | 输入给模型 | 评测对齐 |
|---|---|---|
| RGB-only | 相同 RGB，不向任一方法提供外部 K/T | 仅用输入相机拟合一次全局 Sim(3)，用于转换 held-out 相机/云，不逐目标拟合 |
| Pose-conditioned | 相同校验过的输入 K/T + RGB | 保存各自内部尺度和坐标变换，目标 GT 相机按同一全局变换映射 |

真实 Remy 位姿是采集先验而非绝对 GT；论文里 pose 模式的优势不能跨信息轨道比较。
不可给 SplatAnything 外部相机却拿 DA3 RGB-only 当唯一对手。DA3 内部可能仍用预测相机反投影，
同外部输入不意味着内部机制相同，应在 manifest 标出。

分辨率设两个面板，不能混为一张“算法增益”表：

1. **控制面板**：共同裁剪/resize 的 RGB、K、mask，起步 504 长边且宽高为 14 倍数；
   竖幅可候选 378×504，须确认两端实际 RGB/FOV 一致。若做不到，标记非严格控制对照。
2. **原生面板**：DA3 当前 504；SplatAnything 官方 756×756；用各自正确相机渲染到同一目标
   评测网格。另报共视区域和全人物覆盖，不能只评裁剪交集来隐藏被切掉的头脚。

统一 3DGS EWA 渲染器、背景色、颜色空间、目标分辨率及 SH 解释；保留模型原生属性：
DA3 不裁剪+全 SH，SplatAnything 原生 DC+官方合并/过滤。无需为“公平”砍掉 DA3 的 SH。
基线之后才分拆过滤/合并消融。若 PLY 重渲与内存高斯渲染不一致，先修评测再报方法差异。

### 4.3 指标与保存物

沿用主计划四组指标；重点为 held-out 人物 LPIPS/PSNR、脸 ROI、跨视角 center 重投影、
轮廓、alpha 空洞及 mask 外泄漏。真实无独立深度 GT 时不报绝对几何精度。
区域逐视角定框；锐度看相对 GT 的偏离，避免颗粒噪声使 Laplacian 虚高。
饱和度在 GT 非近灰像素统计绝对差，同时看颜色误差，不能靠过饱和拿高分。

场景内先聚合视角，再按独立人物/场景报告 paired 中位差、IQR 和分组 bootstrap 95% CI；
不把相邻帧当独立样本。按 3/8/13v、共视程度、遮挡/静态状态分桶。
选型和调参只看验证集；测试集待配置锁定后只做一次确认，不据测试结果反复改模型。
本轮空洞率定义为 GT 人物 mask 内 alpha<0.5 的像素比例；泄漏率定义为人物轮廓外
固定 5px 环带的平均人物 alpha（504 评测长边口径），并与 GT 边界叠图核验。
完整场景不能把所有背景 alpha 当人物泄漏：先用 source mask/几何关联提取人物高斯、
单独渲染人物 alpha；无法可靠拆分则该项记 N/A，并用 UE 实例 GT 完成守门，不填伪数值。
保存 source/target ID、裁剪变换、K/T、尺度因子、RGB/alpha/depth、合并前后 centers、
scale footprint、weight/opacity 分布、配置/权重 SHA256、随机种子和失败清单。

效率拆开权重加载、预处理、geometry、student、merge、导出、渲染；GPU 同步后计时，
预热一次、重复三次，报中位延迟和峰值显存。论文硬件时间不可换算成 RTX 3090 时间。

## 5. 实验矩阵与执行顺序

### S0：先验收接口和资源

真权重官方小例 → 1 个静态人像包 3v@504 → 8v → 13v。记录 OOM 和完成率；
训练推理均预留显存余量，不用 swap 掩盖 GPU 超预算。先不跑 32v@756 的大组合。
已有 SplatAnything 目录、权重池与转换工具直接复用，不重复建环境/下载。
本次读取的进行中实验记录只证明随机权重 CPU 冒烟等进度，不证明成品画质。

### S1：成品基线筛选（零训练）

| 编号 | 改动 | 要回答的问题 |
|---|---|---|
| B-D | 冻结 DA3 正式基线 | 当前可交付起点 |
| B-S | 官方 SplatAnything 权重/默认合并过滤 | 新方法的实际起点是否更好 |
| B-S-F | 仅关闭大 scale 过滤，其余与 B-S 同次前向 | 边缘损失/空洞是否由过滤造成 |

先跑 6 包 × 3 个主桶 × 2 方法 × 2 相机模式 = 72 个基础重建（同分辨率控制面板）；
滤波对照复用内存前向，原生分辨率面板先只测 3v/8v。S0 不通过的配置记录失败，不能偷偷降档。
S1 给出候选排序；UE held-out 未到位时仅作暂定判断，不宣布基座胜出。

### S2：补齐“深度 vs offset vs 属性”因果链

使用同次 DA3 前向的原始张量（Nested metric 对齐前后的单位必须显式换算）：

| 编号 | 唯一主动变化 | 解释范围 |
|---|---|---|
| C0 | 原始 depth + xy/depth offsets | 原生 GS |
| C1 | 将 raw xy offset 数值置零，仍按原通道布局解码 | xy 分支影响 |
| C2 | 将 raw depth offset 数值置零 | depth 分支影响；adapter 的 scale 随 depth 被动变化需另报 |
| C3 | 两种 offset 都置零 | 深度反投影固定中心候选；不是已重新训练的最终模型 |
| C4 | 只替换最终 means 为无 offset 反投影，保留 C0 scale/rotation/SH/opacity | 隔离 center 本身的作用，与 C3 成对解释尺度耦合 |

不得简单改配置 false 导致 checkpoint 通道错位。另存 raw depth 反投影云与 GS centers 的
逐像素位移，检查错误是否已存在于 geometry backbone。所有几何误差只在可见对应表面算；
原 E4 的全层非对角低 PSNR/出框率受可见性影响，不能当独立 GT 对应误差。

UE 到位后，加固定属性的 GT-center oracle（仅诊断，不用于产品与基线排名）。
原生 depth/DA3 固定中心/WorldMirror-2 depth 都在同 GT 相机与有效表面上验重投影、深度和边界。
GT center 改善大而 offset 清零也改善：优先训练固定中心属性头；
原生 depth 本身差：才进入受几何监督的深度修正或更换 geometry 基座。
移植 WorldMirror-2 depth 到 DA3 头或反向替换只能算适配实验，不能视为即插即用的公平归因。

### S3：只微调胜出候选，每次只加一项

执行预算以主计划 §0 的 WorkBuddy 任务单为准：**本轮仅 WB-4 的单步/最多 100 step 成本探测**。
本节 2,000/5,000 step 是成本与质量报告评审后的后续候选预算，不在当前首轮执行范围。

| 编号 | 可训练内容 | 冻结内容 / 对照 |
|---|---|---|
| H0 | 小规模学生属性头，保持原生归一与合并规则 | geometry、centers、encoder；确认优化链正常 |
| H1 | H0 + visibility-aware confidence 融合 | 同数据、训练步数、有效 batch；只改融合机制 |
| H2 | H0 + 受监督几何修正（仅在 S2 证明必要时） | 属性头不能自由移动 center；不与 H1 同时引入 |
| H3 | 验证有效的 H1/H2 合并 | 所有单项已成立后再做 |

训练前置门：去除学生路径的推理禁梯度，教师仍冻结；验证可训练参数 grad 非零且 finite、
优化一步权重确实变化，教师参数不变。合并分桶索引不连续，应先固定中心/分桶，
不要假设所有几何操作都有可用梯度。特别检查 weight 分支承接最终 opacity 的梯度。

起步预算（**建议上限，非耗时预测**）：1 个训练场景 100 step 过拟合冒烟；随后每候选
2,000 step、batch=1 scene、梯度累计 4、3v@504 起步，能承载后在 3/8/13v 中抽样。
保持相同更新数/视角分布，并另报相同 GPU 时间预算下的质量。每 250 step 验证；
连 4 个检查点无超过预注册噪声带的改善则停，不转而对测试集扫参。
H0 先用原生渲染损失，逐项加入 ROI/可见性项；不能同时改 LPIPS、采样和融合后归因于某一项。
H2 若启动，几何分支采用有效像素上的鲁棒 Z-depth/3D point 误差，加可见性门控的跨视角
重投影和轮廓损失；先单项调通再组合。外观损失对几何分支 stop-gradient，保留一组
完全冻结中心对照；损失按有效像素数归一，权重只在验证集选定并冻结。
胜出后做 3 个种子、最多 5,000 step 的确认；GPU 资源测不过则评估缓存冻结特征/更小 batch，
不要承诺在 24GB 上全模型训练或复刻论文级预算。

H1 的 confidence 必须先在验证集检查与误差的相关性、可靠性曲线，不能当已校准概率。
用跨视角重投影/深度遮挡一致性构造融合门控，低置信单视角区域保留退路，避免“删掉难点”伪提升。
SplatAnything 修改权重会同时改变中心加权和 opacity：必须一起报告；直接乘 opacity 不是等价实现。
头发/手/轮廓单独看边界召回与空洞；不要第一轮就引入生成式补洞。

GSNorm 的归因实验后置：只有训练链成立且尺度泛化仍是问题，才以同几何/同初始化策略、
同数据/损失/训练预算比较 RDNorm 与 GSNorm 的重新训练。只在现成 GSNorm 权重上改常数
最多是分布失配敏感性分析，不能否定或证明归一化方法。

### S4：复用 T1～T4，效率优化最后做

通过几何门槛后按主计划 T1 普通外观 → T2 高分辨率外观 → T3 Face ROI → T4 受约束联合。
明确 4× 指像素总数还是边长，本轮建议定义为**像素总数 4×、边长 2×**，manifest 显式记录。
Face ROI 沿用高分辨率输入局部特征、可见性采样，不复制整个全局 Transformer。
共享 encoder/蒸馏放在质量达标且 profile 证明有价值之后，必须有双 encoder 原版质量对照。

## 6. 预注册晋级与停止规则

以下是本项目的建议工程门槛，不是论文结论；执行前冻结，不因看到结果改阈值。

**SplatAnything 升级为主要开发基座须同时满足：**

1. S0 坐标/裁剪/导出验收通过；目标 3/8/13v 配置在资源预算内运行。若 13v OOM，只能
   建议 3/8v 子场景采用，不得宣布覆盖全部目标。
2. 独立 held-out 集相对 B-D：人物 LPIPS paired 中位相对降低 ≥10%，且 PSNR 中位
   提高 ≥1 dB；按独立身份/场景 bootstrap 的两项改善 95% CI 均不跨 0。
   对近零 LPIPS 不算不稳定相对率，另报绝对差。
3. 3v 主桶 PSNR 中位不下降、LPIPS 中位不升；人脸 PSNR 不下降超过 0.3 dB，
   人脸 LPIPS 不恶化超过 0.01；最差四分位 PSNR 不恶化超过 0.5 dB。
4. 空洞率和 mask 外 alpha 泄漏率各不增加超过 1 个百分点；轮廓/重投影误差中位
   不恶化超过 5%；若接近零误差，使用先冻结的像素容差。目检固定坏例无新增重影。
5. 同机、同 N/分辨率端到端延迟不超过 B-D 的 1.5×，GPU 峰值建议 ≤22 GiB；
   记录高斯数与实际渲染延迟，不将“25 万点”硬当跨分辨率的可比质量目标。
6. H0 梯度/资源冒烟成立。只满足 1～5 时可选为推理基线，尚不能称为更容易改进的训练基座。

若 CI 不确定，增加独立场景而非重复相邻帧；若质量提高但资源失败，列为质量参考/teacher
候选，不能无条件替换。若只在 pose 或 8v+ 胜出，结论限定到该模式/视角桶。
H1/H2 的晋级另看相对 H0：人物 LPIPS 至少降低 5%，几何/脸/覆盖守门不破，再做三种子确认。

路线选择表：

| 观察结果 | 后续选择 |
|---|---|
| SplatAnything held-out 明显赢，资源和训练链通过 | 以 SplatAnything 为主要改进基座，DA3 留作固定对照 |
| SplatAnything 赢但无法合理微调 | 先保留其成品推理基线，DA3 训练线保留；不从头复刻大训练 |
| SplatAnything 不赢，DA3 C3/C4 明显改善 | 优先 DA3 固定中心属性头训练，GSNorm 作为后续受控消融 |
| 两者原生几何都差，GT-center oracle 明显改善 | 先改人体几何先验/受监督深度分支，暂缓 Face ROI 和 encoder 加速 |
| 几何已好、脸仍糊 | 执行 T1～T4，而非继续改全局 center |
