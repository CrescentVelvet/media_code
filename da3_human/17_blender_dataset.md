# Blender 合成训练集准备清单（DA3 GS-DPT 微调用）

> 2026-11-09 建。峰哥用 Blender 渲染 3D 人物模型作为 LoRA/微调训练集。
> 本清单只规定「需要准备什么」与验收标准，实现由峰哥完成；格式对齐本仓 da3_human 管线。

## 0. 先明确三个训练事实（决定数据规格，2026-11-09 查证 arxiv 2511.10647）

| 事实 | 来源 | 对数据的要求 |
|---|---|---|
| DA3 主模型训练视角数**均匀采样 [2,18]** | 论文 Implementation | 训练采样 8~32 即可，**不需要也不应该每场景上百视角** |
| 基分辨率 504（短边），多宽高比 | 同上 | 渲染原图 ≥1440 短边，DA3 内部会缩；原图分辨率决定评估上限 |
| **GS-DPT 高斯头 = 冻结 backbone、只训 DPT 头**；损失 = 渲染 photometric（MSE+LPIPS）+ 观测视角 scale-shift-invariant 深度损失 | 论文 §5.1 | ① GT 深度图强烈建议出（深度损失直接用）② 相机位姿必须精确已知（Blender 天然满足）③ 我们的第一阶段是**复刻官方做法训头**，LoRA backbone 是第二阶段 |

**推论**：Blender 合成数据的独特优势 = 完美位姿 + 完美深度 + 无运动模糊/噪声；
最大风险 = **domain gap**（渲染器外观 ≠ 实拍照片），所以材质/光照/环境多样性是重中之重。

## 1. 相机几何基准（从 studio_human 实拍 125 视角反算，必须匹配）

| 参数 | 实测值 | Blender 设定 |
|---|---|---|
| 相机到人物中心半径 | **0.45 ~ 1.15 m，中位 0.68**（近景人像！） | 采样 0.5~1.2 m |
| 相机高度带 | 中心 ±0.22 m 窄带（手持环绕特征） | 在人物胸口高度 ±0.25 m 内环绕 |
| 方位角 | 全环 −177°~+178° | 每场景全环均匀 40 视角 |
| 焦距 | fx/W = **0.978**（504p 口径）⇒ 36mm 传感器下 **f ≈ 35.2mm** | sensor_width=36mm，focal=35mm（PINHOLE 无畸变，Blender 默认即满足） |
| 输出分辨率 | **1440×1920 竖幅** JPG | 保持一致；DA3 内部缩到 378×504 |

> 复算工具：`15_diag_worldframe.py` / `_diag_cam_range.py`（输入 bench_first_125v/cameras.npz）。

## 2. 人物资产（A 类：最难凑齐，决定 LoRA 上限）

| 项 | 规格 | 说明 |
|---|---|---|
| 数量 | **≥50 个不同身份**（可先 15~20 个高质量 scan 起步做可行性验证） | 少于 30 基本必然过拟合到少数脸 |
| 来源 | 商用授权扫描库（RenderPeople / AXYZ / Twindom）或 Sketchfab CC 授权高模 | 注意授权是否允许合成数据训练 |
| 网格 | ≥100k 面；封闭或近封闭；法向一致 | 训练信号是 2D 渲染图，网格不必极高模 |
| 纹理 | **4K PBR**：albedo / normal / roughness（皮肤次表面散射近似即可） | 皮肤质感是 domain gap 重灾区 |
| 头发 | 发丝卡片（hair cards）即可，必须带 alpha | 头发是前馈高斯最糊的部位，数据里不能糊弄 |
| 身材多样性 | 高矮胖瘦、不同年龄、男女都要有 | 只训标准身材会偏置 |
| 尺寸 | 真实尺度（身高 1.6~1.9 m），脚底 y=0 | DA3 是度量模型，尺度错了等于教错几何 |
| 姿态 | 每人 2~4 个静态姿态（站/坐/抬手等），绑 SMPL-X 骨骼批量摆 | 姿态多样性防止只学 T-pose/站姿 |
| 服装 | 不同颜色/款式；可同模换 albedo 扩增 | 廉价的身份扩增手段 |

## 3. Blender 场景与渲染（B 类）

| 项 | 规格 |
|---|---|
| Blender 版本 | 4.x，Cycles，GPU（CUDA/OptiX）渲染 |
| 灯光 | **≥10 种 HDRI 环境**（室内多/外若干，照度有层次）+ 可选 1~2 盏柔光区光补光；避免纯点光硬阴影和过曝死黑 |
| 背景 | **不要纯色/绿幕**；用 HDRI 环境或简单室内布景（墙/地板），人物占画面 30%~80% |
| 渲染设置 | 无运动模糊、无景深；采样 128~256；色彩管理 AgX 或 Standard（**全数据集统一**，且接近实拍直出色彩） |
| GT 深度 | Mist pass 或 Z pass → 16-bit PNG / EXR，单位米，逐帧输出 |
| 逐场景定义 | `人物 × 姿态 × 环境` = 一个 scene；同一个人换环境/姿态算不同 scene |

## 4. 输出数据包格式（C 类：与训练脚本对齐）

```
<dataset_root>/<scene_id>/
  images/0000.jpg ...        # 1440x1920, JPG q≥90, 命名与实拍一致（0000 起、与相机序对应）
  cameras.json               # 逐帧: {"0000": {"w2c": [4x4], "K": [3x3]}, ...}
                             # 约定: 世界系 y-up、右手；w2c 为相机外参（与 COLMAP 一致）
  depth/0000.png             # 16-bit, 米制（可选但强烈建议，深度损失用）
  meta.json                  # {"identity": "rp_anna", "pose": "A", "env": "studio_03", "n_views": 40}
```

- `cameras.json` 的 w2c/K 约定**直接照抄** `da3_human/EXPERIMENTS.md` 里 npz 的语义（w2c = R|t，
  世界 y-up），训练脚本直接复用 `12_eval_nvs_first.py` 的加载逻辑。
- 写 JSON 用 `encoding="utf-8", newline="\n"`（仓规，防 CRLF）。

## 5. 数量规划（D 类）

| 阶段 | 身份 | 姿态/人 | 环境 | scene 数 | 图数（40 视角/scene） | 用途 |
|---|---|---|---|---|---|---|
| 可行性验证 | 5 | 2 | 3 | 30 | 1,200 | 跑通训练循环 + 看验证集涨不涨 |
| v1 正式 | 20 | 3 | 6 | 360 | 14,400 | 训头阶段主力 |
| v2 扩容 | 50 | 3 | 10 | 1,500 | 60,000 | LoRA backbone 阶段 |

- 训练时**每步随机采 8~32 视角**/scene（覆盖官方 [2,18] 并外推到我们的推理 32）。
- **留出**至少 3 个身份 + 实拍 studio_human 125 视角作为验证集（场景级留出，防"记住脸"）。
- 主指标：NVS unseen 视角 PSNR / LPIPS，不用 in-sample。

## 6. 验收标准（渲完 1 个 scene 必做，半小时内可完成）

1. **几何自检**：随机抽 3 帧，用 `cameras.json` 的 K+w2c 把 `depth/*.png` 反投影成点云拼合，
   目视无分层/重影（验证 w2c/K 约定没写反）；
2. **管线自检**：该 scene 跑 `08_bench_official_gs.py`（N_VIEWS=32, REF_STRATEGY=first,
   EXPORT=max）+ `13_run_nvs_first.sh`，合成数据无噪声、位姿精确，
   **NVS PSNR 应 ≥27（实拍 COLMAP 3DGS 基线是 27.57）**——达不到说明渲染或相机导出有问题；
3. **domain gap 自检**：渲 1 张与实拍同构图的图，与实拍并排列出，肉眼比对材质/光照/色彩差距，
   差距大就调灯光和色彩管理，不要等训练完才发现。

## 7. 已知风险（按优先级）

1. **Domain gap**（渲染感）→ 用 HDRI 多样性 + 近似实拍的灯光布局 + 色彩管理统一缓解；
   保留一条退路：后期实拍精调（实拍数据训头、Blender 数据训 backbone）。
2. **身份数不足** → 宁可 20 个高质量 + 充分扩增，不要 100 个低质量。
3. **头发/眼镜/透明材质** → 数据里就 avoidance：扫描模型尽量无眼镜；头发必须带 alpha 卡片。
4. **y-up 手系约定写反** → 验收标准 1 就是防这个；w2c/K 照抄 npz 语义，勿凭直觉改（同 som_human 教训）。
