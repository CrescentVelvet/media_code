### N0：一次测量修复，作为几何分支裁决的前置门

交付独立版本的`geometry_audit_v2.json`，保留旧F3文件；不覆盖历史target_metrics.json。

1. **按manifest关联文件，禁止用ID猜文件名**：rosemary相机id20的RGB/深度分别为
   `000021.png/000021.exr`，旧20号读了`000020.exr`。3 source与2 target全部逐项校验。
   human_fbx_gt旧相机旋转修正与本错帧问题分开；新包用版本字段/显式开关防止再次C@R@C。
2. **刚体相机与尺度分开**：世界映射`X_model=s R X_pkg+t`，使用
   `R_cam_model=R R_cam_pkg`、`C_model=s R C_pkg+t`；渲染得到模型系轴向深度后除以s
   再比米制GT，或把高斯中心/尺度整体变回pkg系。旋转应det≈1、正交。
   CPU已验证本包cameras.json与此刚体链误差≤1.03e-7；旧`S@pkg`把尺度乘进旋转，det≈3.30，
   深度变成另一单位，不能据+441mm vs +6mm宣称cameras.json错误。渲染等价性另做对拍。
3. **GT深度类型单独验证**：生成器直接输出Blender Depth pass，不能仅凭注释称轴向Z。
   用已知平面/网格射线校验距离与轴向Z；若为射线距离D，按原始K使用
   `Z=D/||K^-1[u,v,1]||`，再按真实裁剪/缩放重采样。边界不把无效深度填0后双线性混入前景。
4. 原始米制误差、仅用source确定的**单一全局尺度**、逐视角GT拟合尺度的oracle残差分栏。
   不用target或逐视角独立缩放为正式几何验收去掉误差。脸均值之外报鼻尖/鼻翼/眼周p90、
   轮廓、表面法线/GT网格距离；合成脸均值2～4mm即使成立也不能排除鼻部错误。
5. F0的`10*mean(||delta||²)`与14号实际`10*mean(delta_xyz²)`差3倍；位移先保留模型单位。
   F1-B仍用未归一化位移正则，触顶只能说明约束活跃，不能证明刚性平移需求/放开必过拟合。

N0不重跑整套算法，只完成必要的坐标、文件与评分修复；数据整理与N1视觉登记可同步推进。

### 为什么先做局部，而不是整个人物回炉

- mask只提供对象范围/轮廓，不提供鼻梁深度或跨视角对应。抠掉背景再喂SA会改变上下文，
  第一轮保留完整RGB输入，用mask控制高斯归属、优化损失和验收。不要把mask误称几何修复。
- 当前主要坏在脸：默认只开放脸部/额头/颊部高置信高斯，身体、衣服、手、头发和场景冻结。
  人物mask作为外层保护；脸mask和发际/下颌/遮挡边界单列。整个人物优化仅在后续确有身体
  错误时考虑，避免新增衣服/头发伪影。E-19已经出现“指标涨、发尾白条、目视不通过”。
- 三图静态/曝光/对焦先检查；鼻部至少被两张source清楚观测才进入几何修复。若照片间存在
  表情/头动，不用调整全局相机硬拟合，也不对这组宣称静态几何可修。已有手部微动坏例可作
  压力测试，先补一个静态人物包验证实现。脸小到无有效像素时应改采集，不靠锐化造细节。
- 近期32视角2K实验是资源/发布权重边界，不是SA三图或高分辨率ROI监督无效的证据。
  第一轮不升SA骨干输入分辨率；用原图人脸patch提供监督，减少背景像素占比和渲染开销。

### P0：不改变模型，先把局部优化的输入与边界做对

1. 固定SA基线、3张source的ID/hash/K/c2w、预处理、merge参数、底色与渲染器。只从source
   获取人物mask、脸/头发分区与遮挡标注，低置信区域不参与几何更新；target只用于最终评分。
2. 将2D mask转为**3D高斯ID集合**：使用可见性/深度层与投影footprint贡献，多source确认。
   仅“中心投影落在脸框”会选到脸后背景；也不能要求所有三张都可见而删掉合法侧脸。
   首轮只更新至少两个有效视角支持的区域，其余保留冻结，展示所选高斯的各视图覆盖供审计。
3. 原始高斯集合拆为固定块与可训块，仍在同一个renderer中按深度共同合成。**不是**把独立
   渲染的人像RGB直接贴回背景（会破坏头发/手/玩偶/椅子的遮挡）。固定块参数用原值重组，
   不仅把梯度乘0，防止Adam历史动量/weight decay改变背景；逐步哈希核对固定参数不变。
4. ROI裁剪发生在**监督与渲染**，不是单独裁脸重新预测另一套SA相机/几何。按真实裁剪变换
   K'=A_crop_resize K，保留c2w与全场景遮挡；若实现tile culling，必须包含投影footprint
   穿入ROI的高斯。先验证ROI渲染与全图裁图一致，不把裁图坐标误差当重影。
5. 先过0步导入/导出/渲染恒等、固定块哈希、source/target隔离；同dtype RGB MAE≤1e-4
   作为起点容差，需实测声明。相机/曝光/网络权重不优化；已有相机错误先修独立标定。

### P1～P3：最小消融，逐项解释收益

全部从同一P0高斯独立初始化，用同mask/source、监督分辨率、损失、采样与预算，不沿用上一臂
已拟合结果。初跑各100步，记录0/100；链路正常且source诊断无崩坏时到300步，记录固定结果。
不依赖target挑学习率、步数或最佳checkpoint；无独立开发集时只报告预注册0/100/300步。

| 组 | 允许更新的脸部参数 | 要回答的问题 |
|---|---|---|
| P0 | 无 | 原生SA、局部选择与渲染等价性 |
| P1 外观 | DC颜色（保留其余SH不变） | 单靠贴图/颜色能否改善，几何严格不变 |
| P2 footprint/透明度 | DC + scale/quat/opacity；中心固定 | 是否主要是椭球覆盖、重叠透明度问题；不能称中心几何已修复 |
| P3 局部几何 | P2参数 + 受限中心位移 | 鼻部错层/对应能否通过三图证据修正 |

P3设置弱位移正则和可信邻域平滑，初始总位移限制为source估计头宽的5%（预注册起点，
非已调优值）；只在同一皮肤片区平滑，不跨鼻翼/眼睑/唇线/遮挡边缘。尺度范围、四元数归一化、
opacity有界检查；不要用大尺度糊平重影、清空opacity或强贴回错误SA深度来“改善”指标。
首轮固定点数，不densify/prune，不引入2DGS/新纹理表示。若误差已明显超过小位移可修范围，
记录此限制；P3失败不等于三图永远不可修，也不等于人物数据适配无效。

### 损失、几何约束与验收

- 三个source均参与：按每视角有效脸像素数归一化的RGB L1/SSIM，保留边界带与原场景约束。
  脸内部损失、发际/下颌边界、非脸区域分别计数，避免背景淹没小脸或单张正脸支配优化。
- ROI外加入相对P0渲染的保真约束。参数冻结不保证像素不变：脸部高斯移动后仍可能遮住
  原背景，必须查非脸区域、头发和遮挡边界。独立人物/脸mask用于验收，不能用优化后的alpha
  挑好像素。若使用轮廓loss，应监督**人物/脸的语义可见贡献**，不能拿全场景总alpha当人物mask。
- 光度不足以消除几何歧义。若有可靠多视角鼻尖/眼角/嘴角对应，用source相机三角化并做
  正深度/视差/重投影残差筛选后，作为**P3之后单独的几何约束消融**。轮廓点不是固定3D对应，
  动态/遮挡点不用；无可信对应时不强造约束。原SA深度只作弱锚定，不能作为错误鼻部的强GT。
- 验收至少含一个静态开发人物、再2个独立人物确认；每包3 source与至少2独立target。
  仅有三图的包只能报告拟合/定性轨道，不叫新视角验收。开发佳佳不当未见身份测试。
- 初步推进门：target脸LPIPS相对P0下降≥5%，人物PSNR不降超过0.2dB，无新增双边缘/白条/
  空洞；ROI外RGB变化和PSNR单报（建议PSNR下降不超过0.1dB，作为待验证起点）。鼻部对应、
  轮廓、深度分层与固定视频独立检查；没有GT几何时只说诊断改善，不承诺真实毫米精度。
- source loss降而target变差、鼻部变平、覆盖缩小、头发白条或scale爆炸均停止扩展，保存失败例。
  不先验承诺加密/删点一定能救。最多三臂×300步，不自动扩成2000/3000步精调。

### L1：固定改动范围，先训练学生侧 LoRA

“不改网络”指保留原3DGS表示、depth lift、GSNorm、属性头结构、merge/过滤及渲染算法；
只为现有线性层加入低秩更新 W'=W+(alpha/r)BA，可在验证后合并回原权重，禁改原始权重文件。
[LoRA 原论文](https://arxiv.org/abs/2106.09685)提供低秩更新方法，不提供本任务收益保证。

| 模块 | 第一轮 S-LoRA | 能与不能回答什么 |
|---|---|---|
| GeometryWorldMirror 教师及 camera/depth heads | 完全冻结，eval，无梯度 | 固定原深度/相机，不能宣称修好了教师鼻部深度 |
| GaussianWorldMirror 学生 encoder | 原参数冻结，仅 attention LoRA 可训 | 调整人像特征如何驱动高斯属性 |
| GSFeatHead / decoder 的原权重 | 冻结；首轮不混加全头训练 | scale/quat/DC/merge weight 输出仍会因输入特征变化而改变 |
| 原始反投影 centers | 相同source时应与基线一致 | 学生LoRA不能移动原始中心；merge权重/过滤变化可能移动或筛掉最终中心 |
| 表示/分辨率/相机模式/merge/渲染 | 与基线相同 | 不把体素、分辨率、底色变化混作数据收益 |

源码核查（SA本机 `663c540`）：`visual_geometry_transformer.frame_blocks/global_blocks` 中
attention 有 fused `qkv: Linear(d,3d)` 和 `proj: Linear(d,d)`。第一轮建议各序列最后6个 block
的 qkv/proj，全 QKV 低秩更新，r=8、alpha=8、dropout=0、lr=3e-5、grad_clip=1；这是
预注册起点，不是已调优参数。实现时输出实际模块全名/数量/形状/可训练参数，匹配0层必须报错，
不得把教师同名层一起注入。不能误把fused qkv当成独立q_proj/v_proj。

学生不能仍包在 no_grad/inference_mode 中；仅教师可缓存，训练中的学生特征不可缓存。
零增量初始化时与原前向对拍；一次更新验证 LoRA 参数变化、原权重/教师哈希不变、梯度有限。
记录raw center和合并后center分别变化多少，不能把“教师冻结”写成“全部高斯几何冻结”。

### L2：人物资产、渲染与数据划分（先登记再训练）

   几何。生成 `assets_manifest.json`；目前尚未确认资产清单，不能把设计数量写为已有数据。
   正面纹理好但侧脸网格粗糙的资产，不能作为鼻部几何真值。
2. 建议最小试验起点：30个训练身份 + 5个验证身份 + 10个测试身份；不足时按身份近似
   70/15/15分组并报告数量，仅作探索。换衣、表情、姿态、同一底模变体按家族分组，禁止泄漏。
   渲染千张同一个人不等于千个独立训练样本。最终测试身份只在配置锁定后使用。
3. 复用 `24_ue_render_spec.md` A/C轨迹：每样本3张不同机位source + 至少2张独立target。
   第一档保留 s03/s06/s09，之后在训练身份随机化角距/俯仰/人物距离，匹配真实三图分布。

4. 保存RGB、像素K、c2w/w2c约定、axial Z深度、法线、人物/脸/手mask与实例ID。GT深度/
   normal只用于监督或oracle诊断，不能喂进RGB-only正式模型。用投影闭环验证坐标、畸变、
   alpha合成、色彩空间与裁剪；透明背景不能成为唯一训练背景。
5. 高质量源图可以高分辨率渲染，但首轮模型输入与原基线保持504；统计预处理后脸/鼻像素数。
   同时覆盖全身与中近景，不偷偷只做大脸裁剪并与全身基线比较。完整高分辨率输入属后续消融。

   不能再算未见测试。额外保留通用物体/场景集检查遗忘。

### L3：最小对照与有限预算

| 版本 | 数据与更新 | 判读用途 |
|---|---|---|
| L-B0 | 官方原始权重，无LoRA | 配对基线；同配置重复推理排除随机/导出偏差 |
| L-Z | 相同模型插入零增量LoRA或禁用adapter | 工程恒等对照，不需要域训练 |
| L-H | 高质量人物数据，S-LoRA | 首要试验：原架构能否通过人物域适配变好 |
| L-G | 通用数据，完全同LoRA模块/步数/损失/分辨率 | 区分人物数据贡献与单纯继续训练收益；尽量匹配视角/像素/场景规模 |
| L-GEO（条件项） | 人物数据，只更新几何教师LoRA，学生冻结 | 仅学生试验后仍有直接原始深度错误证据时再设计，不与L-H首轮混训 |

L-H / L-G 从相同官方权重独立初始化，不能沿用未经验证的250k长训checkpoint。首轮不做
数据混合/ROI加权/高分辨率/多rank全扫；L-H与L-G用相同RGB L1+0.2(1−SSIM)，按可见
有效像素规范化，保留全图/人物/脸的独立评分。人脸加权、GT几何损失和普通属性头微调可作
后续独立消融，不混进“只换数据”的对照。没有L-G时允许先做L-H，但结论限于域适配可行。

训练source严格只有3图；target不得进入任何encoder、特征缓存、纹理采样、相机联合预测。
RGB模式先从source相机与GT source相机估计唯一全局Sim(3)，仅转换target相机到模型坐标，
报告残差；不得按target拟合。退化/不可靠对齐先隔离排错；另以可信UE pose做受控实验时，
基线与训练模型均使用同一pose track，不能把它的成绩标为RGB-only。

预算分级：

- **工程门：≤100 step**。零增量前向RGB/alpha MAE≤1e-4（同dtype/配置）、梯度有限且
  adapter更新、teacher/raw center保持、存恢复通过；未满足就停。预热后测单进程峰值与稳态
  step/s，连同预处理/验证开销估算试验总成本。E-15 的0.51s/step不能外推到encoder LoRA。
- **域适配小试：每臂最多2000个optimizer step**，有效batch=1个scene tuple起步，累积规则
  固定。250/500/1000/2000步仅在验证集选checkpoint，初跑seed=0；正向信号再加seed=1、2。
  不自动续成250k。连续两次验证脸LPIPS相对B0恶化>10%、PSNR下降>0.5dB、或NaN/scale
  爆炸/发尾白条新artifact，停该臂诊断，不以延长训练解决。
- rank8稳定但无效时只加一个rank16或更大层范围的容量诊断（择一），明确它不再是同容量
  数据对照；仍无效返回L-GEO/监督/资产域差异诊断，不立刻宣布应换2DGS。

### L4：验收、结论边界与交付

**画质与几何分开验收**：固定target的人物/脸LPIPS、PSNR/SSIM，鼻宽/对应误差/轮廓、
raw depth与最终表面层间偏移、头发白条/空洞；原分辨率裁图及匿名A/B视频一起交付。
E-19已表明b/a签名可能漏判重影，不能只凭该分数改好就宣称消除双鼻。

首轮“值得扩展”信号：相对B0，未见身份脸LPIPS中位相对下降≥5%、人物PSNR不降超过0.2dB，
且无新增明显artifact/覆盖退化；只作探索。正式晋级仍沿用原附录人物LPIPS降≥10%、PSNR增≥1dB
及几何/覆盖/资源守门；按身份聚合CI，样本不足或CI跨0即结论暂定，不把多帧当独立身份。
物体/通用集LPIPS相对退化>5%或PSNR下降>0.3dB时，不能宣称无损通用提升，可另评人像专用adapter。

### 已有实验改变了什么

- `05`双重外参变换修正后，从三份`fair_compare.json`按有向图像对去重，共16对、6张图、
  **同一人物采集包**。SHARP−identity中位 **+3.62dB，16/16正**；SHARP−planeH中位
  **+2.11dB，14/16正**。旧+3.73是汇总错误；不能把16对当16个独立场景。
- SHARP跨视角PSNR与SA/SHARP自渲PSNR不可直接比较；11～17dB不能单独证明“精度不够用”。
  `alpha>0.5`只评预测覆盖区、planeH逐target选d、最近邻边界clamp及掩码量化仍有偏差；
  相反方向的偏差不自动相互抵消。当前只支持该评测下的重投影收益，不是纯几何误差分解。
- SH0.5在一个样例的源视图中，full明显优于删一层；不删除第二层。亚像素错位是观察，
  “普遍同表面低通”仍是机制假设；**0.746px不是去重阈值**，也未证明一切压缩都不可行。
- k≈0.9在部分view pair上得分较高，是target指导的尺度敏感性诊断；不是可部署校准，
  不能据此定性为模型固定10%偏大，也不能给完整Sim(3)设置+0.6dB收益上限。

### SH1b：先把“是否值得融合”测清楚

**第一步：冻结结果口径。** 由WorkBuddy固化已修正05/06版本，记录脚本/权重/输入hash，
新目录保存，勿覆盖旧run。修复点先过以下检查，未过不重跑全矩阵：

1. 同一高斯、同一K对拍两条合法路径：原A相机系高斯+T_BA外参，或将高斯完整变换到B系+
   单位外参。均值和协方差都变换；RGB/alpha/depth有效区一致（先声明dtype容差，例如RGB
   MAE≤1e-4），再测A→A恒等。原始单图高斯在A相机系，不能在注释里当世界系。
2. 读取uint8只归一化一次，断言dtype/shape/范围；不能仅用max>1.5拒绝合法暗图。
   K保存fx、fy、cx、cy及裁剪/resize；05目前反投影把fy设为fx，不能称完整真实K接入。
   prior来自采集转换记录，完成来源/重投影检查前不称无误差GT。
3. 保存float RGB/alpha，再在同一固定mask重算三方指标；不复用05的float掩码分数去对比06
   由8bit alpha重建的掩码。planeH用双线性+有效采样域，报告越界覆盖，禁clamp拉边；平面
   法向位于source相机系。逐target选d的版本只标oracle诊断，不能进入前馈主表。
4. Q2输出是alpha归一化的期望深度，不是最前表面；双侧alpha非零不等于同一物理表面。
   先加遮挡/循环一致性筛选，再记录ROI残差；无GT几何只能谈一致性，不谈真实毫米精度。

**第二步：固定最小评测包，不扩大扫描。** 从佳佳现有修正小/大基线各取一个开发三图包，
另外至少3个静态人物身份+1个物体（数量是计划，资产可用性待盘点）。每包严格3个source，
另选2～4个独立target。佳佳含手部微动，人物姿态/表情/曝光差异单列；不同子集不算新身份。
不按target效果选source、相机变换、尺度或checkpoint；只有三图的包不能算三图重建留出评测。

配对两档：可信合成K/pose的控制组，以及RGB-only自估的实用组，二者不混排。实用组
SHARP的外参若来自SA，明确依赖；唯一全局对齐仅用source，target只评分。SA给定pose链
尚未通过可信相机检查时，先标缺失对照，不用有问题的pose结果替代RGB基线。

对照包括SA三图、三份SHARP单图（source按预注册规则选主图，并报全部单图范围），以及
source原图投影。单图/三图输入差异、原生分辨率/点数/成本明确列出；再加同source像素
信息量控制，不能把SHARP内部1536与SA504差异全归因为表示。还未融合时不称SHARP三图模型。

**验收用真实target：** 人物/脸LPIPS、PSNR/SSIM、轮廓与双边缘、覆盖率、掩码外泄漏。
主分母为独立标注/固定的人物与脸mask；固定共同可见区是附表，另外完整报告不可见区，
不通过裁掉难像素提高分数。锐度/高频能量只作辅助，噪声和重影也会使它们变高。
SH1c所有细节必须来自3个source，target RGB不能参与回填；必须优于“直接投影原始RGB”
才能说明额外跑SHARP有价值，不能预设SHARP必然比原照片包含更多有效细节。

预注册探索门：至少两个新增人物的脸LPIPS相对基线下降≥5%，人物PSNR不降超过0.2dB，
双鼻/轮廓/覆盖不恶化；报告逐身份及失败例，不把同人多帧当独立样本。通过才进入SH2，
未通过则保留诊断结论、回到人物LoRA，不连续追加角度/尺度扫描。这里没有绝对20dB通关线。

- 8/13v 只作为同场景额外观测参考；已有输出可保留，不继续完成旧 72-run 大矩阵，也不因
  `object` 的 3v>8v 未定位而阻塞人像三图实验。更多输入不是严格质量上界，教师用途也须另验。

#### R2：先利用已有几何，再验证高分辨率外观的增益

**研发假设：SplatAnything 已提供更好的起点，剩余收益可能主要在人脸/手部纹理和跨视角融合；
不是“几何已完美”的结论。** 先在 3v held-out 看轮廓、对应点重投影、可见深度（UE 有 GT），
记录脸手占原图/504 输入的像素数、各源视角可见性、投影错位与高斯 footprint。
固定全局尺度；只在同表面/同尺度比较深度，mask/GT 仅用于训练监督与评测。

后续域训练对照（R3/T2 成功后排期；每个实验仍用三张原始 source）：

| 对照 | 只新增什么 | 需要回答什么 |
|---|---|---|
| A0 | 官方 SplatAnything，零微调 | 真正的改进前基线 |
| A1 / T1 | 冻结 geometry/encoder/centers，仅普通分辨率属性头域训练 | 仅域适配能获得多少收益 |
| A2 / T2 | A1 + 原始 RGB 的高分辨率外观分支（4×像素，即两边各2×） | 收益是否来自更多真实纹理信息；不扩大完整几何 Transformer |
| A3 / T3 | A2 + Face ROI；手部作为单独 A3-hand 消融 | ROI 相对普通高分辨率分支的独立收益 |
| A4 / T4 | 有直接几何错误证据时才加受约束 depth/geometry 修正 | 联合训练是否超过冻结几何，及其成本 |

在 A1～A3 中记录冻结的是中心还是全部几何属性：首轮 WB-4 允许训练原有 scale/rotation，
因此不能把其结果称为“全部几何冻结”。正式外观归因至少加一条 center/scale/rotation/opacity/
合并拓扑全部锁定、只改颜色/外观的对照；与原属性头训练分表，防止收益来自覆盖变化。
高分辨率特征来自同三张 source 原图，经过正确 K/crop 与遮挡可见性采样；不使用 held-out
RGB 作纹理，不引入第四图，不把超分/生成补纹当真实恢复。Face ROI 与手部 ROI 不一次合并。

停止条件：A1 无效先查等价前向/数据与监督；A2 无效且几何投影正确时再查像素预算/融合，
不直接解冻几何。任一变体只改善训练视角或靠放大高斯掩盖错位即不晋级。
人物/脸 held-out 改善必须同时满足附录几何/覆盖容差和资源预算；没有直接 GT 的几何结论标暂定。
13v 只能在训练身份上作为经 GT 验证的可选教师，不作为默认前置；测试身份及 target RGB 不入教师。

#### R2-N：鼻子变宽/疑似重影专项（用户新增现象，优先于域训练）

**现象来源**：用户反馈 SplatAnything 物体好、人物鼻子变宽，疑似重影。尚未取得该鼻部坏例的
逐视角定量证据，不能把“宽”直接记为“双层几何”，也不能预先认定人物训练数据太少。
本地论文笔记 `C:/code/media_paper/3D-20261112-SplatAnything.html` §10/§14 的数据列表
提示人像专门覆盖值得核查，但没有人脸数量、分辨率、姿态分布统计；它支持域差异假设，不能证明病因。

先定位用户查看的实际输出、source 帧数/模式/分辨率和渲染相机；若原坏例不是三图，保留原例
诊断并另建三图复现，不将多图问题直接算入三图失败率。选原坏例 + 另一独立人像 + 一个正常
人像作对照；缺样本时先做现有包并标局限。物体只作链路控制，不能证明人像相机一定正确。

| 假设 | 有区分度的检查/对照 | 什么结果才支持它 |
|---|---|---|
| N0 输入/相机不一致 | 核对三图头姿/表情变化、时间与滚动快门迹象；审计 EXIF 旋转、畸变、K/crop；pose track 检查鼻尖/眼角等可见对应点 | 若真实像素对应在给定相机下已明显不一致，先排标定/非刚体运动，不先训网络 |
| N1 相机估计误差 | 同三图 RGB-only vs 可信 pose；另用静态 UE 三图 GT K/T 作控制；预测相机与给定相机各自先验收坐标转换 | pose 修正同时降低对应点误差和鼻部重影，支持相机贡献；VIO pose 仍非真值，失败不能排除它 |
| N2 深度/跨视角中心不一致 | 同次前向缓存 raw depth、合并前 splats 的 source ID；统一尺度/参考系，按可见同表面对应比较鼻部层间偏移 | raw depth/中心已不一致且可信相机不能解释，支持几何先验；不同脸侧/遮挡点不能强行对应 |
| N3 合并或 footprint 问题 | 同次预测比较合并前各来源层、未合并全集、官方合并结果；检查 nose ROI 的 voxel/spacing 和投影椭圆；必要时只加一个预注册减半 voxel 对照 | 来源层本来对齐、合并后才变宽，支持融合贡献；中心一致但 footprint 过大支持尺度贡献 |
| N4 人像域/像素预算不足 | 检查输入与 504 预处理的脸/鼻像素，几何审计通过后比较 A1 域适配与 A2 真实高分辨率外观 | 未见身份上改善且几何/覆盖守门通过才支持所选改造；训练集拟合改善不证明人像数据不足 |

N0/N1 不得用 target RGB 做位姿拟合或加入产品测试时优化。若为诊断使用额外标定/GT 信息，
标 `oracle_diagnostic`，不计入仅 RGB 产品性能。若输入有人物动作，先用静态控制分离病因。
鼻部 landmarks 三角化采用多点、重投影残差和不确定性核查；不能只用几乎共面脸点的单一解判相机真值。

N2/N3 可扩展已有 `06_ply_roundtrip.py` 的 merge hook，但当前 hook 只存合并统计，
**尚未保存完整合并前属性与 source ID**，需新增显式产物。源码中“体素内 RMS/voxel 就是跨视角
几何不一致”不可直接作为判据：同表面采样间距和曲率也会产生 RMS，必须保留来源及对应关系。
各来源单层渲染只是同次三图预测的分层诊断，不是重新做单图推理。未合并全集会改变点数/opacity
累积，须同时报告覆盖和深度；未合并更清楚本身不证明 merge 有错，不开启无限体素/scale 扫参。

产物与鼻部判据：

- `nose_case_manifest.json`：来源、三帧/原例 ID、相机模式、主体运动标签、参考系/尺度、鼻脸
  ROI 版本；`nose_diagnosis.csv`：每个目标视角的量测，不只留最佳图。
- `nose_contact_sheet.png`：原始 RGB、预处理输入、GT/render 鼻部同像素裁图、alpha/depth、
  source 分层投影；固定正面/左右斜视角，至少包含未输入的目标。放大只供看，不改变评分像素。
- 鼻翼宽度误差先在同 target 相机、独立 GT/render 鼻翼标注中量测，归一化为同视角眼间距
  （严重侧脸/遮挡标 N/A）；不得单独 warp/缩放预测脸来消除几何误差。自动关键点需人工复核，
  同时保留像素误差、鼻部轮廓和 held-out PSNR/LPIPS，不能只优化一个“鼻宽”数字。
- 重影需用分层来源/对应中心偏移及深度剖面支撑；只有期望深度图可能把两层平均成一层，
  需来源层深度或射线附近带权中心分布。不因鼻梁本身曲面/前后遮挡出现双峰就判重复表面。
- 诊断晋级信号预注册为：鼻宽绝对误差或对应点误差相对降低≥20%，且超过重复标注误差，
  在至少两个独立坏例的相同 held-out 上方向一致；正常控制不突破附录守门。小样本只定下一步，
  不称普遍有效。无重复表面证据则写“宽化/模糊，重影未证实”。

判读后只开一条主改造：N0/N1 → 修输入/相机链；N2 → 受约束几何小适配器；
N3 → 局部可见性融合/属性尺度；N4 → A1 人像域适配再 A2/A3 外观。
混合病因按可归因最小改动逐项处理，不一次同时改相机、几何和纹理。R3 成本探测可并行准备，
但鼻部问题归因前不承诺“只训外观即可修好”，也不因此立即重训 WorldMirror 或 DA3。

### WB-3：DA3 是几何先验错，还是高斯头 offset 错

- 从同次 DA3 前向缓存 raw depth、预测/输入 K/T、raw GS 与正式 Gaussians，冻结其它条件；
  跑附录 C0 原生、C1 xy=0、C2 depth offset=0、C3 两者=0、C4 仅换 means 保留原属性。
  **不要改输出通道布局，不要把 Nested 已缩放 depth 和未缩放高斯混在一起。**
- 先原坏例，再至少另 2 个独立静态包；以可见对应区域评重投影/轮廓/held-out，
  不能用整层非对角 PSNR 或自然遮挡造成的出框率判几何必错。
- UE 到位后，比较原生 depth 反投影与 GT；加 GT-center oracle 只诊断，不能参与正式模型排名。
  GT radial depth 先转 axial Z。scale/rotation 与新中心可能不匹配，因此 oracle 无改善
  不能单独否定几何病因；同时看直接点/深度/重投影误差。
- 判读：C3/C4 改善 + 原生 depth 几何可靠 → 优先固定中心属性头，**不重训几何骨干**；
  原生 depth 在有效对应上也明显错误 + GT-center/直接几何证据支持 → 几何修正候选；
  几何修正先训 depth head/小适配器，只有容量验证失败才考虑解冻 backbone。
  两边都错则记混合病因；offset 清零没用不等于已证明需要重训 backbone。
- 初始因果信号门槛：相对 C0，C3/C4 人物重投影中位误差降≥20%，且 held-out PSNR
  增≥0.5dB 或 LPIPS 降≥5%，同时覆盖/脸不突破附录守门。这是“值得试固定中心训练”的门槛，
  不是一般几何真值判据；没有 GT 时结论必须标暂定。
- 产物：`center_ablation.csv`、逐像素 offset/center 位移统计、可见性 mask、原生/GT 深度误差、
  三类结论之一：`固定中心优先 / 几何修正候选 / 证据不足`，附反证和结论适用数据范围。

## 1. 目标、边界与当前判断

### 1.1 目标

在保持前馈推理速度的前提下，改善不同机位的 **3 张**人物图像生成的 3D Gaussian（8/13v 仅参考）：

1. 远离参考视角时几何不出框、不漂移；
2. 颜色和饱和度跨视角稳定，减少灰化；
3. 降低尺度过大造成的模糊，并保留人脸细节；
4. 控制高斯数量和渲染延迟。

### 1.2 已冻结的边界

| 项 | 当前口径 |
|---|---|
| 推理链路 | SplatAnything 前馈推理 → 高斯导出 → 直接渲染；DA3 保留配对基线 |
| 不纳入目标链路 | per-scene 2DGS/3DGS 优化、InfiniSplat 短训、测试时位姿优化 |
| 导出 | DA3 **不裁剪 + 全 SH**；SplatAnything 原生 DC/合并，分别验收往返 |
| 参考视角 | 固定 `REF_STRATEGY`；跨运行比较不得让参考帧自动变化 |
| 分辨率 | 训练、相机、渲染必须使用同一 `PROCESS_RES`；当前官方口径为 504 |
| 评测 | 仅有三图无目标帧时只评 self；多帧真实包抽三图、其余留出，以及 UE held-out 可评 NVS |
| 区域指标 | 人脸框逐视角确定；固定框和全图 PSNR不能单独作为结论 |

### 1.3 当前病因判断（D1 已闭环）

- **白洞**：导出裁剪造成，已由 D2 零成本修复。
- **人物出框、模糊**：前馈高斯中心/尺度在跨视角时不一致；替换 GT 位姿几乎不改变 v1/v2 结果，不能继续把问题归因给相机位姿。
- **人物发灰**：人物前景 alpha 中位数为 0.96～0.99，问题不是前景覆盖不足，而是远离参考视角时外观/颜色预测失效；v2 饱和度相对 GT 下降约 71%，全 SH 也救不回。

以上是 DA3 的历史诊断，不能外推为 SplatAnything 必须重训几何。
**2026-11-12 最新判断**：研究主线转为 SplatAnything 三图人像，先做 R0～R3；DA3 重训暂缓。
已有用户观感和 SplatAnything 链路/held-out 读数，正式配对质量验收与训练成本仍未完成。

## 2. 评测协议

每个实验都要同时报告下面四组结果，禁止只报一个全图 PSNR：

| 组别 | 指标 | 用途 |
|---|---|---|
| 图像质量 | PSNR、SSIM、LPIPS、Laplacian 锐度、分频能量比 | 颜色和清晰度 |
| 人物/人脸 | 逐视角 mask 内 PSNR、锐度比、饱和度差 | 人像质量；框必须随视角重定 |
| 几何/覆盖 | 深度误差、Chamfer/F-score（有 GT 时）、alpha 空洞率、自由空间泄漏率 | 出框、白洞、漂浮点 |
| 泛化/效率 | 按输入视角数和视角距离分桶的 held-out 指标、高斯数、显存、前向/渲染时间 | 是否值得进入主线 |

仅在输入三图上评分表示自洽，不能写成 NVS；真实多帧包只取三图输入、其余独立留出也可评 NVS。真实与 UE 均固定输入、参考帧和 held-out 相机，按身份/场景汇总。

每次重建至少保存：实际输入 RGB/深度、人物 mask、alpha、Gaussian centers 及投影、opacity 分布、scale/rotation 的像素当量、RGB-GT 并排图、相机和视角覆盖审计。坐标约定、尺度因子和视角索引先用 `ERRATA.md` 的清单验收。

### Phase 0 数据登记

真实 Remy 包的原始序列、抽帧和角度必须单独记录：原始帧数、实际输入帧号、每帧相机中心/姿态、方位角和相机夹角。当前三视角样例不是均匀环：输入帧为 `[0,40,81]`，实际方位角约为 `-176.2°/+12.8°/+112.2°`，间距约 `189°/99.4°`。任何报告都不得把这三帧写成“均匀三视角”。

模型处理分辨率和评测分辨率分开登记：DA3 当前 `process_res=504`；不同方法最终统一到同一评测尺寸，GT、预测图、mask 和相机内参使用同一 resize/crop 变换。指标表中还要保留 Normal Error、Reprojection Error、Silhouette IoU、Boundary Error 和性能项，不能只留 RGB 指标。

D3 的问题定义是：**前馈网络是否能直接生成可渲染的正确 Gaussian Geometry**。Depth 正确不等于 Gaussian Geometry 正确；验收对象必须同时包含 center、scale、rotation、可见性/置信度和 Novel View 渲染结果。先做可归因的最小基线，再逐项增加能力：

|---|---|---|
| G0 / D3-0 | 复刻官方冻结 backbone + Gaussian head 训练口径 | 确认训练/导出/渲染链没有新偏差 |
| G1 | 先固定可靠 depth 反投影中心；S2 证明先验不足时，才用几何监督训练受约束 center/depth 修正；属性分支不自由移动中心 | 解决出框和跨视角漂移，避免光度损失驱动中心偏离表面 |
| G2 | 与现有前馈几何方法做同输入、同渲染器适配对照 | 判断应继续训练 DA3 还是采用外部几何路线 |
| D3-A | 外观一致性监督：可见性加权的跨视角颜色/渲染损失 | 解决远离参考视角的灰化和饱和度衰减 |
| D3-F | 几何融合/去重和置信度阈值 | 在质量不降的前提下把高斯数压到约 25 万以内 |
| D3-C | G1 + D3-A + D3-F | 只在单项消融成立后合并 |

Phase 2 不以 Depth Error 单独验收。每个几何实验至少保存并报告：

- **Center**：对应表面点的 3D 位置误差、跨视角重投影误差和人物轮廓边界误差；
- **Scale**：3D scale 与屏幕 2D footprint 的分布，尤其是脸、头发、脚和轮廓区域；
- **Rotation**：局部表面方向/法向与 Gaussian rotation 的一致性；
- **Visibility/Confidence**：遮挡区域是否被错误融合，自由空间泄漏和重复 Gaussian 是否增加；
- **可渲染结果**：输入视角、插值视角和大角度 held-out Novel View 的 RGB、alpha、锐度和 LPIPS。

Depth、Normal 和 Point 监督用于解释几何误差，最终模型选择以 Gaussian Geometry + Novel View 表现为准。只有 Depth 下降同时带来重投影、轮廓和 Novel View 改善，才算几何有效。

Phase 2 保留两条候选路线，必须在同一输入、相机、导出和渲染器下比较：

| 路线 | 做法 | 适用条件 |
|---|---|---|
| G1-A 外部几何适配 | 接入已有前馈几何方法，只替换 Geometry 输出，外观头和渲染口径保持一致 | 外部方法能直接降低 center/轮廓/Novel View 几何误差 |
| G1-B DA3 Geometry Head | 冻结 backbone，训练 DA3 Geometry Head 输出 center/scale/rotation/confidence；必要时再逐层解冻 | 外部方法兼容性或数据适应性不足 |

Geometry 训练损失可按 `L_geo = λ_depth L_depth + λ_point L_point + λ_normal L_normal + λ_sil L_silhouette + λ_mv L_multiview + λ_scale L_scale` 逐项加入。多视角损失必须带 visibility/occlusion gating；不可见区域和错误遮挡不能作为硬监督。若路线 A 作为 teacher，也必须用 GT 和 held-out Novel View 检查误差没有被蒸馏继承。

当前训练分布固定三图，并覆盖不同角距、遮挡和人物像素尺度；8/13/18/32v 不再是必做桶。
几何修正分支若启动，至少含独立目标相机渲染、深度/轮廓及可见性约束；这里的训练目标
只来自训练身份，不能使用最终测试 target。先不靠复杂感知损失掩盖直接几何错误。

D3 的实验矩阵固定同一场景、输入帧、参考策略、导出和渲染口径，每次只改一个子实验。
历史 per-scene 结果仅作参考；Phase 3 可以直接使用通过几何审计的原生 SplatAnything，
不要求先训练新的 DA3 Geometry Head。

### Phase 3 / D4：冻结几何的纹理与人脸对照

Phase 3 必须保留冻结几何对照。以下四组共享经审计的 Geometry（可直接为原生 SplatAnything），
输入、相机、导出和评测固定。具体冻结范围及 4×像素定义以 §0.0 R2 为准。

| 版本 | 几何 | 外观分支 | 能回答的问题 |
|---|---|---|---|
| T1 | 冻结 | 普通分辨率 Appearance | 纹理解耦的最低基线 |
| T2 | 冻结 | 4× Appearance | 高分辨率纹理头本身带来多少收益 |
| T3 | 冻结 | 4× Appearance + Face ROI | 人脸局部分支的独立收益 |
| T4 | 受约束联合微调 | 4× Appearance + Face ROI | 几何联合微调相对冻结几何的增益/代价 |

T1→T2→T3 每次只增加一项；T4 最后运行，并限制 Geometry Head 学习率、center 偏移范围和可修改区域。禁止用 T4 直接替代 T1～T3。

Phase 3 的外观指标包括人物/人脸 ROI PSNR、LPIPS、锐度、分频能量、饱和度差、跨视角颜色方差和 alpha 泄漏。只有当 T2/T3 在几何指标不恶化的前提下改善外观，才保留高分辨率或 Face ROI 分支；已有未重训的 504→1008 负收益不能直接外推为 T2 结论。

分支只处理人脸局部高分辨率外观特征，不把“全局输入放大”当作方案；监督使用 UE 人脸 mask/关键点，验收仍用逐视角人脸框、锐度和分频指标。

实现上，T2/T3 使用独立的高分辨率 Appearance Encoder（轻量 CNN/FPN 或局部特征），不要简单插值 DA3 低分辨率特征，也不要在 4× 像素数上复制完整全局 Transformer。每个 Gaussian center 投影到输入视角后，只从可见且未遮挡的位置采样特征，再做多视角融合；曝光/颜色校正和 Face ROI 特征必须受 visibility 约束，不能用无约束纹理融合掩盖几何错位。

### 总体对照矩阵

| 版本 | 改动 | 作用 |
|---|---|---|
| B0 | 官方 DA3、历史导出 | 原始参考，不作为最终交付口径 |
| B1 | E1/E2 导出和颜色管线修复 | 排除实现问题，形成 `DA3-Baseline-V1` |
| B2 | 一次性 E3/E4 几何审计 | 区分 scale footprint 与 center/遮挡问题 |
| G1 | 外部 Geometry 适配或 DA3 Geometry Head | 验证 Geometry-First 路线 |
| T1 | 冻结 Geometry + 普通 Appearance | 纹理解耦基线 |
| T2 | 冻结 Geometry + 4× Appearance | 测量高分辨率纹理独立收益 |
| T3 | 冻结 Geometry + 4× Appearance + Face ROI | 测量人脸分支独立收益 |
| T4 | 受约束联合 Geometry/Appearance 微调 | 测量联合微调增益与代价 |

B0/B1/B2/G1/T1～T4 必须共享输入帧、参考策略、评测相机、导出和渲染器。T4 不得跳过 T1～T3，否则无法回答“收益来自纹理还是几何”。

### D5：鲁棒性与多场景验收（D3/D4 后）

在至少多个 UE 场景和一批真实 Remy 包上复测，按视角数、视角弧缺口、人物尺度和背景复杂度分桶。D5 只回答“改进是否可复现”，不再通过单个困难包继续改模型。

## 4. 预注册的停止与晋级条件

- 导出参数改动若不能在同一次前向的 2×2 对照中独立归因，停止继续扩展。
- 几何改动若只提高参考视角、却使远视角或 held-out 下降，判为失败。
- 外观改动若提高 LPIPS 但降低锐度/饱和度或增加 alpha 泄漏，判为失败。
- D3 只有在非参考视角的 PSNR、锐度和饱和度衰减同时收窄，且高斯数/延迟没有失控时，才进入 D3-C。
- D4 以当前基座的几何审计为前置，不以 DA3 重训完成为前置；全局改善而人脸不改善时，不继续堆 SH 或全局分辨率。

## 5. 已终止路线与历史资料

旧的 per-scene DA3+2DGS 方案曾测试 anchor、2DGS、offset 和 detach。C-06 的结论是：opacity 冻结和 detach 是真实 bug，但关闭 densify、固定点数和缺少可增长容量才是无法追上 3DGS 的主要原因；该路线不再作为当前目标。相关数字保留在 `EXPERIMENTS.md`，避免与 D3 前馈重训混淆。
