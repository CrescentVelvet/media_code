# 三视角 DA3-GS 前馈直出：实验规划与方案评审

> 建立：2026-11-11（初版误置于 compare_4methods/，同日移入）。归属：**da3_human  
> 前馈直出优化线**。引用的实测数字全部来自 `compare_4methods/` 台账  
> （FINDINGS.md / P0_EXPERIMENTS.md / IMPROVEMENTS.md / ERRATA.md）。
>
> 背景：峰哥跑了 3 视角输入的 DA3-GS vs InfiniSplat v2 批量对比  
> （`~/output/batch_4methods/`，3v 日志 + eval_3view_jiajia.json + orbit_video_3view 五宫格），观察：DA3-GS 整体偏灰、模糊、  
> 人脸细节丢失、背景大面积白色空洞；InfiniSplat v2 颜色正常、模糊较少，但头脚重影、  
> 人脸细节不足、背景仍有部分白洞。用 GPT 生成了一份四主线归因实验方案，  
> 本文档 = 原方案摘要 + 修订后的实验规划 + 冲突核查附录。**后续三视角实验按 §3 规划表执行。**

## 1. 每次重建必须保存的中间产物（采纳 GPT 方案 2.2 节）

> 这是归因的基础设施：没有这些产物，"灰/糊/白洞"只能靠猜。  
> 建议格式：npz（原始张量）+ PNG（可视化），随每次重建落盘到 results 目录。

| # | 产物                                 | 排查什么问题                                       |
| - | ---------------------------------- | -------------------------------------------- |
| 1 | 输入 RGB / Depth（模型实际看到的分辨率）         | 灰 → 输入侧归一化/色彩问题；深度无效区是否对应空洞                  |
| 2 | Foreground / 人物 mask               | 分离人物区与背景区指标（mask 由 SAM3 或 GT 提供）             |
| 3 | **Alpha / Accumulation 渲染图**       | **白洞第一判据**：空洞处 α≈0 = 覆盖不足；α 高但发白 = 颜色/背景混合问题 |
| 4 | Gaussian centers（3D 点云散点图 + 逐视角投影） | 覆盖范围、离群点、空洞处是否有点                             |
| 5 | Opacity（分布直方图）                     | 灰 → 整体半透明透出背景色；DA3 直出中位 0.033（88.2% < 0.1）   |
| 6 | Scale / Rotation（σ 折像素当量）          | 糊 → footprint 过大的量化证据                        |
| 7 | 渲染 RGB + GT 同帧并排                   | 颜色统计表（Mean RGB / Std / 饱和度，前景 vs 背景分开）       |
| 8 | 相机参数 + 参考视角标记 + 视角覆盖审计（99g）        | 白洞 → 是否落在观测弧缺口（采集包缺口 107.3°）                 |

## 2. 原始 GPT 方案摘要（评审参照）

**思路**：先定位、再分模块、最后联合优化；四条主线独立消融——  
A 颜色与外观（A0 基线 / A1 统一色彩空间 / A2 SH·opacity·背景混合）、  
B Gaussian scale（B0~~B3 足迹约束）、  
C 背景覆盖（C0 原始 / C1 人物背景分开生成 / C2 背景密度增强 / C3 背景几何一致性）、  
D 人脸（G0 基线 / G1 全局 4× 外观分支 / G2 Face ROI 分支 / G3 多视角人脸融合）、  
E 几何重影（E0~~E4 跨视角一致性）、F 置信度融合（E7）。  
组合矩阵 F0~F4（E1+E2 → … → 完整 DA3-GT）。

**方案中值得保留的点**：判据先于实验写死、四主线拆开不混改、  
不把 InfiniSplat 输出当训练标签、G3 多视角人脸融合（正面主纹理 + 侧脸结构 + 可见性加权）。

## 5. 评测方法论硬约束

1. **ROI 人脸指标必须逐视角定框**。固定人脸框在 view 8 落在书架上，把人脸锐度  
   虚高 +142~+180（ERRATA E12）。
2. **主判据不用全图 PSNR**。自一致性口径奖励平滑（RES=1 拿 26.04 但锐度仅 GT 的 48.5%）；  
   必须配锐度比 + 误差图 + 分频相关（A7b）。
3. **参考视角依赖**。DA3 质量随"离参考视角三维距离"单调衰减；跨运行比较必须  
   钉死 `REF_STRATEGY`（saddle_balanced 会换参考帧 → 坐标系不同，P0-1 踩过）。
4. **渲染分辨率对齐再比**。对角线规律：训练/渲染分辨率错配丢 4.5~7.1 dB；  
   锐度跨分辨率不可比（Laplacian 方差随分辨率变 3.4×）。
5. **任何"提升 X dB"必须写成"相对基线某口径 +X"**（R4）。
