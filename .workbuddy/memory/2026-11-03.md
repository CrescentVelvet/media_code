## 调研：SHARP / Depth Pro 的训练数据集可获取性

**触发**：评估前馈重建训练数据来源，看 Apple 两条路线能否复现。

**结论要点**
- SHARP（ICLR 2026, arXiv 2512.10685）：Stage1 = 自建 V-Ray 程序化数据（2K 户外 + 5K 室内场景 →
  700K 场景 / 11 视角 / ~8M 图，1536²或 2048²）；Stage2 = OpenScene + Shutterstock/Getty/Flickr
  商业授权 2.65M 图。**两条腿都拿不到**，官方仓只开推理。可复制的只有评估集：
  Middlebury / Booster / ScanNet++ / WildRGBD / ETH3D / Tanks and Temples（+ Unsplash 定性）。
- Depth Pro（ICLR 2025, arXiv 2410.02073 v2）：训练集清单藏在附录 Table 15（URL+License+Usage）
  与 Table 17（损失×数据集）。19 个训练集，18 个公开可下，全量约 10 TB 量级。

**Depth Pro 训练集分组（Table 17）**
- 合成/度量组（MAE+SSI-MAGE）：Hypersim, TartanAir, Synscapes, UrbanSyn, Dynamic Replica,
  BEDLAM, IRS, Virtual KITTI 2, SAIL-VOS 3D
- 真实组（trimmed MAE 20%）：ARKitScenes, DIML Indoor, ScanNet, SmartPortraits
- 立体/非度量（SSI-MAE+SSI-MAGE）：UnrealStereo4K, 3D Ken Burns, EDEN, MVS-Synth
- 仅结构相似（trimmed SSI-MAE）：HRWSI, BlendedMVS
- 两阶段都只训一次：Stage1=250 ep / Stage2=100 ep，Stage2 只加 MAE/MSE/MAGE/MALE/MSGE

**可获取性分级（实测页面）**
- 免注册直下：Hypersim(1.9TB, CC BY-SA 3.0)、TartanAir(全量 3TB, CC BY 4.0, AirLab/HF)、
  Synscapes(337GB, 自定义非商用、禁再分发)、UrbanSyn(CC BY-SA 4.0 可商用)、VKITTI2(RGB 7GB+深度 7.6GB,
  CC BY-NC-SA 3.0)、UnrealStereo4K(8 场景各 67-76GB，另有 1/4 分辨率 HF 版)、3D Ken Burns(~200GB,
  CC BY-NC-SA 4.0)、EDEN(全量 1.4TB/样本 38GB)、MVS-Synth(HF 9/16/34GB 三档)、HRWSI(7.6GB)、
  BlendedMVS(低清 27.5GB/高清 156GB, CC BY 4.0, GitHub Release)、IRS(OneDrive)
- 需接受许可/注册：Dynamic Replica（官网签协议拿 links.json，train 1.8TB）、BEDLAM（MPI 注册）、
  ARKitScenes（Apple 许可）、ScanNet（签协议 ~1.3TB）
- 基本拿不到：SAIL-VOS 3D（邮件联系 + 须自购 GTA V）、SmartPortraits（toolkit 已 archive，
  下载链接写 "TODO"）、DIML（Naver 短链状态可疑）

**给后续的选型判断**
- 许可陷阱：Hypersim CC BY-SA 3.0 有传染性；Synscapes 禁止再分发；多数为 NC。
  真要做可商用模型，只剩 TartanAir / BlendedMVS(CC BY 4.0) / UrbanSyn(CC BY-SA 4.0) 一类。
- Depth Pro 清单是「深度」导向，多数是单目/立体，不等于前馈 NVS 需要的多视角带位姿序列；
  前馈 3DGS 应补 ScanNet++ / WildRGBD / DL3DV / RealEstate10K / CO3D 这类多视角序列。

## 追加：前馈人体重建数据集调研（同日）

**关键分类（回答"THUman 有用吗"）**
- **扫描型**（THUman2.0/2.1、4D-DRESS、X-Humans-scan）：只有 obj+贴图，**无真实相机**，
  必须自渲染（ICON 有官方脚本出 RGB/Normal/Depth）。位姿深度完美、可任意采样视角，
  但无真实光照噪声/运动模糊/遮挡，贴图已烘焙光照 → 只能当几何先验+背面补全+评测，不能做主训练集。
- **序列型**（THUman4.0 / AvatarReX / DNA-Rendering / HuMMan / ActorsHQ / GeneBody / RenBody）：
  标定多视角同步视频，直接切"N 视角输入 → 多视角监督"，是前馈主力。

**可获取性（实测）**
- 直下零审批：THUman4.0（3 身份 24 相机 ~119GB）、AvatarReX（4 身份 16 相机 ~60GB）、
  THUman2.0/2.1（500→2500 扫描，但要申请表+加密密码）、iPER（单目）、GTA-Human
- 登录/OpenDataLab：HuMMan（1000 身份 10 Kinect，724GB 起，CC BY-NC-SA 4.0）、
  SynBody（10k 身份合成，379GB）、GeneBody（100 人 48 视角）、RenBody（500+ 人 60 视角 4K）
- 需审批：DNA-Rendering（签 PDF+邮件，每周五批，Part1 192GB / 全 ~10.8TB）、
  ActorsHQ（PI 签 release form，160 相机 12MP）、ZJU-MoCap、MVP-Human、4D-DRESS、X-Humans

**前馈训练四条硬约束（写进 DESIGN 前先看）**
1. 每个样本 = 同一帧的 N 视角，**禁止跨姿态混帧**（否则复现 som_human 两态几何冲突）
2. 输入视角数决定任务难度：单图 → 需 SMPL-X/MHR 强先验；4-8 图主流；>12 图退化成 MVS
3. 身份数 > 帧数：DNA-Rendering 500 / SynBody 10k / HuMMan 1000 才有泛化意义；
   THUman4.0 只有 3 身份，只能评测
4. GT 来源二选一：数据集自带逐帧 mesh/SMPL-X，或用现成 3DGS 逐场景优化当伪 GT
- 全部许可均为**非商用**（含 SynBody），商用模型需另找。
- 产出文档：`media_code/FEEDFORWARD_HUMAN_DATASETS.md`

## 追加：三版并入资产库（8 站 + 物体库）

**性质定位**：资产站补"环境"，不补"人体"。用法 = THUman/BEDLAM 出人 → Blender+BlenderProc 换 HDRI/材质/相机 → 渲多视角。
文档第 8 节给了合成流水线草案（抠人 → 环境 → 随机环绕相机 → RGB/深度/法线/mask）。

**许可核实（关键结论）**
- **全 CC0，可放心进训练集**：Poly Haven（HDRI/纹理/模型全 CC0，公共 API api.polyhaven.com）｜
  ambientCG（材质/HDRI/模型，CC0，有 API 与批量下载）｜3DTextures.me（CC0，逐张下）｜
  shareTextures（**1,600+ 纹理 / 250+ 模型 / 50+ atlas**，CC0，免注册，最高 4K）。
- **逐资源许可**：Sketchfab（CC0/CC BY/BY-SA/BY-ND/BY-NC 混，商店授权迁 Fab；Data API v3 需 OAuth token，ToS 禁爬）｜
  Blend Swap（.blend 工程，CC0/CC-BY/CC-BY-SA/CC-BY-NC，免费注册，无官方 API）。
- **买授权模式**：RenderHub（Personal Use Only 非商用 / Extended Use 可商用；两者都禁转售再分发）｜
  freePBR（600+ 套；**许可页 404**，免费单张条款含糊，$19 全库包才明示 commercial rights）。
- **⚠️ 通则：「可商用」≠「可训练」**。上述商业授权均未明示允许 AI 训练；发权重有风险。
  保守策略＝训练集只用 CC0/BY，商用资产只做定性演示；CC-BY 需留 asset_id→作者→许可→URL 的 CSV。
- **有量的物体库**：Objaverse ~800K（HF allenai/objaverse，逐物体 CC-BY/CC0 混合需过滤）｜
  GSO 1,030 扫描家居（CC BY 4.0）。

## 追加：文档四版改为 S/A/B 分级（同日）

**改因**：原文档按"来源"分节（Depth Pro 19 集 / 人体 / 多视角补充 / 资产库），但同源数据集价值可差两个数量级
（BEDLAM 与 Synscapes 同出 Depth Pro 清单）。改为按「对人像前馈重建的有用程度」统一分级。

**判据（四条，按序筛；可复核）**
1. **画面里有人**：不满足 → 最高 B（无人体只教几何）
2. **同帧 ≥4 视角 + 标定内外参**：不满足 → 最高 A；扫描型无相机 → A（需自渲染）
3. **身份数 ≥100**：不满足 → 只到 A（能跑通/评测，撑不起泛化）
4. **GT 可用**（逐帧 SMPL-X/mesh/深度）：缺 → 不降级，但需自造伪 GT

**分级结果（43 个，全覆盖无遗漏）**
- **S 6 个（主训练集，①②③全中）**：DNA-Rendering｜RenBody｜HuMMan｜GeneBody｜SynBody｜**MVP-Human**
  投入排序：HuMMan（登录即下，1000 身份）> SynBody（HF 直连，10k 身份）> GeneBody Test10（48 视角真实，免费试）
  > DNA-Rendering（最高保真但要排队）> RenBody（规模最大但公开信息最少）> MVP-Human（结构最贴但通过率未知）
- **A 22 个（环节级主力，某环不可替代但撑不起主训练）**
  A1 身份少的多视角人体 4：THUman4.0 / AvatarReX / ActorsHQ / ZJU-MoCap → 跑通与评测
  A2 人体但视角≤3 4：BEDLAM / Dynamic Replica / iPER / GTA-Human → 单图分支与先验
  A3 扫描型无相机 6：THUman2.0/2.1 / X-Humans / 4D-DRESS / THuman3.0 / MultiHuman / THuman原始 → 背面与几何 GT
  A4 无人体但多视角 8：DL3DV / CO3Dv2 / MVImgNet / RealEstate10K / WildRGBD / BlendedMVS / MVS-Synth / EDEN → backbone 预训练
- **B 14 个 + 1 失效**：B1 单目立体深度 10（Hypersim/TartanAir/UnrealStereo4K/Synscapes/VKITTI2/UrbanSyn/
  3D Ken Burns/IRS/HRWSI/SAIL-VOS 3D）｜B2 真实室内 RGB-D 4（ARKitScenes/ScanNet v2/ScanNet++/DIML）
  ｜失效 1：SmartPortraits（真人像+深度，仓库 archive 且链接 TODO → **本清单最可惜的一条，无替代品**）

**本次判断变化（与三版不同，需记住）**
- **MVP-Human 从 A 提到 S**：400 身份 × 8 视角且为同一姿态同步多视角，正好命中前馈任务定义；
  "静态扫描无动态"不构成缺陷（本任务只要静态人像）。
- **A 级不再是一个扁平的兜底筐**，拆成 A1/A2/A3/A4 四种缺口，各自对应 pipeline 的一环。
- **资产库不参与分级**，重新定位为「**把 A3 扫描型扩增到接近 S 可用度的杠杆**」——
  A3 贴图已烘焙光照，配 HDRI 重打光才能出可训练的多视角序列。
- Depth Pro 19 集最终只 2 个进 A2（BEDLAM、Dynamic Replica）、3 个进 A4（MVS-Synth/EDEN/BlendedMVS），
  **没有一个进 S**；正确用法 = backbone 深度/法线辅助头 + 室内背景分布。

**第四条判据的来源**：身份数比帧数重要（THUman4.0 有一万多帧但只 3 人，只能评测）。
