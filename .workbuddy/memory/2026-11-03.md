## 调研：SHARP / Depth Pro 的训练数据集可获取性

**触发**：评估前馈重建训练数据来源，看 Apple 两条路线能否复现。

**结论要点**
- SHARP（ICLR 2026, arXiv 2512.10685）：Stage1 = 自建 V-Ray 程序化数据（2K 户外 + 5K 室内场景 →
  700K 场景 / 11 视角 / ~8M 图，1536²或 2048²）；Stage2 = OpenScene + Shutterstock/Getty/Flickr
  商业授权 2.65M 图。**两条腿都拿不到**，官方仓只开推理。可复制的只有评估集：
  Middlebury / Booster / ScanNet++ / WildRGBD / ETH3D / Tanks and Temples（+ Unsplash 定性）。
- Depth Pro（ICLR 2025, arXiv 2410.02073 v2）：训练集清单藏在附录 Table 15（URL+License+Usage）
  与 Table 17（损失×数据集）。19 个训练集，18 个公开可下，全量约 10 TB 量级。

**Depth Pro 训练集分组（Table 17）**
- 合成/度量组（MAE+SSI-MAGE）：Hypersim, TartanAir, Synscapes, UrbanSyn, Dynamic Replica,
  BEDLAM, IRS, Virtual KITTI 2, SAIL-VOS 3D
- 真实组（trimmed MAE 20%）：ARKitScenes, DIML Indoor, ScanNet, SmartPortraits
- 立体/非度量（SSI-MAE+SSI-MAGE）：UnrealStereo4K, 3D Ken Burns, EDEN, MVS-Synth
- 仅结构相似（trimmed SSI-MAE）：HRWSI, BlendedMVS
- 两阶段都只训一次：Stage1=250 ep / Stage2=100 ep，Stage2 只加 MAE/MSE/MAGE/MALE/MSGE

**可获取性分级（实测页面）**
- 免注册直下：Hypersim(1.9TB, CC BY-SA 3.0)、TartanAir(全量 3TB, CC BY 4.0, AirLab/HF)、
  Synscapes(337GB, 自定义非商用、禁再分发)、UrbanSyn(CC BY-SA 4.0 可商用)、VKITTI2(RGB 7GB+深度 7.6GB,
  CC BY-NC-SA 3.0)、UnrealStereo4K(8 场景各 67-76GB，另有 1/4 分辨率 HF 版)、3D Ken Burns(~200GB,
  CC BY-NC-SA 4.0)、EDEN(全量 1.4TB/样本 38GB)、MVS-Synth(HF 9/16/34GB 三档)、HRWSI(7.6GB)、
  BlendedMVS(低清 27.5GB/高清 156GB, CC BY 4.0, GitHub Release)、IRS(OneDrive)
- 需接受许可/注册：Dynamic Replica（官网签协议拿 links.json，train 1.8TB）、BEDLAM（MPI 注册）、
  ARKitScenes（Apple 许可）、ScanNet（签协议 ~1.3TB）

  下载链接写 "TODO"）、DIML（Naver 短链状态可疑）

**给后续的选型判断**
- 许可陷阱：Hypersim CC BY-SA 3.0 有传染性；Synscapes 禁止再分发；多数为 NC。

## 追加：前馈人体重建数据集调研（同日）

**关键分类（回答"THUman 有用吗"）**
- **扫描型**（THUman2.0/2.1、4D-DRESS、X-Humans-scan）：只有 obj+贴图，**无真实相机**，

**前馈训练四条硬约束（写进 DESIGN 前先看）**
1. 每个样本 = 同一帧的 N 视角，**禁止跨姿态混帧**（否则复现 som_human 两态几何冲突）

3. 身份数 > 帧数：DNA-Rendering 500 / SynBody 10k / HuMMan 1000 才有泛化意义；
   THUman4.0 只有 3 身份，只能评测
4. GT 来源二选一：数据集自带逐帧 mesh/SMPL-X，或用现成 3DGS 逐场景优化当伪 GT
- 全部许可均为**非商用**（含 SynBody），商用模型需另找。

## 追加：人像数据采购方案（`PORTRAIT_DATA_SOURCING.md`，同日）

**起因**：公开人体数据集全非商用，要训可商用/可发布权重的模型只能采购或自采。

**⚠️ 最重要的核实（推翻了一个常见误解）**
- **RenderPeople 零售资产默认禁止用于训练**。General Terms **§4.2(a)** 把"Use of the 3D data for
  Computer Vision Research"（含 *creation of datasets, development and training of neural networks
  and machine learning models*）列为禁止项，需单独书面许可（`info@renderpeople.com`）。
  → 之前清单里"商用模型可另找付费资产如 RenderPeople"的说法**是错的，已改**。
- 但同一家公司的 B2B 站 **`humandataset.com`** 口径相反：明确允许造数据集训练 CV 模型；
  每个被扫描者签了含 GDPR 6(1)/9(2) ML 用途的 comprehensive model release；
  且**不得披露源 3D 模型**（可发模型权重、不可发原始扫描）。已被 AGORA/PIFuHD/PHORUM/NECA/CloSe 使用。

**路径 A：humandataset.com（首选，现成可买）**
- 35,000+ 扫描 / 5,500+ 精修模型 / 72 国 / 7-83 岁 / 330 台相机摄影测量棚
  （RenderPeople 零售页写 250 台，口径不一致，询价时问清）
- **核心价值＝多视角原图**：每次扫描 330+ 张不同角度照片，JPG 或 RAW，覆盖全部 34,000+ 次扫描
- 产品线：Posed / Rigged / Motion Animated / **Motion 4D** / Bodyshape；每人 35+ 个姿态
- 额外组件：SMPL 注册（按需）、点云 .XYZ/.PLY、UHQ RAW 网格（5000 万面+）、分割 mask、详细元数据
