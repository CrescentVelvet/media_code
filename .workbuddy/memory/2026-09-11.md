## flame_human ② HYPIR 人脸增强（监督图，cbc18e1）——head 锐度**无增益**
- 承接 09-10 结论（① scale/SH、③ 监督区 均为负）→ 做 ② HYPIR
- 新增 `01d_enhance_faces.sh` + `enhance_faces.py`：按 `03_match` 的 p0 脸框
  裁剪（FACE_PADDING=0.25）→ SD2Enhancer（UPSCALE=2, patch 512/stride 256）
  → 二次羽化融合回原图 → 输出整幅图；08 用 `IMAGES_DIR=<enhanced>/images` 指向
  - 79/125 帧有人脸被增强（90s，≈1s/帧）；无脸帧原样拷贝
  - **HYPIR 依赖在 vggt_human 环境**（accelerate 1.14/diffusers 0.32/peft 0.14），
    flame_human 环境没有 → 脚本内自动 `conda activate vggt_human` 切换
- **增强本身效果显著**：裁图对比皮肤纹理/眉形/眼线/唇形/帽扣细节全部恢复
- **但重训 08 后 head 框内 PSNR 18.57 → 18.61（打平）、裁图目检无差别**
- **根因（关键认知）**：HYPIR 是**逐帧 2D** 模型，补出的细节在各帧之间**不一致**；
  同一 canonical 位置在不同帧被要求呈不同细节 → 共享外观参数在 L1 下最优解
  就是它们的**平均 = 依然平滑**。**逐帧 2D 增强喂 3DGS 会被训练平均掉**
- 结论：提锐度只剩两条路 ——
  1. **3D 一致的细节**（更好几何 / 多视角一致先验 / 4D 一致生成）
  2. **改做渲染后 2D 后处理**（镜头 09 enhance_post 的定位；逐帧独立增强，
     视觉变锐但会有时序闪烁）
- 默认配置已回退 align7px（composite **22.69** 已验证）
- head 提锐度三路实验总表：① ✗（scale/SH）② ✗（HYPIR 监督）③ ✗（监督区收窄）
