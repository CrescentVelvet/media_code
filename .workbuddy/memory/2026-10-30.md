# 2026-10-30 · infinisplat_v2 复现

## 结论先行
InfiniSplat v2（arXiv 2610.20341）**只开源推理包**：无训练代码、无 refiner（Ours*）、
raw3d 数据私有。所以"复现"能做的上限是前馈推理链路，"25.8%/32.9% 提升"复算不了。
本仓 `infinisplat_v2/` 已跑通 4/16/32/50 视角四种规模，提交 073a779 + 94d6a7b。

## 环境：克隆比新装快一个数量级
torch 2.7.1 从 tuna 装要拉 ~3.5GB nvidia-* 依赖，单连接限速下 25 分钟还没装到 torch。
改 `conda create -n infinisplat_v2 --clone flashworld`（py3.11.6 + torch2.6.0+cu124）
28 秒完成，再 `pip install -e .` 只装小依赖。
**克隆来的 env 自带 gsplat 1.5.2 含编译好的 csrc** —— 本机没有 nvcc/gcc，这直接
解决了"发布包不带光栅化器"的问题。

## 三个真坑（都写进了 EXPERIMENTS.md）
1. **RDNorm 坐标系**：输出的 scene.ply 与 cameras.npz 在第一相机相对 + 半径归一化空间，
   而外部 GT 相机在原始尺度，差一个 Sim(3)。直接渲染 → alpha=0、全白、PSNR 负值。
   用输入视角做锚拟合 Umeyama（残差 1e-7、旋转 0.024°）后就对了。
2. **gsplat 1.5.2 输出已含 +0.5 直流偏置**（f_dc=0、alpha≈0.98 → 像素≈0.49），
   再按老习惯加一次会过曝；colors 必须 `[C,N,1,3]`。
3. **holdout 划分**：`rest[::step][:n]` 会让输入全挤在序列前半段，后半圈 target 变纯外推
   （020: 11.83→15.13、028: 8.69→11.54）。改 `np.linspace` 全序列铺开。
   教训：均值只涨 0.6dB，会掩盖局部灾难，必须看逐视角。

## 实测（3090，长边 518）
| 场景 | 口径 | PSNR | SSIM |
|---|---|---|---|
| hypersim 50 视角（GT 位姿） | 自洽 | 27.05 | 0.918 |
| hypersim 32 视角（DA3 位姿） | 自洽 | 23.29 | 0.829 |
| dtu 16 视角 | 自洽 | 20.30 | 0.726 |
| dtu 16 视角 | NVS holdout | 13.10 | 0.585 |

推理 22-31s（含 6.6GB SHA256 校验），2.7M-6.1M 高斯，峰值显存约 11GB。
自洽 ≠ NVS：自洽只证明"属性学对 + 渲染器接对"，不能当 NVS 性能。

## 对 vggt_human 的可用性判断
可作稀疏视角 scene_gs 初始化的 A/B 方案（输入图像 + COLMAP 相机 → PLY）。
但训练数据全室内合成/扫描，无人体专项；几何冻结 → 需要改几何的环节（MHR/3DMM 对齐）
借不上力，只适合背景/场景。

## 补测：三视角自有数据集（D:/dataset/物体三图数据，9 物体各 3 张竖拍）
**耗时几乎全在加载**：端到端 21.8s（均值），其中 CPU 构造 2.62B 参数模型 12.15s +
SHA256 3.55s + 拷 GPU 2.17s；**常驻复用单次仅 0.81s**。显存 nvidia-smi 峰值 9.7-9.9GB
（基线 1.55GB，净增 8.2GB），torch allocated 7.09GB。三视角与 50 视角显存差异不大
（大头是权重本身），差别在高斯数（22-31 万 vs 610 万）。

**DA3 位姿会静默塌缩**（新坑，比坐标变换更隐蔽）：榨汁机（透明）、电饭煲（浅色圆柱）
三张图被估成同一视角（两两夹角 0.2-0.9°），基线 0.02-0.10×半径，**推理照样 exit 0
输出 PLY**，但几何是废的。pose-free 模式不能救（同样塌缩）→ 问题在 DA3 backbone 内部。
COLMAP 也建不起来：1024 长边每图仅 271-380 SIFT，2048 长边 738-1277，
`No good initial image pair found`（3 图 + 大角度 + 白墙，重叠不足）。
→ **判据**：用文件名帧号（转台匀速，帧差 ∝ 转角）交叉验证 —— 帧差/角度比值在同一
物体内应稳定（实测 5 个物体 0.54-3.19 °/帧 内部一致；塌缩的两个是 0.02-0.08）。
`diag_pose.py` 一条命令给出两两夹角/基线，成本 1s，跑完必查。

**自洽 vs 真实 NVS 差 8.4dB**：3 图全输入自洽均值 21.52，2 入→1 出 NVS 均值 13.08
（11.26-16.08），alpha 覆盖 0.47-0.81 —— 留出视角里物体位置/大小对，但**未见过的区域是洞**
（手表表带内侧破洞、桌面文字丢失）。三视角重建的可用形态是"复现见过的角度"。

**又一个内参尺度坑**（06 脚本里，第一次把留出视角渲成白墙）：`cameras.npz` 的 K 在
processed 尺度（长边 518，fx≈468），而 `--cameras`/provided 入口按**原图像素**解释，
直接喂差 7.4 倍视场角；重建几何全错但自洽渲染看着正常。喂前把 fx/fy/cx/cy 乘
`原图长边/LONG_SIDE`，底行 [0,0,1] 不动。
**别用 2 点 Umeyama** 拟合两次推理的 Sim(3)：2 点只约束 4 自由度，解出的 R 会绕连线乱转，
相机转歪又是一面白墙。实测两空间只差纯尺度（朝向夹角 0°、第一相机都在原点），
按基线长度比缩放即可。

COLMAP 4.2.1（conda-forge）选项改名：`SiftExtraction.use_gpu` → `FeatureExtraction.use_gpu`，
`SiftMatching` → `FeatureMatching`，旧名 `unrecognised option`；`mapper --output_path` 需先 mkdir。
