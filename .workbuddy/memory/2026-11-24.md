## zipsplat：ZipSplat × LGTM 接入调研与独立 PPT

- 复用 `assignments` 的源 patch 归属与 ConeLoss 投影链，接 LGTM 原图纹理比无观测来源 query 更自然；
  但自由 3D 高斯没有局部 UV，scene token 又是多源、多高斯，必须改 surfel、选源/遮挡、纹理 2DGS、
  图集与源元数据导出；TokenBA 更新后纹理也需重新投影或联合优化，不能焊死。
- 训练顺序建议 Z0 高分辨率 TokenBA → Z1 普通 2DGS → Z2 固定几何 RGB 纹理 → Z3 alpha/T/纹理 BA。
  LoRA 仅是可选权重适配，不能创造 UV、渲染和新表示；官方大训练规模不是单卡 3090 小试预算。
- 条件化预期：几何正确且源图可见处最可能改善高频外观/LPIPS、减少堆高斯并解耦 backbone/输出分辨率；
  鼻部错层、眼嘴错位、遮挡、无观测和跨源重影不会自动修复。LGTM 多视仅约 2K，不承诺三图人像 4K。

## compare_4methods：四方法 LGTM 高分辨率纹理调研与独立 PPT

- 范围固定 SA / DA3-GS / InfiniSplat v2 / QuerySplat；不纳入 DA3+3DGS、VGGT-Ω+3DGS 回炉方案。
- LGTM 可迁移的是低分辨率几何、原图投影纹理、局部 UV、纹理 2DGS 与高分辨率监督，不是接入即支持 4K。
  论文多视 VGGT 仅到约 2K，4K 未实现；几何误差不会被纹理自动修复。
- 四家都需训练新表示/新纹理路径，但可优先冻结几何，不必直接全量重训基座。LoRA 不能创造 UV、纹理头、
  可导渲染、合并与导出能力。研究成本建议 SA > v2 > DA3-GS > QuerySplat，不是质量排名。
- 只读源码核对：SA 教师/学生独立权重、12 通道与 voxel merge；v2 11 通道与均匀体素合并；
  DA3-GS 深度+XY/深度偏移、SH2 与 Nested 尺度；QuerySplat 8192×64 查询几何与 512 权重契约。
  SA/v2 必须在合并前处理纹理，维护 UV/图元身份；QS 应接查询域而非逐像素摆点。
- 正式记录：`compare_4methods/FINDINGS.md` §10，包含中间档实测、源码行号、训练/数据/验收与 N2 冻结边界。
