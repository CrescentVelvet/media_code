### 踩坑（都是 ICP / IO 层的，值得记住）

1. **ICP 里 src 不能每轮换**：把 `P` 当下轮 src → 40 轮内塌缩成一点（P_std 4cm→0.3cm）。
   正确：src 固定为 MP canonical，每轮 `P = T@src` 求最近点。
2. **`T = A @ T` 双重应用**：Umeyama 的 src 已固定时 A 本身就是完整变换，
   应 `T = A`（替换）。写成累积会让 med_d 从 0.15cm 炸到 28cm。
3. **带尺度 Umeyama 会退化**：C 的奇异值退化时 s→0（实测 0.0005），
   每轮 s 略<1 累积 40 轮就塌缩。两个模板都是真实 cm 级 → **全程锁 s=1**。
4. **`np.diag(S) @ np.diag(D)`**：D 是 2D 数组，`np.diag(D)` 取的是对角线（1D），
   正确写法 `s = (S * np.diag(D)).sum() / var`。
5. **identity*.obj 混有 quad 面**：`load_obj` 三角化会打乱 generic 的面段顺序
   （skin 段是按多边形数给的）→ generic 必须 `triangulate=False`。
6. **proxy.env 的 `WEIGHTS_ROOT=/mnt/d/wheel/...` 是遗留值**，且 `_env.sh` 用
   `set -a` source 会盖掉外部传入值 → **不要拿 WEIGHTS_ROOT 拼路径**。
   `RESULTS_DIR` 在 proxy.env 里写的是 `${RESULTS_DIR:-...}`，外部可覆盖（安全）。

## 三模型独立训练（03i，下午~晚上）

### 架构决策（用户拍板，09-05 日志 + 本日确认）
- 三模型**独立训练**（非合并 init）：每个模型只在自己区域 mask 内被监督，
  区域外用 gt 填充 → loss/梯度=0、densify 不发生 → 模型真正独立。
- head 用**逐帧可微 warp**：head_gs 存参考帧位姿（canonical），训练渲染前
  按 per_frame R_f/t_f 做刚性替换（xyz'=A·xyz+b，q'=qA⊗q），渲染后立即
  恢复。梯度流回 canonical _xyz/_rotation → loss 只优化 canonical 形状，
  不会收敛到"平均位置"导致边缘模糊。
- 评估/training_report 渲染同样要 warp（否则 PSNR 失真）。

### 关键实现（train_face_finetune.py 扩展，commit acb3120）
- RegionMaskData：区域 mask 惰性缓存；region 模式只从有 mask 的帧采样
  （head 44/150 帧，避免空转）
- region loss：image_for_loss = render·m + gt·(1-m)，L1/SSIM 都对它算 →
  区域外 loss 恒 0 无梯度；SSIM 除以 area_ratio 补偿窗口跨边界稀释
- head_warp：HEAD_WARP_JSON 环境变量指向 head_fit.json；03i 脚本对 head
  自动 export。渲染前替换 _xyz/_rotation，渲染后恢复原始参数张量
- ⚠️ renderArgs 里塞 head_warp（index 6），training_report 切片 [:6] 传参

### ⚠️ PLY raw 值大坑（render_head_compare.py 踩过）
- PLY 存的是激活前值：scale=log_scale、opacity=sigmoid 前。
  直接读 PLY 渲染必须 exp(scale)/sigmoid(opacity)，否则渲染是纯色块
  （a_hat 全图恒定值 0.378 那种症状）。
- 训练侧不受影响（GaussianModel.load_ply 内部处理激活）。
- 用户之前强调的"scale/opacity 必须取激活后值"在评估侧同样适用。

### ⚠️ 合成渲染 alpha 大坑（render_composite.py 踩过）
- **不能用 rgb.mean(0) 当 alpha**：黑头发/深色衣服 RGB≈0 但 alpha=1，
  会把物体当透明 → 大面积泄漏。必须染白染黑法单独渲染 alpha
  （_features_dc=1.7724539 + _opacity raw=10 → RGB=累积 alpha）
- 合成顺序：scene 底层 → body → head 最上层（逐帧 warp），
  C = Σ layer_rgb·a_layer·∏(1-a_front)，acc_a 链式累积
