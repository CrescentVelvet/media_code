## 99e 三件套命名容错 + GLB 选择确定性（cgltf 补丁已能吐 json）
- 背景: 用户改 cgltf 源码增加 json 输出后，unpack_work/<task>/ 下出现
  `3DGS.glb, 3DGS_1.glb, cameras.json, GSCompressed_B4.bin, init_cam.json,
  original.mp4, view_limit.json`——**命名与 99e 期望的不一致**，99e 会误报 0/3。
- 改动:
  * UWA_JSONS 从「单名」改为「候选名元组」，**首项是官方名**（camera.json /
    init_camera.json / view_limits.json），别名在后（cameras.json / init_cam.json
    / view_limit.json）；传参给 gltf_unpacker 用官方名，便于回灌 99b/99c。
  * 新增 find_jsons(): ① 候选名逐个试（work_dir → tool_dir 并可自动归位）；
    ② 全不命中时按名字子串猜（JSON_HINTS，顺序 init→view→cam，防 init_cam 被
    误判为 camera）。三件套报告分 3/3、部分、0/3 三档，0/3 且 work 下有 json 时
    明确提示「像是命名不匹配」。
  * 新增 pick_glb(): 优先精确名 3DGS.glb（demuxer 原始产物），避免补丁版额外产出的
    3DGS_1.glb 因更新而被误选；无精确名时回退最新 *.glb。
  * docstring「已知局限」改写：三件套完整性从「必然残缺」改为「取决于工具链版本」，
    并强调回灌前必须比对字段。
