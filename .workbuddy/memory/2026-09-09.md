### 关键实现决策

- **阶段一不做 mask 引导**（与 vggt_human 的 detect_face_landmarks.py 相反）：
  全图直接检测，归属交给阶段二三层判据。理由：mask 引导会把 mask 自身错误带进来。
- **阶段二代价** `cost = -(INSIDE_W·inside + iom)`，INSIDE_W=2.0 让 point-in-mask 压过 IoM；
  逐帧 `linear_sum_assignment` 一对一；再做时序连续性检查（MAX_JUMP_PX=200，
  只标记不删，DROP_SUSPECT=1 才删）。
- **各向同性裁剪**：`square_crop()` 边长 L = max(w,h)×scale_exp，越界先
  `cv2.copyMakeBorder(BORDER_REPLICATE)` pad 整图再裁（**不用黑边**），
  逆变换 `u_full = (u_crop/size)·L + cx - L/2`，与 pad 量无关。
- **CROP_SCALE_LM=1.6**（对齐 vggt_human PAD_RATIO=0.6），**CROP_SCALE_DECA=1.25**（对齐 DECA 官方 demo）。
  注意参考实现用 2.5（含上胸）是给自研 ExpTracker 的，MediaPipe 468 不需要，
  2.5 会把脸压到 512 canvas 的 205px，精度损失——这里是**有意改小**。
- **PnP 位姿初值不依赖 DECA**：用 lm468 嵌入取 FLAME mean face 上的 468 个 3D 点 +
  2D 观测解 `solvePnPRansac`。DECA 只是可选加分项（加载失败自动退回）。
- **DECA 维度对齐**：DECA 默认 n_shape=100 / n_exp=50，FLAME 2020 是 300/100，
  `_pad_to()` 补零。输入归一化用 [-1,1]（对齐 DECA datasets 的 Normalize(0.5,0.5)）。
- **lm468 嵌入自己生成**（`build_lm468_embedding.py`）：MediaPipe canonical_face_model.obj
  → 归一化 → 暴力搜旋转粗对齐（yaw 全周 × pitch × roll）→ ICP 精修 → 最近三角形取重心坐标
  → 鼻尖/眼/嘴语义自检。不依赖第三方转存的 NPZ。

**阶段四要点**：
- 尺度初始化用**线性最小二乘解 SfM↔米**：每帧 `R_cam·p_head + t_cam = s·t_pnp`，
  未知数 [p_head(3), s(1)]，3F 方程解 4 未知数。不能直接混用 t_cam(SfM) 与 t_pnp(米)。
- 4.1 时 local/id/exp **全部冻结**（run_stage 的 optimize 字典控制），
  4.2 放开 local 且 global 走 0.1× lr，4.3 全放开。
- `median_quat()` 返回必须统一成 [w,x,y,z]（scipy as_quat 出来是 [x,y,z,w]，易错）。
- reject 在 4.2 之后，`thr = max(3.0, median(rms) × 5.0)`，剔除后重跑 4.2 再进 4.3。

**阶段五要点**：`area_weighted_sample` 保留 `(face_id, bary)`（**注意：vggt_human
的 build_head_gs.py 把它丢了**）；自由高斯只从「y 分位数以上」的头皮区采样并沿法线外推，
脸上放自由高斯会和绑定点打架。

**阶段七要点**：`surface_distance()` 优先 trimesh ProximityQuery（点到表面，
与顶点密度无关），退回 KNN。**阈值/外推都用米制毫米给，乘各自 scale 转世界单位**，
否则 verts（世界单位）和 offset（米）直接相加会错。

**训练脚本要点**：
- 复用官方 `gaussian_renderer.render`，模型只需提供
  `get_xyz/get_opacity/get_scaling/get_rotation/get_features/get_covariance` 接口；
  `get_xyz` 返回**当前帧形变后**的世界坐标（`set_frame(f)` 切换）。
- 官方 Camera 的 `R` 要传 **c2w**（= `qvec2rotmat(qvec).T`），它内部会再转一次回 w2c。
  `pipe` 不用 argparse，传 `SimpleNamespace(compute_cov3D_python=False,
  convert_SHs_python=False, debug=False)` 即可。
- **bary 用 softmax 参数化**（存 log 再 softmax）：恒为合法重心坐标 + 可训练。
  硬绑定下 clone 出的两点初始完全重合，只能靠 bary/scale 分开，所以 bary 必须能学。
- `fix_and_sync_exp()`：取 `median(exp)` 的**最近真实帧**（不是中位数向量本身，
  逐维中位数可能拼出怪表情），`requires_grad_(False)` 冻结。
- densify 的梯度统计沿用官方（可见点 screen-space 梯度范数），加了长度校验。
