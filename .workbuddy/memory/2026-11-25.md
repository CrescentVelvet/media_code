## ZipSplat × SplatAnything：算法思路讲解稿

- 交付 `D:/ppt/20261125-ZipSplat与SplatAnything算法思路对比.pptx`（15 页）与 D 盘同名 `_src` 工程；官方机制 / 机制示意 / 本机实测分层标注，无新训练或 GPU 实验，图片与 PPT 不入 git。
- 两者都有 token：SA 是源像素深度与相机反投影定中心，12 维属性不含 XYZ，再 GSN + 体素合并；Zip 是 scene token 注意力融合后自由解码 23 维多高斯。约束位置与表达空间不同，不直接决定清晰度或人脸几何正确性。
- 本地 Zip 三图 378×504、query ratio=1：2,916 tokens × G16 = 46,656 Gaussians，跳过 k-means 数量压缩但仍有跨视角融合。assignments / ConeLoss 可接源 patch，非局部 UV / 遮挡 / 真实表面保证。
- 提高分辨率对两者均有 backbone 成本；LGTM 纹理支路需另建 surfel / UV / 选源遮挡 / 可导渲染。本机同帧仅支持外观与覆盖权衡：SA 已知位姿、Zip 无位姿，TokenBA 属 TTO，微动单场景不作总体排名。机制与出处已写入 `zipsplat/EXPERIMENTS.md` 顶部。
