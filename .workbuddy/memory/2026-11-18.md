- 承接 v4 §4 第 3 条。新建 `sharp/07_sharp_nvs_export.py/.sh`：把 SHARP 前馈结果导出成

  坐标系不做任何拟合：`T = inv(c2w_anchor) @ c2w_i`，08 反算 `s=1.000000`、残差 3.6e-08。
- 两个静默 bug（都会毁掉对照且不报错）：①`02` 走官方 CLI 不传焦距→30mm 兜底
  `f=1663.13`，而真值 `fx=1380.82`，偏大 20.4%；故 `07` 复用 `05.predict()` 用真焦距。
  ② SHARP 颜色是 linearRGB，必须 `linearRGB2sRGB` 再编 SH。首版以「SA 不转换」为由跳过，
  实测渲染均值 0.283 vs GT 0.471，PSNR 低 2.4~2.9 dB；修后整体 10.92→**13.34**。
- 结果（21 留出视角，504×504，bg 0.5843，eps2d 0.01，与 SA 逐项同口径）：
  **SA 15.23 / 0.4060 / alpha 0.789 / 锐度89%**，**SHARP 13.34 / 0.2917 / alpha 0.930 / 96%**。
  **SHARP 低 1.89 dB**——不是旧文说的「一个量级」，该说法已在 EXPERIMENTS 正式撤回。
- 渲染有**两个头、两个派大星**的重影。逐条排除：位姿残差 3.6e-08（否）；前景深度极差比
  1.071、最优尺度 0.970/0.985、校正仅 +0.31 dB（否）；**真因是单图云是 2.5D 薄壳，
  跨视角拉不开**。逐片单渲：近 000 的视角仅用 000 = 16.37 dB > 并联 14.54；
  近 022 的仅用 022 = 19.35 > 并联 15.70 —— 并联在近处反而更差。
