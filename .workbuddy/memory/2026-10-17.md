### 踩坑（已写进 NOTES 第 7 节 + 固化到脚本）
1. **gsplat 的 GLM 是子模块**：`git fetch --depth 1 <commit>` 不拉子模块 →
   `glm/gtc/type_ptr.hpp: No such file or directory`。本机 `git submodule update` 会**卡死**
   （9 min 零字节），改用 gh-proxy 的 glm 1.0.1 tarball 解到 `third_party/glm`。
2. **`uvicorn==0.37.9` 在 PyPI 上不存在**（只有 0.37.0 → 0.38.0），官方 requirements 笔误。
3. **spz 需要 `scikit-build-core`**（`--no-build-isolation` 前提），且**CMake 4 会挂**
   （它的 `cmake_minimum_required` 低于 3.5）→ 装 `cmake<4`。
4. **clone 源自带 torchao 0.16.0** 与 torch 2.6 不兼容，会让 diffusers 0.36.0.dev0 在
   import 期 `NameError: name 'logger' is not defined` → 卸载 torchao。

### 3090 兼容性（逐条核对过代码）
- `quant.py: native_fp8_support = capability >= (9,0)`，3090 是 8.6 → **走 bf16 反量化
  分支**，能跑但比 A100/H100 慢；不是硬阻断。
- 显存：官方 24 GB 档 = `--offload_t5 --offload_transformer_during_vae`（20 s/场景），
  本仓默认就带这两个（`REALLY_LOW_VRAM=1` 再加 `--offload_vae`）。

## som_human：per-person 独立重建（方案 J，多人拆分）

- 起因：峰哥问「用 SAM 去背景、som_human 只重建人体、背景交给 GEN3R」是否可行；
  进一步澄清是**每人一个独立模型**（不是「所有人合成一个前景」），头/身可选分合。
- 新增：
  - `01g_person_masks.sh`：SAM3 video 模式（`prompt=person`，obj_id 跨帧一致），
    复用 `vggt_human/sam3_face_masks_worker.py`。
  - `01h_build_person_scenes.{sh,py}`：按 pid 拆场景（images/sparse 软链 +
    每帧该 pid 软 alpha + person.json）。
  - `train_som.py`：`SOM_FG_MASK_DIR` 单人前景监督 + `SOM_FG_INIT_FILTER` 初始点
    多视角 mask 投票过滤 + 随机背景；loss 面积归一化（`numel/area`）。
  - `02_train.sh`：`FG_MASK_DIR / FG_INIT_FILTER / FG_INIT_MIN_VIEWS /
    FG_INIT_MIN_RATIO / BG_RANDOM`。
  - BACKLOG 加「方案 J」；README 加「按人独立重建」节。
- **SAM3 多人实测（hand10，160 帧）**：27 个 track，只有 2 个是真人（p02/p07，
  各 160/160 帧、占画面 10.2%/10.8%）；其余 25 个面积 0.01~1.3% 且与真人
  **IoU 恒为 0**（背景物体误检）。01h 用**帧覆盖率 ≥50% + 平均面积 ≥0.5%**
  过滤；有一个 1.26% 的误检覆盖了 36% 帧，只按面积会漏进来。
- **踩坑（已修）**：①`find` 不加 `-L` 不跟随 01c 产出的 images 目录软链接；
  ②grid_sample 的 fg 已是 4D，多 `[None]` 变 5D 会报 grid 末维错；③DG 的
  `max_radii2D` 在 `create_from_pcd` 末尾按原点数建，`training_setup` 不重建
  → 过滤后不同步会首步 IndexError。
- **结果（hand10，10k + -r 2，严格同参）**：

  | 模型 | 点数 | 耗时 | FG PSNR（本人 mask 内） |
  |---|---|---|---|
  | 整场景（基线） | 608,400 | 635 s | p02 24.492 / p07 24.497 |
  | per-person p02 | 103,669 | ~320 s | 24.343（−0.15） |
  | per-person p07 | 115,896 | ~320 s | 25.193（+0.70） |

  点数/体积 ~1/6，训练速度 3→32 it/s；逐视角最差帧 per-person 更好（+1.1dB）。
  ⚠️ 遗留缺陷：mask 边缘有黑色飞溅状飞点（羽化区梯度 + 双人贴身互染 +
  init 残留点），后续可 mask 腐蚀 / 训练中按 mask prune / 提高 init ratio。
- **结论**：方案可行且资源省 6 倍、质量持平或略升；视觉毛刺不是 per-person
  引入的（双人招手整场景在 fg 区域本来就糊）。**结论与 montage 图已发峰哥**。
  产物：`D:\output\som_human_results\hand10_shuangren_zhaoshou\per_person\`。
- 下一步候选（峰哥定）：①mask 腐蚀 + 训练中按 mask prune 治边缘飞点；
  ②per-person + 更高 densify（点没吃满 600k）；③与 GEN3R 的背景合成链路；
  ④头/身分离（SAM3 prompt=head 或 person∩3DMM 包围盒）。
