## head 模糊根因（e1bbe89）——用户问"为何静态平均还这么糊"
- **前提纠正**：head **不是**静态平均。`train_avatar.py:181 deform(f)` 里
  `exp[f]`/`local_q[f]`/`local_t[f]` 全部逐帧；全局共享的只有 ①外观
  (SH/opacity/scale) ②`free_can` 那套固定偏移
- **模糊主因（量化排序）**：
  1. ★★★ **FLAME 对齐误差**：lm-RMS 26.5px = **脸宽的 12.3%**（脸框 p50
     216px；帧29 164px 下 RMS 30.1px = **18.4%**）→ 每帧网格落在错位置，
     外观只能靠"变糊变大"跨帧妥协
  2. ★★ 头部运动剧烈：相邻帧旋转 40°(p90 67°)、平移幅度 0.43（头尺寸 0.26）
     → 各帧约束方向差异大
  3. ★ free 高斯死重：20000/74936(27%) 塌缩成一个灰盘（std 0.003，
     `tri[is_free]=0` → anchor 恒为 V[0]，free_can≈0 没动）→ 白底渲染只剩
     一个小灰圆 → 纯浪费容量
  4. ★ 巨型 floater 330 个（08e 已剪）
  5. ✗ **表情变化：形变仅占头尺寸 0.02%**（几乎为零）→ **"固定一帧表情"
     无可修**，改了也不会变清晰（用户方案的数据反驳）
- **关键认知**：用户提的"逐帧 FLAME 反变换到 canonical"我们**已在做**
  （bound 高斯 + 逐帧 FLAME 变换）。该方案有效的前提是**拟合足够准**；
  当前 12-18% 脸宽的误差破坏了跨帧一致性 → 外观只能糊
- 帽子实际由 **bound** 高斯渲染（densify 漂移覆盖），不是 free
- 改进方向（治本排序）：① 提升 FLAME 拟合精度（稠密光流/时序平滑，目标
  RMS<8px）；② 清理 free 死重把容量给 bound；③ per-frame 形变场（Dynamic
  3DGS 式，59 帧易过拟合）；④ HYPIR 只提外观上限不解决几何
- 工具：`_debug_head_free.py`（bound/free 白底分开渲染）

## 05 对齐欠训练修复（0dbb820）——RMS 26.5→7.45px ✅
- **诊断链**：
  1. `_debug_lm_overlay.py`：红(pred)/绿(GT) 叠加 + 分区 RMS → 误差结构性：
     嘴部 29px 最差、左眉/左眼 22/19px vs 右眉/右眼 15.6/10.8px 左右不对称
  2. 读图发现：**人物全程"手托脸"坐姿**（帧 15/0/29 都是），下半脸长期被手
     遮挡 → DECA 在遮挡下外推嘴部 landmark → 嘴部误差最大；22-33 段最差
  3. `_debug_selffit.py`：单帧自拟合（pose+exp 自由）可达 **~9px**（id 自由
     8.5px）→ 模型表达力够，全局 26.5px 是**优化不足**
  4. 根因：`run_stage` 用 `ExponentialLR(gamma=0.95)` **逐迭代**衰减，300 步后
     LR 只剩 **2e-7**（后 200 步空转）；而全局要优化 59 帧 ×110 + 300 id

## ① 调小初始 scale / 提 SH 阶数（7e361fa，负结果，配置已回退）

- **SH 阶数重要发现**：读 `forward.cu` 确认官方 CUDA 内核 `computeColorFromSH`

  ② 修 head 监督区（现在用 person mask 含身体，浪费容量）；③ 继续压对齐误差
- 可调开关已入库（默认值保持行为不变）：`SCALE_FACTOR` / `SH_DEGREE` /

## ③ head 监督区收窄（1d1ef81，负结果，开关已入库默认关）
- 量化动机：person mask 均值 383,789px，其中只有 **32.5%** 落在 head_box 投影
  内，**67.5% 是身体**（夹克/胳膊）→ head 分支 2/3 梯度在拟合身体
- 实现：`HEAD_REGION=1` + `HEAD_OUT_W`（head_box 外权重，0=硬切）+ `HEAD_MARGIN`
  + `HEAD_DILATE`（train_avatar.py 里用 `head_mask_2d` 投影 head_box 做区域加权）
- **结果变差**：head 框内 PSNR **18.57 → 17.71 dB（-0.86）**
- 读图：**帽子退化发白、下颌/手部出现新的亮斑伪影**
- 原因分析（两个）：
  1. head_box 的 2D 是 **AABB 矩形**（8 角点投影取包围盒，212k px）——含大量
     非头像素；要正确收窄需投影**头部网格轮廓**（rasterize）而非盒子
  2. **"头"的真实职责域比盒子大**：人物长发挂到肩下 → 失去监督后退化
- 判定：此路性价比低，不再继续；默认配置回退 align7px
- ⚠️ **踩坑**：恢复 06 产物必须 **ply 与 avatar_bind_p0.npz 同步**！只恢复
  avatar_p0.ply 会让 ply(70000) 与 bind(120000) 点数不一致 →
  `_RasterizeGaussiansBackward ... got [120000,16,3] but expected [70000,16,3]`
  （修法：`bash 06_init_avatar_gs.sh` 用默认配置重新生成一对）

## 今日 head 提锐度三条路的结果汇总（重要）
| 路线 | 结果 |
|---|---|
| ① scale/SH | ✗ 负（scale 打平；SH4 内核不支持是空操作） |

## 99c 六项白名单实锤：buffer/radius 收窄全链路失效（f65a163）
- 用户手机实测: thetaBuffer/phiBuffer、RADIUS_RANGE_SCALE 均不生效。根因:

  gravity/target/boundingbox 六项，其余静默丢弃。

  （INIT_FOV_SCALE / INIT_RADIUS_SCALE / 夹紧）。
- 已记入 vggt_human/NOTES.md 第 9 条（含三条未验证出路: 分析播放器消费端、
