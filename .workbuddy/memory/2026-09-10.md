## 帧 24-33 低分根因诊断（ccda236/ee93127）
- 现象：composite 全帧 PSNR（59 帧 mean 17.51/median 19.09），帧 24-33 段掉到 9.3-11.2 dB（其余段 15-21 dB）
- 诊断链（排除法）：
  1. 亮度统计：无曝光跳变（mean 0.51-0.54 平滑）
  2. 消融：scene-only / scene+body / full 在帧 29 均 ~9.7 dB → 与 head/body 无关，scene 自身崩
  3. 官方落盘渲染 vs GT = 25.4 dB → 疑我管线 bug
  4. 相机对照：官方 Scene 相机 vs 手工 GSCamera，world_view_transform diff = 0 → 相机无误
  5. 同相机同 ply：官方 GaussianModel vs 我的 MergedGS = 119.67 dB，张量级 diff≈0 → 渲染管线无误
  6. 官方模型重渲 vs 落盘渲染：ridx 25/75 掉 9.7/12.3 dB，其余 33-59 dB → 落盘渲染是旧版模型产物
- **根因**：nn 场景 ply 在大 yaw 段（25-45°）欠拟合（帧 24-33 相机 yaw -31°~-42°），落盘渲染掩盖了这一点
- **已修 bug**：composite load_gaussian_ply 的 scale 激活 softplus→exp（官方 log-scale 对 exp；数值影响小）
- 结论：body/scene 质量上限受上游 nn 模型视角覆盖限制；改进方向 = body finetune（动态姿态+视角覆盖）或上游重训

## 08b body finetune 首轮实验（44bb8ee）：负结果 + 根因定位
- finetune_body.py：自由 3DGS（无绑定）+ p0 mask 区域监督，60 epoch，
  65,453→117,354 高斯，loss 0.10→0.052（densify 8 轮正常）
- **结果：composite PSNR 反而变差 17.51→14.72**（mean），训练 loss 却在降
- 根因链（像素级证据）：
  - 帧15 mask 外 MAE 0.0586→0.0926（大幅恶化），mask 内 0.0825→0.0853（持平）
  - body 高斯 bbox 膨胀 ~2x（max 距质心 0.252→0.394），opacity p50 0.083→0.181
  - 中心格（人像区）MAE 掉最多（-0.087）——膨胀高斯遮挡 scene 背景渲染
- **机制**：mask 区域监督的 loss 对「长到 mask 外的高斯」不可见（梯度为零），
  densify 的 clone/split 无空间约束 → 高斯往 mask 外自由膨胀且 opacity 升高，
  污染 composite 的背景区域。经典「监督盲区 + 无约束生长」
- 修复方向（未做）：① densify 后 prune 掉投影在 mask 外的点；② loss 加
  mask 外 alpha 惩罚；③ 冻结 xyz 只调外观（无 densify）
- 基线 json 已恢复（composite_psnr_all.json=old body；ft 版存 composite_psnr_bodyft.json）
