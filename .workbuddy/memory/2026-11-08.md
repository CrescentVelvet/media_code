### 2DGS 分析的核心事实（新实测，audit_12_surfel_orient）

读 `gs_adapter.py`：scale 是**三轴独立 sigmoid、无排序**，`1e-5 + (30−1e-5)·sigmoid(raw)`
再乘 `depth·0.1·(1/fx+1/fy)`。实测 484 万高斯：
- **最小 σ 99.9% 落在局部 index 0**（不是 index 2！），量级触到 `scale_min` 下限
  → 第三维不是"薄"，是**被压到下限的退化轴**；
- 该轴方向 vs 真实表面法向 **56.9~66.4°**，而**随机基线是 57.3°** → 法向与几何基本无关；
- vs 视线 25~51°（视角依赖强），三轴里虽有一轴接近视线（19~25°），但**被压到 0 的不是那一轴**。

⇒ DA3 **学出了"零厚度"，但没学出"法向"**：厚度这一自由度用掉了，方向这一自由度浪费了。

### 结论（题眼）

**提升点不在"2DGS 更强"，而在"DA3 已经在输出一个退化的 2D 表示，却用 3DGS 的 EWA 光栅器渲染它"。**
EWA 暗含"Σ_world 满秩"，而 DA3 输出秩 2 → 只能靠 `eps2d=0.3`（σ≥0.55 px）兜底，这就是低通；
掠射时透视缩短让屏幕协方差条件数爆炸 → 长条 = 拉丝，低通 = 糊。
2DGS 换的是：①表示（`Projection2DGSFused.cu:152` 里 `mat3(s0,0,0,0,s1,0,0,0,1)`，第三维是常量 1）
②ray-splat 精确求交（t = (p·n−o·n)/(d·n)），屏幕上是被正确透视缩短的椭圆而非无限长尾。

收益分三档：A 确定（消退化病态、深度取平面交点、法向变可监督量）｜B 可能（掠射区重影/拉丝、
跨视角收敛、点数效率）｜C 不会（**不会造高频**、不修位姿、**全图 PSNR 可能不升甚至降**）。
→ 所以主判据不能是全图 PSNR（R-3 的教训）。

落地分两步（单变量）：I-03 只换光栅器不重训（~20 行，测"错配"净代价）；
I-04 头改 2 axis + 法向、加 L_normal/L_distort（重训 2k 步，才是提升主体）。

**⚠️ 陷阱（已写进 ERRATA E7）**：DA3 最小轴在 index 0，2DGS 只读前两轴 → 直接喂会得到
**零宽刀片**，屏幕上几乎消失。必须先 `argmin(σ)` 再重排 `s'=[s1,s2,s0]` 并同步置换旋转矩阵列。
