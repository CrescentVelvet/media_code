据此建 `compare_4methods/IMPROVEMENTS.md`（改进台账 + 四条规则 R1~R4），冻结基线 **22.11 dB**。

四条规则：R1 参照物先自证（22.11±0.05 可一命令复现）｜R2 单变量｜R3 判据先行｜R4 报告必须带参照。

在拿它当"我们的基线"之前要先抬回官方水平（I-01 不裁剪 +2.0、I-02 全 SH +1.15，都零训练成本）。

### 2DGS 分析的核心事实（新实测，audit_12_surfel_orient）

读 `gs_adapter.py`：scale 是**三轴独立 sigmoid、无排序**，`1e-5 + (30−1e-5)·sigmoid(raw)`
再乘 `depth·0.1·(1/fx+1/fy)`。实测 484 万高斯：
- **最小 σ 99.9% 落在局部 index 0**（不是 index 2！），量级触到 `scale_min` 下限
  → 第三维不是"薄"，是**被压到下限的退化轴**；
- 该轴方向 vs 真实表面法向 **56.9~66.4°**，而**随机基线是 57.3°** → 法向与几何基本无关；
- vs 视线 25~51°（视角依赖强），三轴里虽有一轴接近视线（19~25°），但**被压到 0 的不是那一轴**。

⇒ DA3 **学出了"零厚度"，但没学出"法向"**：厚度这一自由度用掉了，方向这一自由度浪费了。

### 结论（题眼）

**提升点不在"2DGS 更强"，而在"DA3 已经在输出一个退化的 2D 表示，却用 3DGS 的 EWA 光栅器渲染它"。**
EWA 暗含"Σ_world 满秩"，而 DA3 输出秩 2 → 只能靠 `eps2d=0.3`（σ≥0.55 px）兜底，这就是低通；
掠射时透视缩短让屏幕协方差条件数爆炸 → 长条 = 拉丝，低通 = 糊。
2DGS 换的是：①表示（`Projection2DGSFused.cu:152` 里 `mat3(s0,0,0,0,s1,0,0,0,1)`，第三维是常量 1）
②ray-splat 精确求交（t = (p·n−o·n)/(d·n)），屏幕上是被正确透视缩短的椭圆而非无限长尾。

收益分三档：A 确定（消退化病态、深度取平面交点、法向变可监督量）｜B 可能（掠射区重影/拉丝、
跨视角收敛、点数效率）｜C 不会（**不会造高频**、不修位姿、**全图 PSNR 可能不升甚至降**）。
→ 所以主判据不能是全图 PSNR（R-3 的教训）。

落地分两步（单变量）：I-03 只换光栅器不重训（~20 行，测"错配"净代价）；
I-04 头改 2 axis + 法向、加 L_normal/L_distort（重训 2k 步，才是提升主体）。

**⚠️ 陷阱（已写进 ERRATA E7）**：DA3 最小轴在 index 0，2DGS 只读前两轴 → 直接喂会得到
**零宽刀片**，屏幕上几乎消失。必须先 `argmin(σ)` 再重排 `s'=[s1,s2,s0]` 并同步置换旋转矩阵列。

## R-6 I-01/I-02 归位跑完：18.97 → 22.11 dB（02:00~02:40）

按峰哥"先复现官方、再逐个加改动"的规矩，第一段（归位）做完。**零训练成本，+3.14 dB。**

**判据全过**：PLY vs 内存逐档差 ≤0.005 dB（导出无损，含 SH channel-major 排列）；
P3 +3.14 dB；位姿闸门 ΔR=0 / ΔK=0 / Δt 6.2e-5 m（0.06 mm，投影 <0.02 px）。

**本轮最重要的发现（推翻了原先的图注）**：两个开关**分工明确、几乎不重叠**

- 所以归位前"既糊又重影"是**两个不同的缺失各占一半**，不是一个问题的两种表现。
  此前把症状全记在"点数/密度"账上是错的。

**对后续的直接影响**：
1. 治"糊"的第一优先级是 **I-02 全 SH**（零训练成本），不是加点/加分辨率。

fig23 里第一格（GT）看着"脸更大"是错觉——GT 头发更黑（暗像素 21.5% vs 14.5%）、边缘更锐。

## I-03：只换 2DGS 光栅器（头不动、不重训）→ 判 B 档（11:40）

**做法**：同一个 PLY（`i12_fullpts_sh`，610 万点·全 SH·官方 22.11 dB）、同一组相机、
同 `sh_degree=2`、同 `eps2d=0.3`、同一 slant mask、同一组视角对（31 对）。
唯一变量 = 光栅器。2DGS 侧做轴序重排 `s'=[s1,s2,s0]`、`q'=q⊗q_P`（`q_P=(0.5,0.5,0.5,0.5)`，
`R(q_P)` 逐元素 == `[[0,0,1],[1,0,0],[0,1,0]]`，脚本内断言自证）。

| 指标 | 3DGS EWA | 2DGS exp | 2DGS median |
|---|---|---|---|
| 全图 PSNR | **22.11** | 21.82（−0.29） | — |
| 锐度 / 人脸锐度 | **398 / 489** | 331 / 420（−66 / −69） | — |
| 掠射跨视角深度一致性 | 0.80% | 0.98% | **0.41%（−48%）** |

**结论**：A2 成立（median 深度是 3DGS 拿不到的量）、A1 证伪（更糊）。
判据：P-D ❌（1.22）/ P-D2 ✅ / P-D3 ✅（0.516）/ P-COV ✅ / P-E7 ✅（−5.14 dB）。

**根因不是"掠射病态"**（这是本轮最重要的反直觉发现）：
按 GT slant 分档看 MAE 增量 —— 正对 0–30° **+7.54%**、30–60° +4.18%、掠射 60–90° **+5.14%**。
**正对档损失最大**。真因是 **DA3 的盘法向 vs 真实表面 56.9~66.4°（随机基线 57.3°）**，
2DGS 拿随机法向定求交平面 = 把每个高斯投到随机朝向的平面上，屏幕足迹被随机拉伸；
3DGS 的 EWA 靠 `add_blur(eps2d, covar2d)` 兜底，对退化轴不敏感，反而稳。
→ **I-04 的法向正则不是附加项，是让 2DGS 成立的前提。**

**推翻了一个自己的假设**：曾把「DA3 输入深度掠射区 0.80%」当渲染深度下界，
但 2DGS median 拿到 0.41%，比"下界"好一倍。单视角预测的一致性含单视角噪声，
不是融合结果的下界（已记 ERRATA E11）。

**两个工程坑**：
- **E7 量化**：不重排直接喂，逐视角 −4.21/−5.52/−5.70 dB（均值 **−5.14**）。不是"画面消失"，
  是"还在渲染但整体掉 5 dB"——肉眼极难发现，必须做闸门。
- **E10**：gsplat 1.5.3 的 `rasterization_2dgs` **没有 `normals` 参数**（法向由 quats 第三列决定）；
  且 `sh_degree=None` 时不可用（`rendering.py:1503-1520` colors 预处理被整块注释掉，
  下游断言 `colors.shape[:-2]==(B,C,N)` 直接失败）。`render_mode="RGB"` 时
  normals_from_depth/distort/median_depth 全 None。

**判据订正（跑前）**：原主判据「掠射 0.95%→<0.85%」的阈值安在输入误差同量级，必然判负；
改成相对判据 P-D / P-D3 + P-COV / P-E7 闸门。另发现采集序列**首尾不相邻**
（31→0 基线 210.75 cm，其余 6~40 cm，有效比 41.8%），环形口径会污染中位数 → 加视角对闸门。

新增脚本：`audit_15a_probe_2dgs`（API 探针）、`audit_15b_depth_baseline`（GT 深度分档一致性）、
`audit_15_2dgs_raster`（I-03 本体，约 8 min）、`audit_16_i03_diag`（损失归属，秒级）、
`A14_make_i03_figure`（fig25/fig26）。产物在 `$B/佳佳抱枕_p1m_off/i03_2dgs/`。
