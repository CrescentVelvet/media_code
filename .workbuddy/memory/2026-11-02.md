## InfiniSplat v2 Step 2：同预算「加视角 vs 加分辨率」（commit 33a77b7）
- 设计：21v@777 与 48v@518 的 raw 几乎相同（9.68 vs 9.75M，差 0.7%），但**视角数与分辨率
  同时变了**，一分钱花两处 → 无法归因。补 **21v@518** 做基线后才拆成二因素（这是本轮唯一
  的方法论关键，先按 A/B 做会得出错误因果）。
- 三组实测（佳佳抱枕，等间隔取帧）：
  21v@518 4.26M / 14.6 GB / 26.1 s / PSNR 20.195 / σ1.50 / 锐度.686 / 双峰 27.6%
  21v@777 9.68M / 22.7 GB / 34.1 s / 20.578(原生 588×784) / σ1.75 / 锐度.712 / 双峰 30.2%
  48v@518 9.75M / 22.8 GB / 38.4 s / 20.457 / σ1.50 / 锐度.629 / 双峰 22.4%
- **统一到 392×518 后（11_budget_compare.py，GT 共用 + BOX 重采样）**：
  加分辨率 → PSNR **−0.28 dB**、锐度 **+12%**、双峰 −0.8pp（噪声内）
  加视角   → PSNR **+0.26 dB**、锐度 **−8%**、双峰 **−5.2pp**（27.6→22.4）
- **加分辨率不涨 PSNR 只涨锐度 ⇒ 多出来的高频与 GT 不对齐**（过锐/错位），不是真细节。
  加视角降重影的代价是更平滑：merge 丢弃率 4.7%→9.3%（重叠区被合并）。
  → 不是"谁更好"：要干净/准确选加视角；要细节/锐选加分辨率。
- **σ_eff 细网格（0.25px 档）：518 恒 1.50，777 是 1.75（均值 1.93）**。分辨率 ×1.5135，
  若模糊跟着像素走应为 2.27 ⇒ **绝对锐度只涨 1.2–1.3×**（2.27/1.75=1.30，均值口径 1.18）。
  机理：反投影是每像素一个高斯，高斯半径由 pixel footprint 定 → 提分辨率只是让高斯**排更密**，
  单个并不更锐。⇒ **整图提分辨率低效（2.27× 预算买 1.2× 锐度），手/脸要锐只能 ROI 裁剪**。
  ⚠️ 这条 ROI 结论是外推，未实测（E-24 已标证据分级）。
- 口径纪律（同类坑第 3 次）：PSNR/σ_eff 是**像素单位**，不同长边必须重采样到同一尺寸再比。
  21v@777 原生 20.58 → 重采样 19.92，**差 0.66 dB 足以让结论反向**。
