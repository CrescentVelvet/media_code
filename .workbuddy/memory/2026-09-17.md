### CLI 参数（从 `src/sharp/cli/predict.py` 原文读出，非二手）

`sharp predict -i <文件或目录> -o <输出目录> -c <ckpt> [--render] [--device cpu|cuda|mps] [-v]`
- 输入是目录时递归 glob 支持的图像格式
- 输出 `<stem>.ply`；`--render` 时额外 `<stem>.mp4`（**仅 CUDA**，非 CUDA 会 warning 并自动关掉）

### 产出

新建 `media_code/sharp/`（沿用 vggt_human 同一套规范）：
- `_env.sh` — proxy.env / CA / conda activate sharp / CUDA_HOME 指向 conda 前缀 / `TORCH_CUDA_ARCH_LIST=8.6`（3090）
- `00a_setup_env.sh` — conda 建 sharp(py3.13) → pip torch 2.8.0+cu128 → conda 装 cuda-toolkit(label cuda-12.8.0)+gxx_linux-64=12 → clone → `pip install -r requirements.txt`（含 `-e .`）→ **追加**（不覆盖）SHARP_* 到 proxy.env
- `01_download_models.sh` — 下载 + **字节数精确校验**；`SRC=` 导入迅雷下好的文件
- `02_run_inference.sh` — 封装 `sharp predict`，`RENDER=1` 开 `--render`
- `08_move_output.sh` — rsync 到 `/mnt/d/output/sharp_results`
- `README_wsl.md`（主文档，含迅雷链接表）/ `README.md`（精简，含 Config 表）

仓级 `README.md` 的 Algorithms 列表已加 sharp 一行。
