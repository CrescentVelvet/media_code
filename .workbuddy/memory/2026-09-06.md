## vggt_human：闭环推近（alpha 覆盖率驱动）落地 + 关键天花板发现

### 实现（commit fe3fd60，render_closeup.py）

按用户定义的方案实现闭环推近：

- **探测**：从输入视角出发（CLOSED_LOOP=1 时 compute_closeup_pose 不再预推进，起点 = 输入视角本身），
  渲染「头部高斯染白 / 其余染黑」的亮度图 → 软均值 = alpha 覆盖率
- **解析跳步**：cov ∝ 1/d² → `d_new = d × √(cov/TARGET)`，一次测量即可逼近达标距离，
  迭代（MAX_PUSH_ITERS）只为补偿遮挡/透视/画幅溢出；cov≈0（脸完全不可见）退化为几何试探 ×0.7
- **安全下限**：`d_min = max(MIN_DIST_RATIO × d0, MIN_DIST_ABS)`，防相机插进头里
- **探测分辨率 ALPHA_PROBE=128**：覆盖率是尺度无关量，光栅器焦距随宽度缩放
  （focal = W/(2·tan(fov/2))），小图与 512 结果等价，探测成本几乎为零
- 新增字段：`alpha_cov_probe` / `push_iters` / `closed_loop_target_reached`，打印逐视角表格

新增函数：load_gaussians / select_face_gaussians / make_camera / set_camera_distance / closed_loop_pushin
（注意：torch 与 gaussian_renderer 是 render_views 里的懒加载，新函数需各自 import + sys.path.insert(GS_DIR)）

### 关键发现：目标 40% 在当前代理下不可达（物理天花板）

| 诊断实验 | 结果 |
|---|---|
| TARGET_COV=40, d_min=0.3×d0 | 全部 1 次迭代撞下限（0.189m），cov 仅 12.8%，无一达标 |
| 放开 MIN_DIST_ABS=0.08 | 好视角仍卡 0.189（绑定约束是 0.3×d0 而非绝对下限） |
| 放开 MIN_DIST_RATIO=0.10 / ABS=0.05 | **推到 0.05~0.065m 时 cov 全塌成 0.00%**：相机进入头部高斯簇内部（椭球半轴 8.8cm > 距中心 6.3cm），高斯全在相机背后/被近平面裁掉 |
| TARGET_COV=12（当前代理的实测天花板） | **闭环真正收敛**：好视角自适应停在 0.20~0.23m、cov 12.0~13.1%，靠覆盖率终止而非撞下限 |

**天花板成因（数值吻合验证）**：
- 头部代理 = 椭球 K×spread = [8.8, 4.0, 6.9] cm（脸部点簇），远小于真人头（半径 ~9cm）
- d=0.19m、fx≈493 → 椭球投影椭圆 228×104 px，几何占画面 28%；
  但簇内高斯稀疏、平均 alpha≈0.45 → 实测 28%×0.45 ≈ 12.6%，与实测 12.8% 吻合
- 故「40% 目标」要成立，必须换成**真·人头高斯**（3DMM 头/身/景拆分后的 head_gs），
  届时 40% 对应约 0.25~0.30m 物距；在 3DMM 落地前用 TARGET_COV=12 作为 interim 值
