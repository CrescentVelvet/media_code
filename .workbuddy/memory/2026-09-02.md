## vggt_human 全黑渲染根因（已确诊 + 官方对照实验已跑）
- **症状**：model_3dgs/train/ours_30000/renders 全黑带小白点，GT 正常。以为是"粗糙"，其实是训练**完全失败**。
- **铁证对比**（同一 source 数据）：
  - 你的 `train_pose.py`（增强全开）：高斯 1.8 万、跨度 162、opacity logit 爆到 12580、loss 发散
  - 官方 `train.py`（3000 iter）：高斯 36 万、跨度 3.3、opacity logit 1.57、loss 0.34→0.06 健康收敛

- **根因（train_pose.py）**：
  1. PoseAdjuster 把相机半径归一化到 10，但点云用同一个 scale=29.67 一起放大，导致训练时点云跨度 162（应 ~2），与 camera_extent=10 严重脱节

  4. 多个失败因素叠加，训练后期 opacity 爆到 12580 → 渲染全黑

## 加回 depth_normal_cons 增强（P1-1）
- **法线公式 bug（关键修复）**：`depth_normal_cons.py` 的 `estimate_normal_from_depth` 原写 `(-dz/dx/fx, -dz/dy/fy, 1)`，应由 `P(u,v)=((u-cx)Z/fx,(v-cy)Z/fy,Z)` 取切线叉积得 `(-Zu*fx, -Zv*fy, Z)`。原版既把 fx/fy 乘除弄反（差 fx² 倍，fx≈1000），又把 nz 写成常数 1 而非深度 Z，导致法线退化成近似 (0,0,1)，DN Loss≈1.0 等同随机噪声、约束静默失效。修正后 DN Loss 降到 0.35-0.54（合理范围）。
- **缓存尺寸不匹配崩溃**：densification 会 clone/split 高斯，点数变化后缓存的法线索引对不上当前点云，`point_normals * view_dir` 报 `tensor a (7163) must match b (9679)`。修法：检测点数变化时立即重算缓存（不只靠固定间隔）。
- **import 路径**：`train_depth_normal.py` 位于 `vggt_human/`，但 import 依赖官方仓根目录模块（utils/、gaussian_renderer/、scene/）。Python 只把脚本所在目录加进 sys.path[0]，cd 到 GS_DIR 不够，需在脚本顶部 `sys.path.insert(0, GS_DIR)`。
- **触发开关**：`USE_DEPTH_NORMAL=1`（环境变量），不是 `--depth_normal_consistency`（命令行参数）。权重 `DEPTH_NORMAL_WEIGHT` 默认 0.05。
- **commit**：`7c266f0`（加回+法线修复）、`55249bc`（缓存崩溃修复）
- **待验证**：30000 iter 完整对照训练（基线亮度 127.6 vs GT 127.9，看 DN 增强后能否提升）

## 加回 pose_refine（P1-2，遇阻）
- **关键发现**：diff_gaussian_rasterization 的 CUDA rasterizer **不支持对 viewmatrix 求梯度**。
  - `world_view_transform.sum().backward()` → 位姿参数有梯度 ✓（说明 cat 构造修复了梯度链）
  - `render(prc, gaussians, pipe, bg)` 后 L1 loss backward → 位姿参数 grad=None ❌
  - 原因：rasterizer 把 viewmatrix 当常量用于投影，只对高斯参数求梯度
- **修复的 bug**：
  1. `world_view_transform` 原 `torch.zeros(4,4)` + in-place 赋值断梯度 → 改 `torch.cat` 构造
  2. `PoseRefinedCamera` 缺 `alpha_mask` 等属性 → 加 `__getattr__` 委托 base Camera
  3. `_rotmat_to_quat` 用了 `np` 但 numpy 在条件块内 import → 移到顶部
- **commit**：`def70d2`
- **结论**：pose_refine 在当前 rasterizer 下无法工作。需换可微 rasterizer（如 gsplat）或用替代方案（COLMAP bundle adjustment / 独位姿优化 loop）
