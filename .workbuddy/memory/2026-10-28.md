## 00 编译两连坑（同日下午实锤）
- **custom_rasterizer 构建隔离**：setup.py import torch，pip 隔离环境没有 → `--no-build-isolation`（同 basicsr 手法）。
- **cusparse.h 找不到**：torch 2.5.1+cu121 是 pip 轮，CUDA 头在 `site-packages/nvidia/*/include`
  （conda env 的 nvcc 12.1 只带 runtime 头）。修法：00 里把 `nvidia/*/include` 拼进
  `CPLUS_INCLUDE_PATH`、`nvidia/*/lib` 拼进 `LIBRARY_PATH`，nvcc/host gcc 就能找到。
- **WSL 无系统 c++**：conda toolchain 只有 `x86_64-conda-linux-gnu-c++`，官方
  compile_mesh_painter.sh 写死 `c++` → 00 里建 mktemp shim 软链 c++/g++/cc/gcc 前置 PATH。
- **GitHub releases 不可达（000）**：RealESRGAN_x4plus.pth 改走 ModelScope
  `AI-ModelScope/RealESRGAN_x4plus`（67,040,989 B，与官方一致）；wget/curl 全部加超时防挂死。
- **wsl.exe 变量预展开又踩 2 次**：`$E`、`$PATH` 在 bash -c 单引号串里仍被 Windows 侧吃掉
  （Windows PATH 注入报 not a valid identifier）。铁律重申：wsl 命令串要么平铺无变量、
  要么写 .sh 文件跑 `MSYS2_ARG_CONV_EXCL='*' wsl -- bash /mnt/c/.../xx.sh`。
- 验证通过：custom_rasterizer / mesh_inpaint_processor import OK（前者需先 import torch）。
