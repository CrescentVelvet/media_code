## ⚠️ 加研H100（蓝区）ssh 连不上的标准处置顺序（2026-11-21 峰哥实踩）
- **现象**：`ping 69.48.159.15` 通（~256ms TTL=47），但 `ssh -o ConnectTimeout=10` 报
  `Connection timed out`，TCP 22 探测也是 timeout，不是 refused。换了 WiFi 网络后立刻出现。
- **根因**：换 WiFi 后**本机公网 IP 变了**，服务器有 IP 白名单，新 IP 不在白名单里。
  叠加一层：**v2rayN 代理开着**会让公司 WiFi 的 captive portal（认证页）打不开，
  没认证成功之前实际出口受限，看起来像"网络没事但 ssh 连不上"。
- **处置顺序（峰哥定的标准流程）**：
  1. **先关 v2rayN 代理**（系统代理 + 退出客户端更稳）；
  2. **连接公司 WiFi**，浏览器会自动弹认证页，完成认证；
  3. **重开 v2rayN 代理**；
  4. 再 `ssh h100`，恢复。
- **判据对照表**（以后再遇到先按这个分流，别去查服务器）：
  | 现象 | 指向 |
  |---|---|
  | ping 通 + TCP 22 timeout（不是 refused） | 出口 IP 不在白名单 / 中间设备丢包 |
  | TCP 22 refused | 服务端 sshd 没起，走 IPMI/带外 |
  | 全部站点都连不上 | 本机没完成 WiFi 认证（captive portal）|
  | 换 WiFi 后才出现 | 优先怀疑白名单（加研/蓝区这台有）|
- **不要做的事**：
  - ❌ 不要直接怀疑服务器挂了（这次服务器一直是好的）；
  - ❌ 不要先 `sacct` / `sinfo` 查作业——根本连不上去；
  - ❌ 不要在代理开着时去点 WiFi 认证页，会卡住转圈。
- 该条只适用于**加研 H100（蓝区，`69.48.159.15`）**，其它服务器不一定有 IP 白名单。
