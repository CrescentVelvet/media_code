
## tools_99 新增族 E：运镜轨迹渲染（2026-10-31）

- **99l_gen_colmap_traj.py**（纯标准库）：参数化运镜 → COLMAP 三件套。orbit/helix/
  dolly_zoom/push_in/arc；`PLY=...` 自动定心用**中位数中心 + q90 半径**（不用包围盒——
  flashworld 场景有离散远点，bbox 半径 20m 主体才 1m 级）；EASE=smoothstep 是电影感来源。
- **99m_render_trajectory.py**（infinisplat_v2 env，gsplat 1.5.2 + torch 2.6）：读 COLMAP
  三件套渲 MP4（cv2.VideoWriter mp4v，本机无 ffmpeg）。activation 与 3DGS 训练端一致；
  PLY rot 默认官方 wxyz 加载时 roll 成 xyzw；scale/rot 兼容向量与逐分量两种写法。
- **实测踩过的坑**：look_at→w2c 时 OpenCV y 轴向下，第二个基向量必须是 -up（用 +up
  画面上下颠倒且能通过相机中心回算检查，极难发现）；images.txt 每条记录必须两行
  （位姿行 + 空 POINTS2D 行），99m 用「字段数 mod 3」双重判据防错位。
- **性能实测**（RTX 3090）：405 万高斯 120 帧 1920x1080 渲染 4.6s，≈26 it/s 全分辨率。

## 99m 通道主序 f_rest 彩虹 bug 修复（2026-10-31，commit 1d7c9eb）
- 症状：整屏红绿蓝色影。根因：HMSD/4khq_human fork 导出 PLY 少做 transpose，
  f_rest 为**通道主序**（R/G/B 各一块 15 列），99m 按官方系数主序 reshape → SH 系数
  跨颜色通道污染。DC 项不受影响 → 静止视角正常、一动相机才花，极易误判为编码问题。
- 判据：按每通道 15 列切块，**各块尾/头能量比最大值** < 0.30 → channel（通道主序每块
  都衰减；系数主序至少有一块同阶近似水平）。均值版判据会把系数主序误判（0.246）。
- 之前 flashworld/dtu_smoke 的 PLY 均系数主序或无 f_rest → SH 分支从未被反向数据测到。
- 修复：99m SH_LAYOUT=auto|coef|channel；99n 判据同源修复（原判据误报 45 系数"非标"，
  实际 45=3×15=SH3 完整）。合成双布局 PLY 回归实测：检测双向正确、渲染色相正确。
- 旁证：该 PLY x/y/z min/max 逐位相同（±293.1975），导出器做过立方体归一化，不影响渲染。

## SH 排布 auto 二次修复：双统计量或规则（commit 7ed4890）
- 首版均值判据在真实 PLY 上失效（auto 仍彩虹、强制 channel 正常）：真实训练 SH
  重尾 + 未收敛异常点，tail 列 mean|x| 被拉爆 → 块比 0.39 越过 0.30 阈值。
- 教训：**合成测试用高斯噪声会掩盖重尾问题**；判据类逻辑必须用重尾/异常值数据测。
- 终版：中位(0.30)/均值(0.25) 双统计量取「或」，全块衰减才认 channel；系数主序
  的同阶块在任何中心统计量下都水平，不会被「或」误判。三场景合成实测通过。
- 测试还踩一个坑：>50% 稀疏零值会让中位数退化为全零（ratio=1 全报 coef），
  合成数据稀疏度不能超 50%。

## 99m 批量渲染改造（commit 3e1ee6c）
- TRAJ_DIR 支持逗号分隔多条轨迹：PLY 只加载一次，逐条渲成 OUT_DIR/<轨迹目录名>.mp4；
  单条时 OUT 仍可自定义文件名。渲染循环拆为 render_traj(gs, cams, frames, out_path, P)。
- main() 预设改成 TRAJ_DIRS 列表（用户手滑把 6 个路径写成 Path() 相邻字符串拼接=单一路径 bug）。
- 踩坑：gsplat 的 import 放在 main() 里，render_traj 引用 NameError——import 必须放用到它的函数里。
- 坑2：Git Bash 双引号字符串里 \n 不会转义换行，会进 commit message 字面量且尾部引号残留——
  多行 commit message 用 git commit -F - << 'MSG' heredoc；heredoc 定界符别与外层 cat << 'EOF' 撞名。
