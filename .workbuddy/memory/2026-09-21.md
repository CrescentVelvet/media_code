### 关键结论
- **能做，但不能冲 2K**。24GB 卡 BF16 装不下（全套 33 GB），SGLang 官方 4090 实测峰值 22.7 GiB @1024×1024（text encoder 逐层 offload）。
- 推荐路线：**ComfyUI + Comfy-Org 官方 INT8 重打包**（DiT 6.76 + TE 8.71 + VAE 0.63 = **16.10 GiB**，24GB 可全常驻）。
- diffusers 官方路线需 git main（清华源最高 0.40.0，无 `QwenImage21Pipeline`）；transformers 需 ≥5.17（清华源已有 5.17.0）。

### 本机环境新事实（实测，重要）
- **网络策略：本机不走代理**。`proxy.env` 里没有 `http_proxy`/`https_proxy`，只有 `HF_ENDPOINT=https://hf-mirror.com` + `HF_TOKEN` + `PIP_INDEX_URL=清华源`。
  - `huggingface.co` 直连 000 不通；`hf-mirror.com` 200 可用。
  - **`github.com` 直连 000 不通**；gitee 的 diffusers 镜像无效；**唯一可用通道是 `ghfast.top`**（`git ls-remote` 已验证成功）。
  - 推论：`AGENTS.md` 的 `_env.sh` 代理模板在本机是空转（不报错但不起作用）。
- WSL 资源：54 GiB 内存 / 128 GiB swap / 866 G 可用（/）/ 8.8 T 可用（/mnt/d，可写）/ i9-12900K 8 核。
- `.wslconfig` 里 **`vhdxSize=100GB` 是无效键**，WSL 启动报未知键警告；实际根分区 1007 G。
- conda env 清单（`/home/velvet/miniconda3`）：4danyone / flame_human / minimax_h3 / osediff / sam3 / sharp / vggt_human。
  - 最接近需求的 `minimax_h3`：py3.11.6 + torch2.6.0+cu124 + transformers5.15.1 + diffusers0.40.0，**两个包都不达标**，建议新建独立 env。

### 待核实 / 风险
- **无任何 3090 公开实测数据**（SGLang 只测到 4090；媒体口径"runs on 3090"是推断）。
- **2K 峰值显存全网无数据**，token 4 倍导致 attention 平方增长，24GB 上大概率 OOM。
- Ampere sm_86 无 FP8 tensor core → 3090 上 FP8 无速度收益，**INT8 才是正解**。
- `int8_convrot` / `w4a8` 在 sm_86 的 kernel 可用性【待核实】。
- `pip install git+https://ghfast.top/...` 的可行性【待核实】（仅验证了 git ls-remote）。
