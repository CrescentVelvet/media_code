    • ⚖️ Step 01 三种方式对比

    01 Full — SAM 3D Body

    • 原理: 3D 姿态 global_rot 算朝向
    • 准确度: ★★★★★ (最准)
    • 速度: ~2-5s/张 (模型重)
    • 权重: GATED, ~1GB+ (需 HF_TOKEN)
    • 额外依赖: detectron2, pyrender, MoGe2
    • 分割: SAM2 / 3D mesh / bbox 三级
    • 适用: 有 HF Token + 要最准

    01b Simple — 按面积

    • 原理: 检测人体 → 按面积最大选
    • 准确度: ★★☆ (面积大≠正面)
    • 速度: ~1-2s/张 (每张都跑检测+分割)
    • 权重: 无 GATED (只需 ViTDet)
    • 额外依赖: detectron2
    • 分割: SAM2 / bbox
    • 适用: 无 GATED + 快速跑

    01c MediaPipe — Face Mesh

    • 原理: 鼻尖居中 + 双眼距离最大
    • 准确度: ★★★★ (正面锁定好)
    • 速度: ~0.1s/张 评分 + 1张分割
    • 权重: 无 (pip 包, face_landmarker.task ~1MB)
    • 额外依赖: mediapipe (轻量)
    • 分割: 两阶段, 先选再分割 (省加载)
    • 适用: 无 GATED + CPU + 要正面

    🔄 数据闭环

    Step 03 的输出 rotate_360/image/ 是合法的 INPUT_DIR，可喂回 Step 01 重新选图 + 分割 —— 形成"生成→选图→再生成"的闭环。 同样可喂给 pi3_3dgs 或任何接受 INPUT_DIR/image/ 模式的算法。
