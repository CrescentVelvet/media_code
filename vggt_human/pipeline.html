VGGT-Human — 算法整体思路与实现细节

多视图图像 → VGGT-Omega 前馈重建 → COLMAP 格式转换 → 3DGS 优化训练
（含去噪增强 + 人脸美颜 + 位姿优化）

整体流程总览

[01] 前处理人脸增强 (MediaPipe+HYPIR+渐变融合) ──→ input_face/images/ [02] VGGT-Omega 前馈推理 (一次前向→位姿+深度→点云) ──→ vggt/<scene>/predictions.npz [03] npz→COLMAP 转换 (Otsu过滤+体素降采样+坐标对齐) ──→ source/ (cameras.txt + images.txt + points3D.txt) [04] 3DGS 训练 (L1+SSIM loss, 30k iter, densification) 可选: PoseAdjuster 居中+重力对齐+尺度归一化 可选: PoseRefineModule 训练中可学位姿 ──→ model_3dgs/point_cloud.ply ═══ 可选增强（去噪+人脸后处理+重训）═══ [05] 渲染新视角→去噪→AdaIN (DiffBIR/SwinIR可切换) ──→ source_aug/ (原图+去噪虚拟视角) [06] 后处理人脸增强 (同01脚本, 对增强场景图) ──→ source_aug_face/ [07] 增强场景训练3DGS (原图+去噪图+人脸增强 共同监督) ──→ model_3dgs_denoise/point_cloud.ply

所有步骤共用 vggt_human conda env（从 doll 克隆，含 torch≥2.3 + 3DGS CUDA 扩展 + HYPIR 依赖 + mediapipe）。

01 前处理人脸增强

算法思路

VGGT-Omega 重建出的点云在人脸区域可能因低纹理（光滑皮肤）导致深度估计不准。在推理之前对人脸做美颜增强，可以让 VGGT-Omega 看到更清晰的纹理细节，间接提升重建质量。同样在训练之后（step 06）对 3DGS 场景图做人脸增强，让 3DGS 训练时人脸区域有更好的 GT 质量。

实现步骤

  1. MediaPipe BlazeFace 人脸检测：对每张图运行 mp.solutions.face_detection，输出相对坐标的 bbox (xmin, ymin, width, height)，转为像素坐标。
  2. 框放大：bbox 中心不变，宽高各放大 FACE_PADDING（默认 0.2 = 20%），裁出人脸区域 (x1, y1, x2, y2)。过小（<32px）跳过。
  3. Pad 到 8 的倍数：用 F.pad(mode='reflect') 在右下补 0 到宽高都是 8 的倍数。原因：HYPIR 的 SD2 VAE 下采样倍率是 8，非整除会导致 VAE 编解码后尺寸不匹配（如 31→30 的 off-by-one 错误）。
  4. HYPIR 增强：裁剪图 → SD2Enhancer.enhance(lq, prompt="", upscale=1)。upscale=1 表示只做修复/美颜，不超分。HYPIR 加载 beauty_ppr50k 训练的 LoRA checkpoint。
  5. 剥 padding：result.crop(0, 0, rw-pad_w, rh-pad_h) 去掉右下 padding。
  6. 渐变融合：构造二次衰减 mask mask = clip(1 - (r/r_max)², 0, 1)，中心=1（完全用 HYPIR 结果），边缘=0（完全用原图），中间平滑过渡。
渐变融合公式 blended = original × (1 - mask) + enhanced × mask
mask(x,y) = clamp(1 - (r(x,y) / r_max)², 0, 1)
r(x,y) = √((x-cx)² + (y-cy)²),   r_max = min(cx, cy)
关键设计：01 和 06 调用同一个 face_enhance.py，脚本自动适配输入结构（images/ 子夹 / image/ 子夹 / 散图夹 + 有无 sparse/）。01 无 sparse（前处理），06 有 sparse（后处理，原样复制）。

02 VGGT-Omega 前馈推理

算法思路

VGGT-Omega（CVPR 2026 Oral，1B 参数）是前馈模型——一次前向推理即可从任意数量视图恢复相机位姿 + 深度图。不需要特征匹配 / SfM / bundle adjustment，几秒出结果。

相比 Pi3（pdfgs_human 用的模型），VGGT-Omega 的优势：实际内参（模型预测，不是假设 fx=fy=max(W,H)）+ w2c 直接输出（无需 c2w→w2c 转换）+ 置信度图（可用于自适应过滤）。

实现步骤

  1. 场景发现：discover_scenes(INPUT_DIR) 自动识别输入结构——散图夹→1场景 / 视频→抽帧 / 场景子夹→批量。
  2. 图像预处理：load_and_preprocess_images(mode=balanced, resolution=512)。balanced 模式按 token 预算调大小；max_size 限最长边=RESOLUTION（省显存）。
  3. 前向推理：VGGTOmega(images) → 一次出 pose_enc（位姿编码）+ depth + depth_conf（置信度）+ images。
  4. 位姿解码：encoding_to_camera(pose_enc) → 外参 extrinsic (N,3,4) w2c [R|t] + 内参 intrinsic (N,3,3)。
  5. 深度反投影：unproject_depth_map_to_point_map(depth, extrinsic, intrinsic) → 世界坐标点云 (N,H,W,3)。
深度反投影公式（每个像素） x_cam = (u - cx) / fx × depth
y_cam = (v - cy) / fy × depth
z_cam = depth
x_world = R_w2c^T × (x_cam - t_w2c)   # R^T 因为 w2c→c2w 是转置逆

输出 predictions.npz 的 keys 与官方 demo_gradio.py 一致：depth, depth_conf, extrinsic, intrinsic, world_points_from_depth, images, pose_enc。

显存：随帧数线性增长——1帧~6GB, 100帧~13GB, 500帧~43GB（624×416）。用 RESOLUTION=256 或 MODE=max_size 降压。run_batch.py 捕获 OOM 继续下一个场景。

03 npz → COLMAP 转换

算法思路

3DGS 的 train.py 读 COLMAP 文本格式场景（cameras.txt + images.txt + points3D.txt）。VGGT-Omega 输出的 predictions.npz 需要转换为这个格式。核心挑战：点云太大（百万级）需要降采样到 ~200k 给 3DGS 做初始化。

三个核心操作

① 自适应置信度过滤（Otsu's method）

VGGT-Omega 的 depth_conf 是每个像素的深度置信度。用 Otsu 方法在置信度直方图上找最大化类间方差的阈值——自动分离高/低置信度点，无需手动调阈值。

Otsu 目标函数 σ²_between(t) = w₀(t) × w₁(t) × [μ₀(t) - μ₁(t)]²
t* = argmax σ²_between(t)

若 Otsu 结果过疏（<5%点保留）或过密（>80%），回退到百分位阈值（10th / 40th percentile）。

② 体素降采样到 ~200k

过滤后的点云仍有数百万点。用体素网格降采样：从场景包围盒体积和目标点数算出体素大小，每个体素保留最高置信度的点。

体素降采样 voxel_size = ∛(scene_volume / target_count)
key(x,y,z) = floor((point - scene_min) / voxel_size)
每 key 保留 conf 最大的点   # sort by key, keep first occurrence of each unique key

③ 坐标系对齐

点云减去质心居中到原点，相机平移相应调整。帮助 3DGS 训练稳定性（场景在原点附近，learning rate 和 densification 阈值更合理）。

坐标系对齐（POSE_ADJUST=0 时生效；=1 时由 PoseAdjuster 接管） centroid = mean(points)
points_new = points - centroid
t_new = R @ centroid + t_old   # 相机平移调整（w2c 约定）

图像处理

优先从 frames/ 复制原图（质量更好），内参按原图 / 预处理图尺寸比缩放。若 frames/ 不可用，从 npz 的 images 数组保存 PNG。

内参缩放 scale_x = original_W / npz_W
fx_new = fx_npz × scale_x,   cx_new = cx_npz × scale_x   # 同理 fy, cy

04 3DGS 训练

算法思路

3DGS（3D Gaussian Splatting）用一组 3D 高斯点表示场景。每个高斯有：位置 μ(3)、缩放 s(3)、旋转 q(4, 四元数)、不透明度 α(1)、球谐系数 SH(48, degree 3)。通过可微分光栅化将高斯投影到 2D 图像，与 GT 比较，梯度下降优化所有参数。

训练循环（每 iteration）

  1. 随机选相机：从训练集随机取一个 camera。
  2. 渲染：render(cam, gaussians, pipe, bg) → diff-gaussian-rasterizer (dr_aa 分支, antialiasing) 光栅化高斯 → RGB image (3,H,W)。
  3. 损失：loss = (1-λ)×L1 + λ×(1-SSIM)，λ=0.2。
  4. 反向传播：loss.backward()。
  5. 高斯优化器 step：Adam，更新 μ/s/q/α/SH。
  6. 密度控制（iter 500-15000，每 100 iter）：梯度大的高斯 split（分裂）或 clone（克隆）；低不透明度的 prune（剪枝）。iter 3000 重置不透明度。
  7. 保存：iter 7000 / 30000 存 PLY。
3DGS 光栅化（diff-gaussian-rasterizer, dr_aa 分支） G(x) = α × exp(-½(x-μ)² Σ⁻¹ (x-μ))   # 2D 高斯（投影后）
C(p) = Σᵢ Gᵢ(p) × cᵢ(p)   # alpha blending (front-to-back)
α = σ(opacity) × G_scale   # 不透明度 × 高斯覆盖
c = SH(SH_coefficients, dir)   # 球谐颜色（视角相关）

两种模式

模式条件行为
标准POSE_ADJUST=0, POSE_REFINE=0直接调官方 train.py
位姿优化POSE_ADJUST=1 或 POSE_REFINE=1调 wrapper train_pose.py（见下方位姿优化模块）

位姿优化模块（可选，通过 env 开关控制）

Part 1: PoseAdjuster — 训练前一次性位姿调整

在 COLMAP 加载后、GaussianModel 创建前执行。三个独立操作：

操作①：平移居中（视线交点法）

不是简单取相机位置质心，而是用所有相机的视线方向求交点——找到所有相机"看向"的焦点。对环绕人像拍摄更准。

最小二乘视线交点 对每个相机 i: c2w_t_i = center + t_i × sight_dir_i
→ [I₃ | -diag(sight_dir_i)] × [center; t₁..tₙ] = c2w_t_i
→ A(3n, n+3), b(3n,) → center = (AᵀA)⁻¹ Aᵀb 的前 3 个分量

inside-out vs outside-in：比较 ‖c2w_t + sight_dir - center‖ 和 ‖c2w_t - sight_dir - center‖，前者近 = inside-out（相机看向外），翻转 sight_dir 重新求解。

操作②：旋转重力对齐（SVD）

环绕拍摄时相机 right 向量在水平面内变化，与重力方向垂直。取所有 right 向量的协方差做 SVD，最小奇异值对应的向量 = 与所有 right 最垂直 = 重力方向。

重力方向估计 right_vecs = [w2c_r[:,0] for each camera]   # (N, 3)
C = right_vecsᵀ × right_vecs   # (3, 3) 协方差
U, S, V = SVD(C) → down = Vᵀ[2]   # 最小奇异值向量
若 dot(down, mean_down) < 0 → down = -down   # 对齐方向
旋转矩阵构建 lookat = normalize(cross(first_right, down))
right = normalize(cross(down, lookat))
pred_rot = [right, down, lookat]ᵀ @ diag(1, -1, -1)   # OpenGL/OpenCV 约定适配

操作③：尺度归一化

extent = median(‖c2w_t_i - center‖)   # 相机到中心距离中位数
scale = 10 / extent   # 归一化到半径 10

变换公式（关键：相机和点云公式不对称）

正向变换 相机: new_w2c_t = scale × (w2c_t + w2c_r @ center)
new_w2c_r = w2c_r @ pred_rot
点云: new_pts = scale × (pts - center) @ pred_rot

反向变换（训练后恢复原始坐标） 相机: old_w2c_r = w2c_r @ pred_rotᵀ
old_w2c_t = (1/scale) × w2c_t - old_w2c_r @ center
高斯: pts = (1/scale) × pts @ pred_rotᵀ + center
scaling /= scale, rotation @= pred_rotᵀ
不对称原因：w2c_t 是相机世界坐标取负后旋转（w2c_t = -R×C），所以先加 center（恢复 C）再旋转；点云直接减 center 再旋转。

Part 2: PoseRefineModule — 训练中可学位姿精炼

每个相机的位姿作为 nn.Parameter，通过梯度下降持续微调，修正 COLMAP/VGGT-Omega 的位姿误差。

PoseRefineModule 设计

  • w2c_q_vec (4,): 可学四元数 [w,x,y,z]，requires_grad=True
  • w2c_t_vec (3,): 可学平移
  • intrinsic_ndc (4,): NDC 空间内参 [fx/W, fy/H, cx/W, cy/H]（可选学，REFINE_INTRINSIC 开关）
  • 冻结的 _ori 副本用于正则化
正则化损失 reg_loss = ‖q - q_ori‖² + ‖t - t_ori‖²
total_loss = L1 + λ_dssim × (1 - SSIM) + pose_refine_weight × reg_loss
优化器（三组学习率） Adam: q→1e-3, t→1e-3, intrinsic_ndc→1e-4

PoseRefinedCamera — 动态 world_view_transform

原始 3DGS 的 Camera 存预计算的 world_view_transform（4×4 tensor）。改为从 PoseRefineModule 的可学四元数动态计算，梯度通过 quat → rotmat → wvt → rasterizer → rendered_image → loss 流回位姿参数。

world_view_transform 动态计算 R = quat_to_rotmat(w2c_q_vec)   # (3,3) 可微
T = w2c_t_vec   # (3,)
wvt = [[R, 0], [T, 1]]   # 3DGS 行主序约定 (4×4)

四元数→旋转矩阵（PyTorch 可微实现）：

R = [[1-2(y²+z²), 2(xy-wz), 2(xz+wy)],
[2(xy+wz), 1-2(x²+z²), 2(yz-wx)],
[2(xz-wy), 2(yz+wx), 1-2(x²+y²)]]

训练循环修改

# 标准 3DGS 训练循环 + 位姿精炼
render_pkg = render(cam, gaussians, pipe, bg)
loss = (1-λ)×L1 + λ×(1-SSIM)
loss += pose_refine_weight × cam.pose_module.reg_loss()  # 新增
loss.backward()
gaussians.optimizer.step()                               # 高斯优化
cam.pose_optimizer.step()                                 # 新增: 位姿优化
gaussians.optimizer.zero_grad(set_to_none=True)
cam.pose_optimizer.zero_grad(set_to_none=True)

执行顺序

  1. COLMAP 加载 → 初始 w2c_qvec, w2c_tvec
  2. PoseAdjuster.apply_to_camera() → 调整后的位姿
  3. PoseAdjuster.apply_to_points() → 调整后的点云
  4. 创建 Camera，用调整后位姿初始化 PoseRefineModule（ori = 调整后的值）
  5. 创建 GaussianModel，用调整后点云初始化
  6. 训练循环中 PoseRefineModule 持续微调
  7. 训练结束 PoseAdjuster.reverse → 原始坐标系 PLY
反向变换时机：训练中保持调整后坐标系（PLY + 相机都在调整后坐标，render_novel 直接用）。训练结束额外存 point_cloud_original/point_cloud.ply（恢复原始坐标，供外部工具）。PoseAdjuster 参数存 JSON 供 render_novel 加载正向变换虚拟相机。

05 渲染新视角 → 去噪 → AdaIN → 增强COLMAP

算法思路

3DGS 在训练相机覆盖密集的区域重建好，但在相机稀疏的间隙区域有伪影（空洞 / 模糊 / 拉伸）。策略：在相机轨迹的间隙插入虚拟相机 → 用当前 3DGS 渲染（有伪影）→ 去掉伪影 → 当作"伪 GT"加入训练集 → 3DGS 在这些区域也有监督信号。

Stage 1: render_novel.py — 渲染新视角

  1. 加载 3DGS：从 step 04 的 PLY 加载 GaussianModel（若 PoseAdjuster 启用，加载 JSON 正向变换相机到调整后坐标系）。
  2. 相机轨迹分析：把训练相机按绕场景中心的方位角排序，找最大间隙。
  3. SLERP 插入虚拟相机：在每个大间隙中插入 NUM_NOVEL_VIEWS 个中间视角。位置线性插值，旋转用 SLERP（球面线性插值）。
  4. 渲染 + 算 alpha：每个虚拟相机渲染两次（黑底 + 白底），alpha = 1 - (white - black)。低 alpha = 稀疏区（高斯覆盖不足）。
SLERP 插值 位置: C_interp = (1-t)×C₁ + t×C₂
旋转: R_interp = Slerp([R₁, R₂], t)   # scipy.spatial.transform.Slerp
→ T = -R_interp @ C_interp   # 转 w2c
Alpha 计算（black + white 两次渲染） I_black = α × color + (1-α) × 0 = α × color
I_white = α × color + (1-α) × 1
α = 1 - (I_white - I_black).mean(dim=0)

Stage 2: denoise_images.py — 去噪 + AdaIN + 增强场景

  1. Alpha 检查：avg_alpha < ALPHA_THRESH 的视角 = 稀疏区，需去噪。高 alpha = 覆盖够，跳过。
  2. 去噪：DENOISER 可切换（DiffBIR / SwinIR / none）。denoisers.py 用 registry 模式——每个去噪器是函数 (image, device) → image，lazy load + cache。
  3. AdaIN 颜色校正：去噪图的颜色分布可能与原图不同（DiffBIR 可能偏色）。用 AdaIN 把去噪图的均值/标准差对齐到最近训练图。
  4. 写增强 COLMAP：原图 + 去噪图 → source_aug/images/；原相机 + 虚拟相机 → cameras.txt + images.txt；points3D.txt 不变。
AdaIN 颜色校正 s_mean, s_std = source.reshape(-1,3).mean(0), source.reshape(-1,3).std(0)
t_mean, t_std = target.reshape(-1,3).mean(0), target.reshape(-1,3).std(0)
corrected = (source - s_mean) / (s_std + ε) × t_std + t_mean
去噪模型可插拔：加新模型只需在 denoisers.py 写 denoise_my_model(image, device) → np.ndarray + 注册到 DENOISERS 字典。DENOISER=none 跳过去噪（仅渲染 + AdaIN）。

06 后处理人脸增强

与 step 01 调用同一个 face_enhance.py，算法和实现完全一致（MediaPipe → HYPIR → 渐变融合）。区别仅在输入：01 对原始输入图，06 对增强 COLMAP 场景中的图（source_aug/images/）。COLMAP sparse/ 原样复制（只增强图像，不改相机参数）。

前后两次人脸增强的作用互补：01 让 VGGT-Omega 看到更好的人脸纹理 → 重建更准；06 让 3DGS 训练时有更好的面部 GT → 渲染质量更高。

07 增强场景训练

用增强 COLMAP 场景（原图 + 去噪虚拟相机 + 人脸增强图）训练 3DGS。原图提供真实 GT 监督；去噪虚拟相机提供稀疏区域的额外监督（修正伪影）；人脸增强图提供更好的面部质量。同样支持 PoseAdjuster / PoseRefineModule。

默认从头训（增强场景有更多相机，结果通常更好）；可选从 04 的 checkpoint 续训（需 04 加 --checkpoint_iterations 存 .pth）。
