  • 二次衰减渐变 mask 无缝融合回原图

  • 写 cameras.txt / images.txt / points3D.txt

↓
04

3DGS 训练（标准或带位姿优化）

vggt_human env · gaussian-splatting (dr_aa)
  • 标准模式: train.py -s source --iterations 30000 (L1+SSIM, densification)
  • PoseAdjuster (POSE_ADJUST=1): 训练前视线交点居中 + SVD 重力对齐 + 尺度归一化
  • PoseRefineModule (POSE_REFINE=1): 训练中可学四元数+平移+内参, reg_loss 防漂移
  • 结束后反向变换 → 原始坐标系 PLY
→ model_3dgs/point_cloud/iteration_30000/point_cloud.ply

🔧 位姿优化模块（可选，通过 env 开关控制）

PoseAdjuster（训练前一次性变换）: 视线交点居中 → SVD 估计重力方向 → 旋转对齐 → 中位距离归一化到 10。存 JSON 供 render_novel.py 正向变换虚拟相机。
PoseRefineModule（训练中持续精炼）: 每个相机的 w2c 四元数+平移+内参作为 nn.Parameter, Adam 优化 (q/t: 1e-3, intrinsic: 1e-4), reg_loss 权重 0.01 防偏离。
PoseRefinedCamera: world_view_transform 从四元数动态计算（可微路径 → rasterizer → loss → 梯度回传到位姿参数）。

⚡ 可选增强：去噪 + 人脸后处理 + 重训
05

渲染新视角 → 去噪 → AdaIN

vggt_human env
  • Stage 1 render_novel.py: 加载 3DGS → 轨迹找间隙 → SLERP 插入虚拟相机 → 渲染 (black+white bg 算 alpha)
  • Stage 2 denoise_images.py: alpha<阈值=稀疏 → DENOISER 去噪 (DiffBIR/SwinIR/none 可切换) → AdaIN 颜色校正 → 写增强 COLMAP
→ source_aug/ (原图 + 去噪虚拟视角)
→
