🧪 一、HYPIR 美颜退化路径（数据集构建 03d/04b）

只输入原图人脸 → 同一 src 张量派生三张像素级对齐 512×512： hq_orig(原图) / hq_beauty(美颜) / lq_gauss(高斯模糊) · 共用 LQ 换 HQ 目标做 A/B 单变量对比

💡 核心思路：换 HQ 目标，修掉「长痘变丑」

现有 03c/04c 在线退化路径（LQ=高斯模糊、HQ=原图）虽能复原模糊，但模型过度增强会凭空长出皮肤瑕疵（"长痘变丑"）。

解法：LQ 保持同样的模糊，把 HQ 目标换成 RetouchFormer 的美颜版（已去瑕疵+磨皮、保结构）。模型仍学去模糊（增强不失），但目标变成干净光滑皮肤 → 不再 invent 瑕疵。

同时建两套数据做 A/B 单变量对比：两者共用同一 lq_gauss，仅 HQ 目标不同。

关键设计要点

  • 像素级对齐：三者皆派生自同一 src 张量，故任意尺寸/宽高比输入都安全（模型 VRT 写死 512×512，非方形会被 CenterCrop，而 hq_orig / lq_gauss 存的正是这个 crop 版本）。
  • 单变量 A/B：A 与 B 共用同一 lq_gauss，仅 HQ 目标不同 → 对比纯粹反映「HQ 美颜 vs 原图」对长痘问题的影响。BLUR_SEED 可复现地重随机。
  • 高斯模糊复现本仓 HYPIR clone 里简化版 batch_transform.py：随机 kernel 3/5/7/9/11、σ∈[1,2]、重复 1–5 次，每图一个 FIXED seeded 实现（离线，非每 epoch 重随机）。作用于 raw 对齐 crop（非 USM(orig)）——与 03c 略有偏差，但 A/B 共用同一 lq_gauss，对比仍是单变量。
  • 训练暖启动：从发布 HYPIR_sd2.pth LoRA 继续练、适配人脸域，而非从零重学（7k 张从零不够；发布模型是 bs1024 大数据训出来的）。
  • 对应脚本：Phase A = 03d_build_beauty_dataset.sh + build_beauty_dataset.py；Phase B = 复用 03b_build_paired_dataset.sh；训练 = 04b_train_paired.sh（A/B 各跑一次，OUTPUT_DIR 分开）。

🧍 二、三维人体重建中的人脸增强模块

双时机增强（前处理 / 后处理）→ 人脸定位 → 区域增强 → 渐变融合 →（可选）美颜后处理

⚙️ 模块定位：训练循环里的人脸质量提升

在人体重建（SMPLX / 3DGS / NeRF 训练）中，人脸区域常因分辨率低、模糊而细节丢失。该模块在训练前（前处理）或训练中特定 epoch（后处理）对 GT 人脸做增强，让监督目标更清晰，从而获得更高质量的人体重建结果。

关键点：用「人脸框 ∩ 身体 Mask 重叠率」把人脸框关联到人体 tracking ID，解决多人场景的人脸归属问题。

1
双时机增强（调用时机）
两种时机共用同一套增强流程（下方 Stage 2–5）
🟦 前处理增强
训练前增强 GT 图像
→ 增强后的图作为训练监督目标
🟪 后处理增强
训练中特定 epoch：用渲染图增强
→ 再回写 GT（迭代精修监督目标）

设计要点

  • 双时机：前处理静态提升 GT 质量；后处理随训练迭代——特定 epoch 用当前渲染图（而非原始 GT）做增强再回写，让监督目标随模型能力动态精修。
  • 人脸定位靠重叠率：RetinaFace 只给框、SAM3 只给追踪 ID + 身体 Mask，二者不直接关联；用「人脸框落在哪个身体 Mask 内的重叠率最大」把人脸框绑定到 tracking ID，解决多人场景的人脸归属。
  • 512×512 缩放对齐：EnhModel 与 RetouchFormer 都写死 512×512 输入，故 crop → upscale bbox → 缩放 512 → 推理 → 缩放回原尺寸，保证增强后人脸与原图像素对齐、可无缝贴回。
  • 54px 渐变掩码：硬接缝会留下可见边界；54px 宽渐变带让增强区从中心到边缘平滑过渡到原图，后处理模式再叠一层 alpha 掩码融合渲染图与增强图。
  • 美颜后处理可选串联：RetouchFormer 接口与 EnhModel 一致（同样的 crop → 512 → 推理 → 回缩 → 渐变融合流程），可在 EnhModel 之后作为第二 pass 串联，进一步去瑕疵磨皮。
