💡 核心思路：换 HQ 目标，修掉「长痘变丑」

现有 03c/04c 在线退化路径（LQ=高斯模糊、HQ=原图）虽能复原模糊，但模型过度增强会凭空长出皮肤瑕疵（"长痘变丑"）。

解法：LQ 保持同样的模糊，把 HQ 目标换成 RetouchFormer 的美颜版（已去瑕疵+磨皮、保结构）。模型仍学去模糊（增强不失），但目标变成干净光滑皮肤 → 不再 invent 瑕疵。

同时建两套数据做 A/B 单变量对比：两者共用同一 lq_gauss，仅 HQ 目标不同。

关键设计要点

  • 像素级对齐：三者皆派生自同一 src 张量，故任意尺寸/宽高比输入都安全（模型 VRT 写死 512×512，非方形会被 CenterCrop，而 hq_orig / lq_gauss 存的正是这个 crop 版本）。
  • 单变量 A/B：A 与 B 共用同一 lq_gauss，仅 HQ 目标不同 → 对比纯粹反映「HQ 美颜 vs 原图」对长痘问题的影响。BLUR_SEED 可复现地重随机。
  • 高斯模糊复现本仓 HYPIR clone 里简化版 batch_transform.py：随机 kernel 3/5/7/9/11、σ∈[1,2]、重复 1–5 次，每图一个 FIXED seeded 实现（离线，非每 epoch 重随机）。作用于 raw 对齐 crop（非 USM(orig)）——与 03c 略有偏差，但 A/B 共用同一 lq_gauss，对比仍是单变量。
  • 训练暖启动：从发布 HYPIR_sd2.pth LoRA 继续练、适配人脸域，而非从零重学（7k 张从零不够；发布模型是 bs1024 大数据训出来的）。
  • 对应脚本：Phase A = 03d_build_beauty_dataset.sh + build_beauty_dataset.py；Phase B = 复用 03b_build_paired_dataset.sh；训练 = 04b_train_paired.sh（A/B 各跑一次，OUTPUT_DIR 分开）。
